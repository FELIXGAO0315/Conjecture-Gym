# C186

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose -2*p_3 + 3*p_4 >= 0, -2*p_4 + 2*p_5 >= 0, sum_pk_after_p6 <= 1. Then 2*p_6 >= p_3 - 2*p_5 + 2.

**Formula.** `if ((is_simple) and (-2*p_3 + 3*p_4 >= 0) and (-2*p_4 + 2*p_5 >= 0) and (sum_pk_after_p6 <= 1)), then p6 >= ((((0.5 * p3) + (-1 * p5)) + 1))`

## Proof

    - Premise: `-2*p_4 + 2*p_5 >= 0`.
    - Premise: `-1*sum_pk_after_p6 + 1 >= 0`.
    - Assumption: `1*f_2 + -7 >= 0`.
    - Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Linear combination (`linarith`): `-1*p_3 + 2*p_5 + 2*p_6 + -6/5 >= 0`.
    - Integer rounding (`omega`): `-1*p_3 + 2*p_5 + 2*p_6 + -2 >= 0`.
  - **Case 2** (`1*f_2 <= 6`):
    - Inventory `tail_juc_upper`: `-3*sum_pk_after_p6 + 1*W_tail + -1*J_tail >= 0`.
    - Inventory `tail_juc_half`: `6*sum_pk_after_p6 + -1*W_tail + 2*J_tail >= 0`.
    - Premise: `-2*p_3 + 3*p_4 >= 0`.
    - Premise: `-2*p_4 + 2*p_5 >= 0`.

    - Linear combination (`linarith`): `-1*p_3 + 18/7 >= 0`.
