# C96

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 9, sum_pk_after_p6 <= 2, 3*p_3 - 2*p_5 >= 0. Then p_6 >= -2*p_4 - p_5 + 3.

**Formula.** `if ((is_simple) and (f_2>=_9) and (sum_pk_after_p6 <= 2) and (3*p_3 - 2*p_5 >= 0)), then p6 >= ((((-2 * p4) + (-1 * p5)) + 3))`

## Proof

- Inventory `tail_juc_lower`: `2*sum_pk_after_p6 + 1*J_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `-1*sum_pk_after_p6 + 2 >= 0`.
- Premise: `1*f_2 + -9 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
- Linear combination (`linarith`): `2*p_4 + 1*p_5 + 1*p_6 + -8/3 >= 0`.
- Integer rounding (`omega`): `2*p_4 + 1*p_5 + 1*p_6 + -3 >= 0`.
