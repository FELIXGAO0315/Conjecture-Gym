# C158

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose -2*p_3 + 3*p_5 >= 0. Then p_6 >= -2*p_4 - 2*p_5 + 6.

**Formula.** `if ((is_simple) and (-2*p_3 + 3*p_5 >= 0)), then p6 >= ((((-2 * p4) + (-2 * p5)) + 6))`

## Proof

- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Inventory `tail_juc_upper`: `-3*sum_pk_after_p6 + 1*W_tail + -1*J_tail >= 0`.
- Inventory `tail_juc_half`: `6*sum_pk_after_p6 + -1*W_tail + 2*J_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `-2*p_3 + 3*p_5 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Linear combination (`linarith`): `1*p_4 + 1*p_5 + -24/11 >= 0`.
- Integer rounding (`omega`): `1*p_4 + 1*p_5 + -3 >= 0`.
- Linear combination (`linarith`): `2*p_4 + 2*p_5 + 1*p_6 + -6 >= 0`.
