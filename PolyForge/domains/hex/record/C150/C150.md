# C150

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 42, sum_pk_after_p6 >= 3, -p_3 + 2*p_5 >= 0. Then 2*p_6 >= -p_4 - 2*p_5 + 12.

**Formula.** `if ((is_simple) and (f_2>=_42) and (sum_pk_after_p6 >= 3) and (-p_3 + 2*p_5 >= 0)), then p6 >= ((((-0.5 * p4) + (-1 * p5)) + 6))`

    - Linear combination (`linarith`): `1*p_4 + 2*p_5 + 2*p_6 + -12 >= 0`.
  - **Case 2** (`1*p_5 <= 5`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `1*f_2 + -42 >= 0`.

    - Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
    - Linear combination (`linarith`): `1*p_4 + 2*p_5 + 2*p_6 + -34/3 >= 0`.
    - Integer rounding (`omega`): `1*p_4 + 2*p_5 + 2*p_6 + -12 >= 0`.
