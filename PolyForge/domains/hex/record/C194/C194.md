# C194

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 36, 2*p_3 - 3*p_5 >= 0, p_4 <= 4. Then 2*p_6 >= -2*p_3 + p_5 + 10.

**Formula.** `if ((is_simple) and (f_2>=_36) and (2*p_3 - 3*p_5 >= 0) and (p_4 <= 4)), then p6 >= ((((-1 * p3) + (0.5 * p5)) + 5))`

- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `2*p_3 + 2*p_6 + -27/2 >= 0`.
- Integer rounding (`omega`): `1*p_3 + 1*p_6 + -7 >= 0`.
