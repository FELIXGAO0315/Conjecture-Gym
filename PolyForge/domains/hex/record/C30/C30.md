# C30

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 30, p_4 = 0, sum_pk_after_p6 >= 3. Then p_6 >= -2*p_3 - 2*p_5 + 22.

**Formula.** `if ((is_simple) and (f_2>=_30) and (p_4 = 0) and (sum_pk_after_p6 >= 3)), then p6 >= ((((-2 * p3) + (-2 * p5)) + 22))`

## Proof

- Case split (`by_cases`) on `bnb:p_3` at threshold 11: `2*p_3 + 2*p_5 + 1*p_6 + -22 >= 0`.
  - **Case 1** (`1*p_3 >= 11`):
    - Assumption: `1*p_3 + -11 >= 0`.
    - Inventory `nonneg_p_5`: `1*p_5 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Linear combination (`linarith`): `2*p_3 + 2*p_5 + 1*p_6 + -22 >= 0`.
  - **Case 2** (`1*p_3 <= 10`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Premise: `1*f_2 + -30 >= 0`.
    - Assumption: `-1*p_3 + 10 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
    - Premise: `1*p_4 == 0`.
    - Linear combination (`linarith`): `2*p_3 + 2*p_5 + 1*p_6 + -22 >= 0`.
