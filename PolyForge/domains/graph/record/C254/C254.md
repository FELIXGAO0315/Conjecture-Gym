# C254

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, alpha >= 2*omega, chi <= omega. Then 2*omega >= 2*n - 5*alpha + 8.

**Formula.** `if ((is_bipartite) and (alpha >= 2*omega) and (chi <= omega)), then (2*omega >= 2*n - 5*alpha + 8)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-2*omega + 1*alpha >= 0`.
- Premise: `-1*chi + 1*omega >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
- Linear combination (`linarith`): `1*alpha + -2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
- Linear combination (`linarith`): `-2*n + 2*omega + 5*alpha + -8 >= 0`.
