# C297

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), n <= 2*alpha. Then 2*alpha >= n - 3*chi + 6.

**Formula.** `if ((is_regular(3)) and (n <= 2*alpha)), then (2*alpha >= n - 3*chi + 6)`

## Proof

- Case split (`by_cases`) on `omega` at threshold 3: `3*chi + 1*alpha + -1*tau + -6 >= 0`.
  - **Case 1** (`1*omega >= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Assumption: `1*omega + -3 >= 0`.
    - Premise: `-1*n + 2*alpha >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*chi + 1*alpha + -1*tau + -9 >= 0`.
  - **Case 2** (`1*omega <= 2`):
    - Case split (`by_cases`) on `bnb:chi` at threshold 2: `3*chi + 1*alpha + -1*tau + -6 >= 0`.
      - **Case 1** (`1*chi >= 2`):
        - Assumption: `1*chi + -2 >= 0`.
        - Premise: `-1*n + 2*alpha >= 0`.
        - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
        - Linear combination (`linarith`): `3*chi + 1*alpha + -1*tau + -6 >= 0`.
      - **Case 2** (`1*chi <= 1`):
        - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
        - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
        - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
        - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
        - Assumption: `-1*chi + 1 >= 0`.
        - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
        - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
        - Inventory `regular_max`: `1*max_deg + -3 == 0`.
        - Linear combination (`linarith`): `3*chi + 1*alpha + -1*tau + -7 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `2*alpha >= n - 3*chi + 6`.
