# C135

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, min_deg <= 3. Then 2*diam + radius >= 3.

**Formula.** `if ((is_connected) and (has_cycle) and (min_deg <= 3)), then (2*diam + radius >= 3)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `2*diam + 1*radius + -5/2 >= 0`.
- Integer rounding (`omega`): `2*diam + 1*radius + -3 >= 0`.
