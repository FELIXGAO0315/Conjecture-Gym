# C92

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau >= 2*alpha. Then max_deg <= 3*m - 3*min_deg - 1.

**Formula.** `if ((tau >= 2*alpha)), then (max_deg <= 3*m - 3*min_deg - 1)`

## Proof

- Case split (`by_cases`) on `bnb:min_deg` at threshold 2: `3*m + -1*max_deg + -3*min_deg + -1 >= 0`.
  - **Case 1** (`1*min_deg >= 2`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Premise: `-2*alpha + 1*tau >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Assumption: `1*min_deg + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 2): `-2*n + -1*min_deg + 1*P_n_mindeg + 2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + -1 >= 0`.
  - **Case 2** (`1*min_deg <= 1`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Premise: `-2*alpha + 1*tau >= 0`.
    - Assumption: `-1*min_deg + 1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + -1 >= 0`.
