# C58

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, tau >= 2*alpha, girth <= 5. Then tau >= girth - 1.

**Formula.** `if ((has_cycle) and (tau >= 2*alpha) and (girth <= 5)), then (tau >= girth - 1)`

## Proof

- Inventory `girth_le_card`: `1*n + -1*girth >= 0`.
- Premise: `-2*alpha + 1*tau >= 0`.
- Premise: `-1*girth + 5 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -1*alpha + -1*girth + 5/3 >= 0`.
- Integer rounding (`omega`): `1*n + -1*alpha + -1*girth + 1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `tau >= girth - 1`.
