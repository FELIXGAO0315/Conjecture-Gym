# C58

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose -min_deg + 2*alpha >= 0, min_deg >= 3. Then 2*max_deg - min_deg + 2*alpha >= 7.

**Formula.** `if ((-min_deg + 2*alpha >= 0) and (min_deg >= 3)), then (2*max_deg - min_deg + 2*alpha >= 7)`

## Proof

- Premise: `1*min_deg + -3 >= 0`.
- Premise: `-1*min_deg + 2*alpha >= 0`.
- Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -2 >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Linear combination (`linarith`): `2*max_deg + -1*min_deg + -3 >= 0`.
- Linear combination (`linarith`): `2*max_deg + -1*min_deg + 2*alpha + -7 >= 0`.
