# C58

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), tau <= 1, max_deg >= 5. Then min_deg <= m - 4.

**Formula.** `if ((is_k_edge_connected(1)) and (tau <= 1) and (max_deg >= 5)), then (min_deg <= m - 4)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `1*max_deg + -5 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -6 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 0): `-6*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -1*min_deg + -10/3 >= 0`.
- Integer rounding (`omega`): `1*m + -1*min_deg + -4 >= 0`.
