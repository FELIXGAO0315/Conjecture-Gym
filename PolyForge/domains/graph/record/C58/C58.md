# C58

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_bipartite, -n + m <= 0, alpha - 2*diam <= 0. Then alpha >= -2*diam + 3.

**Formula.** `if ((is_tree) and (is_bipartite) and (-n + m <= 0) and (alpha - 2*diam <= 0)), then (alpha >= -2*diam + 3)`

## Proof

- Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `-1*alpha + 2*diam >= 0`.
- Inventory theorem `tau_le_card_sub_one` (via `linarith`): `1*n + -1*tau + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*radius + -1/4 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*alpha + 2*diam + -3 >= 0`.
