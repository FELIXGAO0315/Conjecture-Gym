# C81

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 6. Then max_deg <= 2*m - 2*min_deg.

**Formula.** `if ((n >= 6)), then (max_deg <= 2*m - 2*min_deg)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*n + -6 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 0): `-6*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*m + -1*max_deg + -2*min_deg >= 0`.
