# C17

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg >= 3. Then chi >= -2*m + 3*tau + 7.

**Formula.** `if ((min_deg >= 3)), then (chi >= -2*m + 3*tau + 7)`

## Proof

    - Assumption: `1*alpha + -2 >= 0`.
    - Premise: `1*min_deg + -3 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.

    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 3): `-3*n + -1*min_deg + 1*P_n_mindeg + 3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*m + 1*chi + -3*tau + -7 >= 0`.
  - **Case 2** (`1*alpha <= 1`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
