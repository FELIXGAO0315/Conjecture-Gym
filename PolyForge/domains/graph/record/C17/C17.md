# C17

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, min_deg <= 3, chi - 2*tau <= 0. Then tau >= -2*n - 2*m + 7.

**Formula.** `if ((is_tree) and (min_deg <= 3) and (chi - 2*tau <= 0)), then (tau >= -2*n - 2*m + 7)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `-1*chi + 2*tau >= 0`.
- Inventory theorem `tau_le_card_sub_one` (via `linarith`): `1*n + -1*tau + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2 >= 0`.
- Linear combination (`linarith`): `1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -1 >= 0`.
- Linear combination (`linarith`): `2*n + 2*m + 1*tau + -7 >= 0`.
