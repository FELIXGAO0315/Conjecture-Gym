# C17

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 6. Then 3*n >= m + 3.

**Formula.** `if ((n <= 6)), then (3*n >= m + 3)`

## Proof

- Inventory `edge_card_bound`: `-1*n + -2*m + 1*N2 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*n + 6 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 6): `7*n + -1*N2 + -6 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + -3 >= 0`.
