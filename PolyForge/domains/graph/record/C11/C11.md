# C11

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, max_deg <= 4. Then m <= 3*n - 3.

**Formula.** `if ((is_acyclic) and (max_deg <= 4)), then (m <= 3*n - 3)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*n + -1*m + -3 >= 0`.
