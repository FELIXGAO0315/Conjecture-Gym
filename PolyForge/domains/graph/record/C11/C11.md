# C11

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= tau. Then min_deg <= 3*chi + 3*alpha - 6.

**Formula.** `if ((chi >= tau)), then (min_deg <= 3*chi + 3*alpha - 6)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-1*min_deg + 3*chi + 3*alpha + -6 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `1*chi + -1*tau >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-1*min_deg + 3*chi + 3*alpha + -9 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-1*min_deg + 3*chi + 3*alpha + -6 >= 0`.
