# C11

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, -2*min_deg + diam <= 0. Then diam <= 2*min_deg + 2*radius - 2.

**Formula.** `if ((is_connected) and (has_cycle) and (-2*min_deg + diam <= 0)), then (diam <= 2*min_deg + 2*radius - 2)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `2*min_deg + -1*diam >= 0`.
- Linear combination (`linarith`): `1*min_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*min_deg + -1*diam + 2*radius + -2 >= 0`.
