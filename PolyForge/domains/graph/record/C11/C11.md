# C11

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, n <= 2*alpha. Then max_deg <= 2*alpha + tau - 3.

**Formula.** `if ((not_bipartite) and (n <= 2*alpha)), then (max_deg <= 2*alpha + tau - 3)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-1*n + 2*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*max_deg + 2*alpha + 1*tau + -5/2 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 2*alpha + 1*tau + -3 >= 0`.
