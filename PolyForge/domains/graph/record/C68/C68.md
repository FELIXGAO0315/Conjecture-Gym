# C68

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 3. Then n >= -3*chi + 2*tau + 4.

**Formula.** `if ((alpha <= 3)), then (n >= -3*chi + 2*tau + 4)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-1*alpha + 3 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 3, chi ≥ 1): `3*chi + 1*alpha + -1*P_alpha_chi + -3 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + 3*chi + -2*tau + -4 >= 0`.
