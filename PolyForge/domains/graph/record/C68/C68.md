# C68

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, chi >= max_deg, radius >= 1. Then 2*omega <= 3*max_deg + 2*chi - 3.

**Formula.** `if ((is_connected) and (chi >= max_deg) and (radius >= 1)), then (2*omega <= 3*max_deg + 2*chi - 3)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*max_deg + 2*chi + -2*omega + -3 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Linear combination (`linarith`): `3*max_deg + 2*chi + -2*omega + -4 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Premise: `1*radius + -1 >= 0`.
    - Linear combination (`linarith`): `1*n + -2 >= 0`.
    - Premise: `-1*max_deg + 1*chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 2, max_deg ≤ 2): `2*n + 2*max_deg + -1*P_n_maxdeg + -4 >= 0`.
    - Linear combination (`linarith`): `3*max_deg + 2*chi + -2*omega + -3 >= 0`.
