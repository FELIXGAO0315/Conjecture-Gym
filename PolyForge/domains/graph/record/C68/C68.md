# C68

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, n - 2*min_deg <= 0. Then 2*n >= -2*max_deg + tau + 8.

**Formula.** `if ((not_bipartite) and (n - 2*min_deg <= 0)), then (2*n >= -2*max_deg + tau + 8)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-1*n + 2*min_deg >= 0`.
- Linear combination (`linarith`): `1*min_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -2 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*n + 2*max_deg + -1*tau + -8 >= 0`.
