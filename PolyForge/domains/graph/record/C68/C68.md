# C68

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 4. Then 2*tau <= 3*max_deg + 1.

**Formula.** `if ((n <= 4)), then (2*tau <= 3*max_deg + 1)`

## Proof

- Inventory `tau_le_card_sub_one`: `1*n + -1*tau + -1 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*n + 4 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 4, max_deg ≥ 0): `4*max_deg + -1*P_n_maxdeg >= 0`.
- Linear combination (`linarith`): `3*max_deg + -2*tau + 3/2 >= 0`.
- Integer rounding (`omega`): `3*max_deg + -2*tau + 1 >= 0`.
