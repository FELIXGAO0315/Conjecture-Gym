# C84

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 2*chi, min_deg >= 2. Then n <= 3*chi - 2.

**Formula.** `if ((n <= 2*chi) and (min_deg >= 2)), then (n <= 3*chi - 2)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*min_deg + -2 >= 0`.
- Premise: `-1*n + 2*chi >= 0`.
- Linear combination (`linarith`): `-1*n + 3*chi + -3/2 >= 0`.
- Integer rounding (`omega`): `-1*n + 3*chi + -2 >= 0`.
