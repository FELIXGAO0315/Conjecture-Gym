# C134

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, omega >= 1, 2*n - m >= 0. Then radius + 2*girth >= 7.

**Formula.** `if ((is_connected) and (has_cycle) and (omega >= 1) and (2*n - m >= 0)), then (radius + 2*girth >= 7)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + 2*girth + -13/2 >= 0`.
- Integer rounding (`omega`): `1*radius + 2*girth + -7 >= 0`.
