# C145

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, n >= 2*alpha. Then chi <= 3*n - alpha - 5.

**Formula.** `if ((has_cycle) and (n >= 2*alpha)), then (chi <= 3*n - alpha - 5)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Premise: `1*n + -2*alpha >= 0`.
- Linear combination (`linarith`): `3*n + -1*chi + -1*alpha + -9/2 >= 0`.
- Integer rounding (`omega`): `3*n + -1*chi + -1*alpha + -5 >= 0`.
