# C242

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(3), nontrivial, n >= 2*chi. Then m >= 3*chi.

**Formula.** `if ((is_k_edge_connected(3)) and (nontrivial) and (n >= 2*chi)), then (m >= 3*chi)`

## Proof

- Inventory `edge_conn_min_deg`: `1*min_deg + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `1*n + -2*chi >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 3): `-3*n + -1*min_deg + 1*P_n_mindeg + 3 >= 0`.
- Linear combination (`linarith`): `1*m + -3*chi >= 0`.
