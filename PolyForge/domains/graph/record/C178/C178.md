# C178

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 5. Then 2*max_deg >= m - 2.

**Formula.** `if ((n <= 5)), then (2*max_deg >= m - 2)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `edge_card_bound`: `-1*n + -2*m + 1*N2 >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 5): `6*n + -1*N2 + -5 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 5, max_deg ≥ 0): `5*max_deg + -1*P_n_maxdeg >= 0`.
- Linear combination (`linarith`): `-1*m + 2*max_deg + 2 >= 0`.
