# C131

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m - 2*chi >= 0, m >= 5. Then 2*m - omega >= 8.

**Formula.** `if ((m - 2*chi >= 0) and (m >= 5)), then (2*m - omega >= 8)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Premise: `1*m + -5 >= 0`.
- Premise: `1*m + -2*chi >= 0`.
- Linear combination (`linarith`): `2*m + -1*omega + -15/2 >= 0`.
- Integer rounding (`omega`): `2*m + -1*omega + -8 >= 0`.
