# C203

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 2*max_deg. Then m >= 2*max_deg - chi + 1.

**Formula.** `if ((chi >= 2*max_deg)), then (m >= 2*max_deg - chi + 1)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-2*max_deg + 1*chi >= 0`.
- Linear combination (`linarith`): `1*m + -2*max_deg + 1*chi + -1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -2*max_deg + 1*chi + -1 >= 0`.
