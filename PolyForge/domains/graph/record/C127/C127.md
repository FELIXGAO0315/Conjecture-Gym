# C127

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 6. Then chi <= 3*n - m - 2.

**Formula.** `if ((m <= 6)), then (chi <= 3*n - m - 2)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 3: `3*n + -1*m + -1*chi + -2 >= 0`.
  - **Case 1** (`1*n >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `-1*m + 6 >= 0`.
    - Assumption: `1*n + -3 >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 6 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 3, max_deg ≤ 6): `6*n + 3*max_deg + -1*P_n_maxdeg + -18 >= 0`.
    - Linear combination (`linarith`): `3*n + -1*m + -1*chi + -4/3 >= 0`.
    - Integer rounding (`omega`): `3*n + -1*m + -1*chi + -2 >= 0`.
  - **Case 2** (`1*n <= 2`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Assumption: `-1*n + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 2, max_deg ≥ 0): `2*max_deg + -1*P_n_maxdeg >= 0`.
    - Linear combination (`linarith`): `3*n + -1*m + -1*chi + -2 >= 0`.
