# C127

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), is_tree, -omega + 2*tau >= 0, n >= 4. Then chi - tau <= 1.

**Formula.** `if ((is_k_edge_connected(1)) and (is_tree) and (-omega + 2*tau >= 0) and (n >= 4)), then (chi - tau <= 1)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*n + -4 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Premise: `-1*omega + 2*tau >= 0`.
- Linear combination (`linarith`): `-1*chi + 1*tau + 3/2 >= 0`.
- Integer rounding (`omega`): `-1*chi + 1*tau + 1 >= 0`.
