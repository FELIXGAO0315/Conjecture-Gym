# C91

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, max_deg - 2*alpha >= 0, n <= 4. Then -chi + 2*alpha <= -1.

**Formula.** `if ((not_bipartite) and (max_deg - 2*alpha >= 0) and (n <= 4)), then (-chi + 2*alpha <= -1)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `1*max_deg + -2*alpha >= 0`.
- Premise: `-1*n + 4 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `-1*alpha + 3/2 >= 0`.
- Integer rounding (`omega`): `-1*alpha + 1 >= 0`.
- Linear combination (`linarith`): `1*chi + -2*alpha + -1 >= 0`.
