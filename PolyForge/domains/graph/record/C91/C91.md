# C91

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, alpha <= 4. Then diam <= 2*chi + radius - 1.

**Formula.** `if ((is_connected) and (alpha <= 4)), then (diam <= 2*chi + radius - 1)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*alpha + 4 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 4, chi ≥ 1): `4*chi + 1*alpha + -1*P_alpha_chi + -4 >= 0`.
- Linear combination (`linarith`): `2*chi + -1*diam + 1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `2*chi + -1*diam + 1*radius + -1 >= 0`.
