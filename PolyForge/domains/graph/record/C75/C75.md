# C75

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 1, chi >= n. Then m >= -3*max_deg - 2*chi + 8.

**Formula.** `if ((m >= 1) and (chi >= n)), then (m >= -3*max_deg - 2*chi + 8)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + 3*max_deg + 2*chi + -8 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `-1*n + 1*chi >= 0`.
    - Inventory theorem `complete_indep` (via `linarith`): `-1*alpha + 1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*m + 3*max_deg + 2*chi + -8 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*m + -1 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `-1*n + 1*chi >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 1): `1*n + 1*max_deg + -1*P_n_maxdeg + -1 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Linear combination (`linarith`): `-1*n + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 2, max_deg ≥ 0): `2*max_deg + -1*P_n_maxdeg >= 0`.
    - Linear combination (`linarith`): `1*m + 3*max_deg + 2*chi + -8 >= 0`.
