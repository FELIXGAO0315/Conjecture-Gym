# C75

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial. Then max_deg <= 3*m - 3*min_deg + 1.

**Formula.** `if ((is_connected) and (nontrivial)), then (max_deg <= 3*m - 3*min_deg + 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*m + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 2, min_deg ≥ 1): `-1*n + -2*min_deg + 1*P_n_mindeg + 2 >= 0`.
- Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + 1 >= 0`.
