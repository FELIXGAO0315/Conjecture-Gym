# C13

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, n >= 1. Then tau <= n + 2*radius - 3.

**Formula.** `if ((has_cycle) and (is_connected) and (n >= 1)), then (tau <= n + 2*radius - 3)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Premise: `1*n + -1 >= 0`.
- Inventory theorem `tau_le_card_sub_one` (via `linarith`): `1*n + -1*tau + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -1*tau + 2*radius + -3 >= 0`.
