# C34

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 2*n, min_deg >= 2. Then min_deg <= m - 1.

**Formula.** `if ((max_deg <= 2*n) and (min_deg >= 2)), then (min_deg <= m - 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*min_deg + -2 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 2): `-2*n + -1*min_deg + 1*P_n_mindeg + 2 >= 0`.
- Linear combination (`linarith`): `2*m + -2*min_deg + -2 >= 0`.
