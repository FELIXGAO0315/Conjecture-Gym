# C34

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, is_tree, omega - 2*radius >= 0. Then 2*radius <= 2*omega + tau - 2.

**Formula.** `if ((is_acyclic) and (is_tree) and (omega - 2*radius >= 0)), then (2*radius <= 2*omega + tau - 2)`

## Proof

- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Premise: `1*omega + -2*radius >= 0`.
- Linear combination (`linarith`): `2*omega + -2*radius + -1 >= 0`.
- Integer rounding (`omega`): `1*omega + -1*radius + -1 >= 0`.
- Linear combination (`linarith`): `2*omega + 1*tau + -2*radius + -2 >= 0`.
