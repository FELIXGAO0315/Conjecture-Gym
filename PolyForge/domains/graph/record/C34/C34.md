# C34

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, -max_deg + omega >= 0, max_deg <= 3. Then -n + 2*min_deg <= 2.

**Formula.** `if ((has_cycle) and (-max_deg + omega >= 0) and (max_deg <= 3)), then (-n + 2*min_deg <= 2)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*n + -2*min_deg + 2 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Premise: `-1*max_deg + 3 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*min_deg + 2 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Premise: `-1*max_deg + 1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*min_deg + 2 >= 0`.
