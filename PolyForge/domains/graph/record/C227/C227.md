# C227

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), chi <= 2. Then 6*alpha >= 3*n - 4*chi + 8.

**Formula.** `if ((is_regular(3)) and (chi <= 2)), then (6*alpha >= 3*n - 4*chi + 8)`

## Proof

- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `-1*chi + 2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `regular_edges`: `-3*n + 2*m == 0`.
- Linear combination (`linarith`): `1*m + 2*chi + -3*tau + -7/2 >= 0`.
- Integer rounding (`omega`): `1*m + 2*chi + -3*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `6*alpha >= 3*n - 4*chi + 8`.
