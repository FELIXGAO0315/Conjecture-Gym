# C65

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, tau >= 1, -2*m + chi <= 0. Then 2*m >= -alpha + 3.

**Formula.** `if ((is_acyclic) and (tau >= 1) and (-2*m + chi <= 0)), then (2*m >= -alpha + 3)`

## Proof

- Inventory `nonneg_alpha`: `1*alpha >= 0`.
- Premise: `1*tau + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `2*m + -1*chi >= 0`.
- Linear combination (`linarith`): `1*m + -1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Linear combination (`linarith`): `2*m + 1*alpha + -3 >= 0`.
