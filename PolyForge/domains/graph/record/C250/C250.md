# C250

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_connected, m >= 6. Then chi <= 3*m - 3*min_deg - 5.

**Formula.** `if ((nontrivial) and (is_connected) and (m >= 6)), then (chi <= 3*m - 3*min_deg - 5)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 5: `3*m + -3*min_deg + -1*chi + -5 >= 0`.
  - **Case 1** (`1*n >= 5`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
    - Premise: `1*m + -6 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
    - Assumption: `1*n + -5 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 1): `-1*n + -5*min_deg + 1*P_n_mindeg + 5 >= 0`.
    - Linear combination (`linarith`): `3*m + -3*min_deg + -1*chi + -5 >= 0`.
  - **Case 2** (`1*n <= 4`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Premise: `1*m + -6 >= 0`.
    - Assumption: `-1*n + 4 >= 0`.
    - Linear combination (`linarith`): `3*m + -3*min_deg + -1*chi + -5 >= 0`.
