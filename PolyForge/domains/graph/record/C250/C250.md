# C250

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau >= 3, max_deg <= 3. Then m <= 3*n + 3*chi - 15.

**Formula.** `if ((tau >= 3) and (max_deg <= 3)), then (m <= 3*n + 3*chi - 15)`

    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `1*tau + -3 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `-1*max_deg + 3 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 3): `3*n + 1*max_deg + -1*P_n_maxdeg + -3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*n + -1*m + 3*chi + -15 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*tau + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.

    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*alpha + -3 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `-1*max_deg + 3 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 3): `3*n + 1*max_deg + -1*P_n_maxdeg + -3 >= 0`.
