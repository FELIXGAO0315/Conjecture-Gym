## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), nontrivial, m >= 3. Then n <= 3*m - 3*min_deg.

**Formula.** `if ((is_k_edge_connected(1)) and (nontrivial) and (m >= 3)), then (n <= 3*m - 3*min_deg)`

    - Premise: `1*m + -3 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `edge_conn_min_deg`: `1*min_deg + -1 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.

    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 1): `-1*n + -3*min_deg + 1*P_n_mindeg + 3 >= 0`.
    - Linear combination (`linarith`): `-1*n + 3*m + -3*min_deg >= 0`.
