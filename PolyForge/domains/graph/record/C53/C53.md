# C53

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 6, n <= 4. Then 2*min_deg <= m + 1.

**Formula.** `if ((m <= 6) and (n <= 4)), then (2*min_deg <= m + 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `-1*n + 4 >= 0`.
- Linear combination (`linarith`): `-1*min_deg + 3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≤ 4, min_deg ≤ 3): `-3*n + -4*min_deg + 1*P_n_mindeg + 12 >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + 9/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + 1 >= 0`.
