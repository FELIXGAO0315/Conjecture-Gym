# C53

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle. Then 2*m >= 3*min_deg.

**Formula.** `if ((has_cycle)), then (2*m >= 3*min_deg)`

## Proof

- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*m + -3*min_deg >= 0`.
