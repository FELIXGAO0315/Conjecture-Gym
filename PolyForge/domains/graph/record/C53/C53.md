# C53

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 5, alpha >= 3. Then 2*chi >= -3*alpha + 13.

**Formula.** `if ((n >= 5) and (alpha >= 3)), then (2*chi >= -3*alpha + 13)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*chi + 3*alpha + -13 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*alpha + -3 >= 0`.
    - Linear combination (`linarith`): `2*chi + 3*alpha + -15 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*alpha + -3 >= 0`.
    - Premise: `1*n + -5 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.
    - Linear combination (`linarith`): `2*chi + 3*alpha + -37/3 >= 0`.
    - Integer rounding (`omega`): `2*chi + 3*alpha + -13 >= 0`.
