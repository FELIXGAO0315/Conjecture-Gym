# C69

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg >= 4. Then max_deg <= m - 6.

**Formula.** `if ((min_deg >= 4)), then (max_deg <= m - 6)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*min_deg + -4 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 4): `-4*n + -1*min_deg + 1*P_n_mindeg + 4 >= 0`.
- Linear combination (`linarith`): `1*m + -1*max_deg + -6 >= 0`.
