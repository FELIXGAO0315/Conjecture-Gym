# C95

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, max_deg <= 5. Then m <= 3*n + max_deg - 8.

**Formula.** `if ((not_bipartite) and (max_deg <= 5)), then (m <= 3*n + max_deg - 8)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 5 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 3, max_deg ≤ 5): `5*n + 3*max_deg + -1*P_n_maxdeg + -15 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + 1*max_deg + -8 >= 0`.
