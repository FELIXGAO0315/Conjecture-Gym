## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, diam <= 2. Then 2*diam <= 3*chi + 3*alpha - 6.

**Formula.** `if ((is_connected) and (diam <= 2)), then (2*diam <= 3*chi + 3*alpha - 6)`

## Proof

    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*diam + 2 >= 0`.
    - Linear combination (`linarith`): `3*chi + 3*alpha + -2*diam + -8 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Case split (`by_cases`) on `bnb:chi` at threshold 2: `3*chi + 3*alpha + -2*diam + -6 >= 0`.

        - Assumption: `1*chi + -2 >= 0`.
        - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.

      - **Case 2** (`1*chi <= 1`):
        - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
        - Inventory `nonneg_diam`: `1*diam >= 0`.

        - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.

        - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
