# C44

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= 2. Then 5*alpha >= 3*n - 2*chi + 2.

**Formula.** `if ((tau <= 2)), then (5*alpha >= 3*n - 2*chi + 2)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*chi + 2*alpha + -3*tau + -2 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*tau + 2 >= 0`.
    - Linear combination (`linarith`): `2*chi + 2*alpha + -3*tau + -2 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*tau + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*chi + 2*alpha + -3*tau + -2 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `5*alpha >= 3*n - 2*chi + 2`.
