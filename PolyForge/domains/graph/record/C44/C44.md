# C44

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, omega >= 2. Then 2*min_deg <= 2*n + m - 5.

**Formula.** `if ((not_bipartite) and (omega >= 2)), then (2*min_deg <= 2*n + m - 5)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*n + -2*min_deg + -2 >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*n + 1*m + -2*min_deg + -5 >= 0`.
