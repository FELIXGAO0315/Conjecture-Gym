# C27

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 5, omega <= 3. Then omega - alpha <= 2.

**Formula.** `if ((chi <= 5) and (omega <= 3)), then (omega - alpha <= 2)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-1*omega + 1*alpha + 2 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Premise: `-1*omega + 3 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `tau_le_card_sub_one` (via `linarith`): `1*n + -1*tau + -1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-2*omega + 2*alpha + 4 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `nonneg_alpha`: `1*alpha >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-2*omega + 2*alpha + 4 >= 0`.
