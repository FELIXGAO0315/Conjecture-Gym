# C27

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, max_deg - 2*tau <= 0, tau >= 2. Then tau >= -2*radius + 4.

**Formula.** `if ((has_cycle) and (is_connected) and (max_deg - 2*tau <= 0) and (tau >= 2)), then (tau >= -2*radius + 4)`

## Proof

- Premise: `1*tau + -2 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*tau + 2*radius + -4 >= 0`.
