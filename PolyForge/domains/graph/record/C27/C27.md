# C27

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_k_edge_connected(1), alpha <= 1. Then min_deg <= 3*chi - 5.

**Formula.** `if ((nontrivial) and (is_k_edge_connected(1)) and (alpha <= 1)), then (min_deg <= 3*chi - 5)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `edge_conn_min_deg`: `1*min_deg + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*alpha + 1 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 1, chi ≥ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
- Linear combination (`linarith`): `-1*min_deg + 3*chi + -5 >= 0`.
