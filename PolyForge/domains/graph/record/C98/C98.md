# C98

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, -omega + 2*tau >= 0, omega >= 3. Then n + 2*tau >= 7.

**Formula.** `if ((not_bipartite) and (-omega + 2*tau >= 0) and (omega >= 3)), then (n + 2*tau >= 7)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Premise: `1*omega + -3 >= 0`.
- Premise: `-1*omega + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -2 >= 0`.
- Linear combination (`linarith`): `1*n + 2*tau + -7 >= 0`.
