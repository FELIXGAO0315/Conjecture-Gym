# C98

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 2, m <= 2. Then 2*max_deg >= 3*n - 3*chi - 4.

**Formula.** `if ((alpha <= 2) and (m <= 2)), then (2*max_deg >= 3*n - 3*chi - 4)`

## Proof

- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*alpha + 2 >= 0`.
- Premise: `-1*m + 2 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*n + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 4, max_deg ≥ 0): `4*max_deg + -1*P_n_maxdeg >= 0`.
- Linear combination (`linarith`): `-3*n + 2*max_deg + 3*chi + 4 >= 0`.
