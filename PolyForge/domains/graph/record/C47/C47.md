# C47

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, radius >= 1. Then alpha >= -chi + 3.

**Formula.** `if ((is_connected) and (radius >= 1)), then (alpha >= -chi + 3)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*chi + 1*alpha + -3 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Linear combination (`linarith`): `1*chi + 1*alpha + -4 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Premise: `1*radius + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*chi + 1*alpha + -5/2 >= 0`.
    - Integer rounding (`omega`): `1*chi + 1*alpha + -3 >= 0`.
