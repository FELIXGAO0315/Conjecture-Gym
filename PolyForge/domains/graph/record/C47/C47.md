# C47

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, chi <= 2. Then m >= 2*tau - 1.

**Formula.** `if ((is_connected) and (chi <= 2)), then (m >= 2*tau - 1)`

## Proof

- Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 2 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*m + -2*tau + 1 >= 0`.
