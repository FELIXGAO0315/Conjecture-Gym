# C45

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, -max_deg + girth >= 0, min_deg <= 3. Then diam + 2*radius >= 3.

**Formula.** `if ((is_connected) and (has_cycle) and (-max_deg + girth >= 0) and (min_deg <= 3)), then (diam + 2*radius >= 3)`

## Proof

- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*diam + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*diam + 2*radius + -3 >= 0`.
