# C45

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, chi >= 6, m - 2*tau >= 0. Then tau <= 2*n + 2*radius - 9.

**Formula.** `if ((is_connected) and (has_cycle) and (chi >= 6) and (m - 2*tau >= 0)), then (tau <= 2*n + 2*radius - 9)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*chi + -6 >= 0`.
- Linear combination (`linarith`): `1*n + -6 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*n + -1*tau + 2*radius + -9 >= 0`.
