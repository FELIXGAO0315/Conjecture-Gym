# C150

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, diam >= 3. Then n >= 2*diam - 3*radius + 3.

**Formula.** `if ((is_tree) and (diam >= 3)), then (n >= 2*diam - 3*radius + 3)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `1*diam + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -2*diam + 3*radius + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2*diam + 3*radius + -3 >= 0`.
