# C37

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 3, tau >= m. Then 2*n >= 3*min_deg + 6.

**Formula.** `if ((alpha >= 3) and (tau >= m)), then (2*n >= 3*min_deg + 6)`

## Proof

- Premise: `1*alpha + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `-1*m + 1*tau >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*n + -3*min_deg + -6 >= 0`.
