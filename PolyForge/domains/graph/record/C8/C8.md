# C8

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega <= 2*tau. Then alpha <= 2*n - 3.

**Formula.** `if ((omega <= 2*tau)), then (alpha <= 2*n - 3)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
- Premise: `-1*omega + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*n + -1*alpha + -3 >= 0`.
