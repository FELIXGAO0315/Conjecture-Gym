# C126

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree. Then max_deg <= 3*chi + 3*alpha - 8.

**Formula.** `if ((nontrivial) and (is_tree)), then (max_deg <= 3*chi + 3*alpha - 8)`

## Proof

- Case split (`by_cases`) on `bnb:chi` at threshold 2: `-1*max_deg + 3*chi + 3*alpha + -8 >= 0`.
  - **Case 1** (`1*chi >= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Assumption: `1*chi + -2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 3*chi + 3*alpha + -8 >= 0`.
  - **Case 2** (`1*chi <= 1`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 3*chi + 3*alpha + -8 >= 0`.
