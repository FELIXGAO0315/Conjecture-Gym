# C126

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, girth <= 4, -2*min_deg + girth >= 0. Then -min_deg + 2*girth >= 5.

**Formula.** `if ((has_cycle) and (girth <= 4) and (-2*min_deg + girth >= 0)), then (-min_deg + 2*girth >= 5)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `-2*min_deg + 1*girth >= 0`.
- Linear combination (`linarith`): `-1*min_deg + 2*girth + -9/2 >= 0`.
- Integer rounding (`omega`): `-1*min_deg + 2*girth + -5 >= 0`.
