# C83

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, tau <= 6. Then m >= -3*chi + 2*tau + 3.

**Formula.** `if ((is_connected) and (tau <= 6)), then (m >= -3*chi + 2*tau + 3)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + 3*chi + -2*tau + -3 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Premise: `-1*tau + 6 >= 0`.
    - Linear combination (`linarith`): `1*m + 3*chi + -2*tau + -3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*m + 3*chi + -2*tau + -3 >= 0`.
