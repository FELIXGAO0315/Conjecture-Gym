# C83

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, chi <= 2*omega. Then omega >= 2.

**Formula.** `if ((not_bipartite) and (chi <= 2*omega)), then (omega >= 2)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-1*chi + 2*omega >= 0`.
- Linear combination (`linarith`): `1*omega + -3/2 >= 0`.
- Integer rounding (`omega`): `1*omega + -2 >= 0`.
