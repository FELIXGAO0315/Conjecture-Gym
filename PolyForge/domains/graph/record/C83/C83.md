# C83

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, n >= 5. Then omega <= 2*m - 3*min_deg + 1.

**Formula.** `if ((is_acyclic) and (n >= 5)), then (omega <= 2*m - 3*min_deg + 1)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*m + -3*min_deg + -1*omega + 6/5 >= 0`.
- Integer rounding (`omega`): `2*m + -3*min_deg + -1*omega + 1 >= 0`.
