# C57

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 2*tau, max_deg <= 4. Then max_deg <= -2*n + 4*alpha.

**Formula.** `if ((alpha >= 2*tau) and (max_deg <= 4)), then (max_deg <= -2*n + 4*alpha)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*alpha + -2*tau >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*max_deg + 2*alpha + -2*tau + 2/3 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 2*alpha + -2*tau >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `max_deg <= -2*n + 4*alpha`.
