# C57

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 3, chi <= 5. Then m <= n.

**Formula.** `if ((m <= 3) and (chi <= 5)), then (m <= n)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*m + 3 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 3 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 3): `3*n + 1*max_deg + -1*P_n_maxdeg + -3 >= 0`.
- Linear combination (`linarith`): `2*n + -2*m + 1 >= 0`.
- Integer rounding (`omega`): `1*n + -1*m >= 0`.
