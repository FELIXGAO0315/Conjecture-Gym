# C1

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, n <= 5, radius <= 5. Then tau <= 3*max_deg.

**Formula.** `if ((is_tree) and (n <= 5) and (radius <= 5)), then (tau <= 3*max_deg)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 5, max_deg ≥ 0): `5*max_deg + -1*P_n_maxdeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `3*max_deg + -1*tau >= 0`.
