# C238

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, max_deg <= 4. Then max_deg >= -2*n + m + 4.

**Formula.** `if ((not_bipartite) and (max_deg <= 4)), then (max_deg >= -2*n + m + 4)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 3, max_deg ≤ 4): `4*n + 3*max_deg + -1*P_n_maxdeg + -12 >= 0`.
- Linear combination (`linarith`): `2*n + -1*m + 1*max_deg + -4 >= 0`.
