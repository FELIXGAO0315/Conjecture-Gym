# C54

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 5, max_deg <= 2*omega. Then m >= max_deg - chi + 3.

**Formula.** `if ((m >= 5) and (max_deg <= 2*omega)), then (m >= max_deg - chi + 3)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `1*m + -5 >= 0`.
- Premise: `-1*max_deg + 2*omega >= 0`.
- Linear combination (`linarith`): `1*m + -1*max_deg + 1*chi + -5/2 >= 0`.
- Integer rounding (`omega`): `1*m + -1*max_deg + 1*chi + -3 >= 0`.
