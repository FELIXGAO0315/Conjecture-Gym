# C54

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, chi - 2*tau <= 0, chi <= 4. Then min_deg <= 2*n + 2*tau - 8.

**Formula.** `if ((not_bipartite) and (chi - 2*tau <= 0) and (chi <= 4)), then (min_deg <= 2*n + 2*tau - 8)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Premise: `-1*chi + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -2 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*n + -1*min_deg + 2*tau + -8 >= 0`.
