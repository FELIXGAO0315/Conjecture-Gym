# C54

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, -n + 2*max_deg >= 0, alpha <= 5. Then -m - max_deg + 2*alpha <= 4.

**Formula.** `if ((is_bipartite) and (-n + 2*max_deg >= 0) and (alpha <= 5)), then (-m - max_deg + 2*alpha <= 4)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Premise: `-1*n + 2*max_deg >= 0`.
- Premise: `-1*alpha + 5 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*m + -2*alpha + 15/2 >= 0`.
- Integer rounding (`omega`): `1*m + -2*alpha + 7 >= 0`.
- Linear combination (`linarith`): `1*m + 1*max_deg + -2*alpha + 14/3 >= 0`.
- Integer rounding (`omega`): `1*m + 1*max_deg + -2*alpha + 4 >= 0`.
