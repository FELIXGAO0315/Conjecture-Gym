# C54

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= omega, alpha <= 2*tau. Then omega <= 3*n - 2*alpha - 3.

**Formula.** `if ((max_deg >= omega) and (alpha <= 2*tau)), then (omega <= 3*n - 2*alpha - 3)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
- Premise: `1*max_deg + -1*omega >= 0`.
- Premise: `-1*alpha + 2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*omega + 1*alpha + 3*tau + -7/3 >= 0`.
- Integer rounding (`omega`): `-1*omega + 1*alpha + 3*tau + -3 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `omega <= 3*n - 2*alpha - 3`.
