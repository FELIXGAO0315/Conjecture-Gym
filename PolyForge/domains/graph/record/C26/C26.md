# C26

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 3. Then tau <= 3*chi - 3.

**Formula.** `if ((alpha <= 3)), then (tau <= 3*chi - 3)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-1*alpha + 3 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 3, chi ≥ 1): `3*chi + 1*alpha + -1*P_alpha_chi + -3 >= 0`.
- Linear combination (`linarith`): `-1*n + 3*chi + 1*alpha + -3 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `tau <= 3*chi - 3`.
