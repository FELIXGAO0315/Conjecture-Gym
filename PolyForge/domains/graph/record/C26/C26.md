# C26

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 3, alpha >= 2*omega. Then chi >= -alpha + 4.

**Formula.** `if ((n >= 3) and (alpha >= 2*omega)), then (chi >= -alpha + 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*n + 1*chi + -1*tau + -4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Premise: `-2*omega + 1*alpha >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*n + 1*chi + -1*tau + -5 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*n + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Premise: `-2*omega + 1*alpha >= 0`.
    - Linear combination (`linarith`): `1*alpha + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*n + 1*chi + -1*tau + -7/2 >= 0`.
    - Integer rounding (`omega`): `1*n + 1*chi + -1*tau + -4 >= 0`.
