# C26

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial, m >= 2, chi <= 2. Then min_deg <= 2*m - 3.

**Formula.** `if ((is_connected) and (nontrivial) and (m >= 2) and (chi <= 2)), then (min_deg <= 2*m - 3)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*m + -2 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 2, min_deg ≥ 1): `-1*n + -2*min_deg + 1*P_n_mindeg + 2 >= 0`.
- Linear combination (`linarith`): `2*m + -1*min_deg + -7/3 >= 0`.
- Integer rounding (`omega`): `2*m + -1*min_deg + -3 >= 0`.
