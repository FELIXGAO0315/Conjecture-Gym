# C26

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, -2*max_deg + omega <= 0, alpha <= 6. Then tau <= 2*m + 2*max_deg - 3.

**Formula.** `if ((is_tree) and (-2*max_deg + omega <= 0) and (alpha <= 6)), then (tau <= 2*m + 2*max_deg - 3)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Premise: `2*max_deg + -1*omega >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*m + -1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `2*m + -1*tau + -1 >= 0`.
- Linear combination (`linarith`): `2*m + 2*max_deg + -1*tau + -3 >= 0`.
