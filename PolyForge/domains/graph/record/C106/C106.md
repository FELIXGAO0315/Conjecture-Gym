# C106

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, n >= 5. Then alpha >= -m + 2*min_deg + 4.

**Formula.** `if ((is_acyclic) and (n >= 5)), then (alpha >= -m + 2*min_deg + 4)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*n + -5 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `1*alpha + -5/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*m + 1*alpha + -5 >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + 1*alpha + -17/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + 1*alpha + -4 >= 0`.
