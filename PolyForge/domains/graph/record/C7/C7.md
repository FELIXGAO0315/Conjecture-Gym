# C7

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, m <= 4. Then 2*alpha >= m - 2*tau + 2.

**Formula.** `if ((is_bipartite) and (m <= 4)), then (2*alpha >= m - 2*tau + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*m + 4 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*m + 2*alpha + 2*tau + -6/5 >= 0`.
- Integer rounding (`omega`): `-1*m + 2*alpha + 2*tau + -2 >= 0`.
