# C7

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_connected, max_deg >= 3, min_deg >= 2*alpha. Then chi <= 2*max_deg + 2*tau - 8.

**Formula.** `if ((nontrivial) and (is_connected) and (max_deg >= 3) and (min_deg >= 2*alpha)), then (chi <= 2*max_deg + 2*tau - 8)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Premise: `1*max_deg + -3 >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*min_deg + -2*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*tau + -5/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -3 >= 0`.
- Linear combination (`linarith`): `2*max_deg + -1*chi + 2*tau + -15/2 >= 0`.
- Integer rounding (`omega`): `2*max_deg + -1*chi + 2*tau + -8 >= 0`.
