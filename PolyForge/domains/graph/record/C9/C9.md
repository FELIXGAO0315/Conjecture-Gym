# C9

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= 3. Then 4*alpha >= 2*n - 3*chi + 5.

**Formula.** `if ((tau <= 3)), then (4*alpha >= 2*n - 3*chi + 5)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*chi + 2*alpha + -2*tau + -5 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*tau + 3 >= 0`.
    - Linear combination (`linarith`): `3*chi + 2*alpha + -2*tau + -5 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*chi + 2*alpha + -2*tau + -5 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `4*alpha >= 2*n - 3*chi + 5`.
