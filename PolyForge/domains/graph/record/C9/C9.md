# C9

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, is_tree, -2*m + omega >= 0. Then 2*max_deg <= 2*chi + diam - 2.

**Formula.** `if ((is_connected) and (is_tree) and (-2*m + omega >= 0)), then (2*max_deg <= 2*chi + diam - 2)`

## Proof

- Inventory `nonneg_diam`: `1*diam >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `-2*m + 1*omega >= 0`.
- Linear combination (`linarith`): `-2*max_deg + 2*chi + -1 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 1*chi + -1 >= 0`.
- Linear combination (`linarith`): `-2*max_deg + 2*chi + 1*diam + -2 >= 0`.
