# C113

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha >= 3. Then 2*radius >= -3*alpha + 2*diam + 5.

**Formula.** `if ((is_tree) and (alpha >= 3)), then (2*radius >= -3*alpha + 2*diam + 5)`

## Proof

- Case split (`by_cases`) on `bnb:radius` at threshold 3: `3*alpha + -2*diam + 2*radius + -5 >= 0`.
  - **Case 1** (`1*radius >= 3`):
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Assumption: `1*radius + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `1*alpha + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.
    - Linear combination (`linarith`): `3*alpha + -2*diam + 2*radius + -9/2 >= 0`.
    - Integer rounding (`omega`): `3*alpha + -2*diam + 2*radius + -5 >= 0`.
  - **Case 2** (`1*radius <= 2`):
    - Premise: `1*alpha + -3 >= 0`.
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Assumption: `-1*radius + 2 >= 0`.
    - Linear combination (`linarith`): `3*alpha + -2*diam + 2*radius + -5 >= 0`.
