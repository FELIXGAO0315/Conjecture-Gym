# C253

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), tau <= 2, omega >= alpha. Then n >= -omega + 6.

**Formula.** `if ((is_regular(2)) and (tau <= 2) and (omega >= alpha)), then (n >= -omega + 6)`

## Proof

- Case split (`by_cases`) on `omega` at threshold 3: `3*m + 1*min_deg + 3*omega + -20 >= 0`.
  - **Case 1** (`1*omega >= 3`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Assumption: `1*omega + -3 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Inventory `regular_min`: `1*min_deg + -2 == 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `3*m + 1*min_deg + 3*omega + -20 >= 0`.
  - **Case 2** (`1*omega <= 2`):
    - Premise: `-1*tau + 2 >= 0`.
    - Premise: `1*omega + -1*alpha >= 0`.
    - Assumption: `-1*omega + 2 >= 0`.
    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 3, n ≤ 4): `7*n + -1*N2 + -12 >= 0`.
    - Inventory `regular_min`: `1*min_deg + -2 == 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `3*m + 1*min_deg + 3*omega + -20 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `n >= -omega + 6`.
