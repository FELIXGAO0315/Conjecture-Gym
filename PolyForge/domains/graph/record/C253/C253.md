# C253

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 4, tau >= 1. Then max_deg >= -2*n + m + 4.

**Formula.** `if ((max_deg <= 4) and (tau >= 1)), then (max_deg >= -2*n + m + 4)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*tau + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 2, max_deg ≤ 4): `4*n + 2*max_deg + -1*P_n_maxdeg + -8 >= 0`.
- Linear combination (`linarith`): `2*n + -1*m + 1*max_deg + -4 >= 0`.
