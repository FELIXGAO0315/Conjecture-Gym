# C193

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, n <= 6. Then alpha >= 3*m - 2*chi - 20.

**Formula.** `if ((is_bipartite) and (n <= 6)), then (alpha >= 3*m - 2*chi - 20)`

## Proof

- Inventory `bipartite_edges`: `-4*m + 1*N2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*n + 6 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 6): `7*n + -1*N2 + -6 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `-1*m + 9 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*alpha + 6 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 6, chi ≥ 1): `6*chi + 1*alpha + -1*P_alpha_chi + -6 >= 0`.
- Linear combination (`linarith`): `-3*m + 2*chi + 1*alpha + 229/11 >= 0`.
- Integer rounding (`omega`): `-3*m + 2*chi + 1*alpha + 20 >= 0`.
