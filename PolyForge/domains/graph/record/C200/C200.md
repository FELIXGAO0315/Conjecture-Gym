# C200

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 2*omega, alpha <= 3. Then chi >= 3*alpha - 7.

**Formula.** `if ((alpha <= 2*omega) and (alpha <= 3)), then (chi >= 3*alpha - 7)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Premise: `2*omega + -1*alpha >= 0`.
- Premise: `-1*alpha + 3 >= 0`.
- Linear combination (`linarith`): `1*chi + -3*alpha + 15/2 >= 0`.
- Integer rounding (`omega`): `1*chi + -3*alpha + 7 >= 0`.
