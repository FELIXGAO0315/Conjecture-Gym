# C200

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 2*chi, tau <= 1. Then 2*chi >= -3*max_deg + 3*tau + 2.

**Formula.** `if ((n <= 2*chi) and (tau <= 1)), then (2*chi >= -3*max_deg + 3*tau + 2)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*max_deg + 2*chi + -3*tau + -2 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `-1*tau + 1 >= 0`.
    - Linear combination (`linarith`): `3*max_deg + 2*chi + -3*tau + -3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*n + 2*chi >= 0`.
    - Premise: `-1*tau + 1 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 4, max_deg ≥ 0): `4*max_deg + -1*P_n_maxdeg >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*max_deg + 2*chi + -3*tau + -7/6 >= 0`.
    - Integer rounding (`omega`): `3*max_deg + 2*chi + -3*tau + -2 >= 0`.
