# C41

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, alpha >= 3, -2*max_deg + chi <= 0. Then min_deg >= -2*max_deg + 4.

**Formula.** `if ((not_bipartite) and (alpha >= 3) and (-2*max_deg + chi <= 0)), then (min_deg >= -2*max_deg + 4)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -2 >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Linear combination (`linarith`): `2*max_deg + 1*min_deg + -4 >= 0`.
