# C41

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 3. Then n >= 2*max_deg - 3*alpha + 2.

**Formula.** `if ((chi <= 3)), then (n >= 2*max_deg - 3*alpha + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 3 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 3): `1*chi + 3*alpha + -1*P_alpha_chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -2*max_deg + 3*alpha + -2 >= 0`.
