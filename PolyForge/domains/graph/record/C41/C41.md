# C41

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial, diam >= 5, radius <= 3. Then min_deg + 2*radius >= 7.

**Formula.** `if ((is_connected) and (nontrivial) and (diam >= 5) and (radius <= 3)), then (min_deg + 2*radius >= 7)`

## Proof

- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -5 >= 0`.
- Linear combination (`linarith`): `1*radius + -5/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -3 >= 0`.
- Linear combination (`linarith`): `1*min_deg + 2*radius + -7 >= 0`.
