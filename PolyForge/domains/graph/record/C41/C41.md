# C41

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, n >= 2*chi. Then omega <= m - min_deg.

**Formula.** `if ((is_connected) and (has_cycle) and (n >= 2*chi)), then (omega <= m - min_deg)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `conn_cycle_edges`: `-1*n + 1*m >= 0`.
- Inventory `cycle_three_le_edges`: `1*m + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `1*n + -2*chi >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 1): `-1*n + -3*min_deg + 1*P_n_mindeg + 3 >= 0`.
- Linear combination (`linarith`): `1*m + -1*min_deg + -1*omega + 1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -1*min_deg + -1*omega >= 0`.
