# C41

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree, tau <= 2, alpha <= 6. Then m <= max_deg + alpha - 1.

**Formula.** `if ((nontrivial) and (is_tree) and (tau <= 2) and (alpha <= 6)), then (m <= max_deg + alpha - 1)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*tau + 2 >= 0`.
- Premise: `-1*alpha + 6 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*n + 8 >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 8, max_deg ≥ 1): `1*n + 8*max_deg + -1*P_n_maxdeg + -8 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `-1*m + 1*max_deg + 1*alpha + -1/8 >= 0`.
- Integer rounding (`omega`): `-1*m + 1*max_deg + 1*alpha + -1 >= 0`.
