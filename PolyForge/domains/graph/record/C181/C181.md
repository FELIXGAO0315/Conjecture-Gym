# C181

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle. Then chi <= 2*m - 3*min_deg + 3.

**Formula.** `if ((is_connected) and (has_cycle)), then (chi <= 2*m - 3*min_deg + 3)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 1): `-1*n + -3*min_deg + 1*P_n_mindeg + 3 >= 0`.
- Linear combination (`linarith`): `2*m + -3*min_deg + -1*chi + 3 >= 0`.
