# C73

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, nontrivial. Then radius <= 3*chi + 3*alpha - 8.

**Formula.** `if ((is_tree) and (nontrivial)), then (radius <= 3*chi + 3*alpha - 8)`

## Proof

- Case split (`by_cases`) on `bnb:alpha` at threshold 2: `3*chi + 3*alpha + -1*radius + -8 >= 0`.
  - **Case 1** (`1*alpha >= 2`):
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Assumption: `1*alpha + -2 >= 0`.
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `3*chi + 3*alpha + -1*radius + -8 >= 0`.
  - **Case 2** (`1*alpha <= 1`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Assumption: `-1*alpha + 1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 1, chi ≥ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
    - Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
    - Linear combination (`linarith`): `3*chi + 3*alpha + -1*radius + -8 >= 0`.
