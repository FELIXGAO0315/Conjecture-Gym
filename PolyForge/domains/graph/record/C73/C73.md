# C73

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, tau >= omega, n <= 2*max_deg. Then omega <= max_deg.

**Formula.** `if ((is_tree) and (tau >= omega) and (n <= 2*max_deg)), then (omega <= max_deg)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `-1*omega + 1*tau >= 0`.
- Premise: `-1*n + 2*max_deg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*max_deg + -1*omega + 1/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -1*omega >= 0`.
