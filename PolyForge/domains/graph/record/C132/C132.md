# C132

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, 2*m - 2*min_deg >= 0, alpha <= 2. Then 2*diam + radius + 2*girth >= 9.

**Formula.** `if ((has_cycle) and (is_connected) and (2*m - 2*min_deg >= 0) and (alpha <= 2)), then (2*diam + radius + 2*girth >= 9)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `2*diam + 1*radius + 2*girth + -17/2 >= 0`.
- Integer rounding (`omega`): `2*diam + 1*radius + 2*girth + -9 >= 0`.
