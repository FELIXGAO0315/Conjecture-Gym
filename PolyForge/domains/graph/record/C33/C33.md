# C33

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, max_deg <= 3, alpha <= 2*n. Then 2*tau >= m - 2*alpha + 2.

**Formula.** `if ((nontrivial) and (max_deg <= 3) and (alpha <= 2*n)), then (2*tau >= m - 2*alpha + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 3 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 3): `3*n + 1*max_deg + -1*P_n_maxdeg + -3 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*m + 2*alpha + 2*tau + -2 >= 0`.
