# C123

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, 2*m - 2*diam >= 0, 2*min_deg - tau >= 0. Then radius + girth >= 4.

**Formula.** `if ((has_cycle) and (is_connected) and (2*m - 2*diam >= 0) and (2*min_deg - tau >= 0)), then (radius + girth >= 4)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + 1*girth + -7/2 >= 0`.
- Integer rounding (`omega`): `1*radius + 1*girth + -4 >= 0`.
