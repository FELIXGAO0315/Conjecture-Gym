# C128

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, is_acyclic, 2*max_deg - tau >= 0, alpha - 2*tau >= 0. Then chi - alpha <= 0.

**Formula.** `if ((is_bipartite) and (is_acyclic) and (2*max_deg - tau >= 0) and (alpha - 2*tau >= 0)), then (chi - alpha <= 0)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*alpha + -2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-2*chi + 2*alpha + 4/3 >= 0`.
- Integer rounding (`omega`): `-1*chi + 1*alpha >= 0`.
