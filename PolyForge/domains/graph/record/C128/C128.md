# C128

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 5, omega >= 2. Then max_deg <= 3*m - 3*min_deg - 2.

**Formula.** `if ((alpha >= 5) and (omega >= 2)), then (max_deg <= 3*m - 3*min_deg - 2)`

## Proof

- Case split (`by_cases`) on `bnb:min_deg` at threshold 1: `3*m + -1*max_deg + -3*min_deg + -2 >= 0`.
  - **Case 1** (`1*min_deg >= 1`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Premise: `1*alpha + -5 >= 0`.
    - Assumption: `1*min_deg + -1 >= 0`.
    - Inventory `nonneg_tau`: `1*tau >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 1): `-1*n + -1*min_deg + 1*P_n_mindeg + 1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*m + -5/2 >= 0`.
    - Integer rounding (`omega`): `1*m + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -5 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 1): `-1*n + -5*min_deg + 1*P_n_mindeg + 5 >= 0`.
    - Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + -12/5 >= 0`.
    - Integer rounding (`omega`): `3*m + -1*max_deg + -3*min_deg + -3 >= 0`.
  - **Case 2** (`1*min_deg <= 0`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Premise: `1*omega + -2 >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Assumption: `-1*min_deg >= 0`.
    - Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + -2 >= 0`.
