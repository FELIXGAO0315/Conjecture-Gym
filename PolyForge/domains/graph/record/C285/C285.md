# C285

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 6, max_deg <= 4. Then 3*max_deg >= -2*n + m + 12.

**Formula.** `if ((alpha >= 6) and (max_deg <= 4)), then (3*max_deg >= -2*n + m + 12)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Premise: `1*alpha + -6 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -6 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 6, max_deg ≤ 4): `4*n + 6*max_deg + -1*P_n_maxdeg + -24 >= 0`.
- Linear combination (`linarith`): `2*n + -1*m + 3*max_deg + -12 >= 0`.
