## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, m <= 2, n >= 2. Then max_deg >= -2*alpha + 3.

**Formula.** `if ((is_acyclic) and (m <= 2) and (n >= 2)), then (max_deg >= -2*alpha + 3)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `1*n + -2 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `-1*m + 2 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 2 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 2, max_deg ≤ 2): `2*n + 2*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*max_deg + 2*alpha + -3 >= 0`.
