# C64

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, min_deg >= 2, n - omega >= 0. Then max_deg >= -2*radius - 2*girth + 10.

**Formula.** `if ((has_cycle) and (is_connected) and (min_deg >= 2) and (n - omega >= 0)), then (max_deg >= -2*radius - 2*girth + 10)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `1*min_deg + -2 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + 2*radius + 2*girth + -10 >= 0`.
