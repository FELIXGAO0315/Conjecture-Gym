# C64

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, chi - 2*tau >= 0, n >= 4. Then 2*chi + omega + 2*alpha >= 11.

**Formula.** `if ((nontrivial) and (chi - 2*tau >= 0) and (n >= 4)), then (2*chi + omega + 2*alpha >= 11)`

## Proof

- Premise: `1*n + -4 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `1*chi + -2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*chi + 2*alpha + -9 >= 0`.
- Integer rounding (`omega`): `1*chi + 1*alpha + -5 >= 0`.
- Linear combination (`linarith`): `2*chi + 1*omega + 2*alpha + -11 >= 0`.
