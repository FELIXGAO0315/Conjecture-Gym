# C215

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 5, chi >= max_deg. Then chi >= -m + 3*min_deg + 1.

**Formula.** `if ((alpha >= 5) and (chi >= max_deg)), then (chi >= -m + 3*min_deg + 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `-1*max_deg + 1*chi >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*alpha + -5 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -3*min_deg + 1*chi + -1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -3*min_deg + 1*chi + -1 >= 0`.
