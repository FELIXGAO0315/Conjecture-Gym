# C55

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 4, omega - 2*tau >= 0. Then max_deg >= -2*chi - 2*alpha + 10.

**Formula.** `if ((n >= 4) and (omega - 2*tau >= 0)), then (max_deg >= -2*chi - 2*alpha + 10)`

## Proof

- Case split (`by_cases`) on `bnb:alpha` at threshold 4: `1*max_deg + 2*chi + 2*alpha + -10 >= 0`.
  - **Case 1** (`1*alpha >= 4`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `1*n + -4 >= 0`.
    - Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
    - Assumption: `1*alpha + -4 >= 0`.
    - Linear combination (`linarith`): `1*max_deg + 2*chi + 2*alpha + -10 >= 0`.
  - **Case 2** (`1*alpha <= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Premise: `1*n + -4 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `1*omega + -2*tau >= 0`.
    - Assumption: `-1*alpha + 3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*max_deg + 2*chi + 2*alpha + -10 >= 0`.
