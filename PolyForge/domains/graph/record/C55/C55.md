# C55

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 2*min_deg, n >= 2. Then n >= min_deg + 2.

**Formula.** `if ((max_deg >= 2*min_deg) and (n >= 2)), then (n >= min_deg + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*n + -2 >= 0`.
- Premise: `1*max_deg + -2*min_deg >= 0`.
- Linear combination (`linarith`): `1*n + -1*min_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*min_deg + -2 >= 0`.
