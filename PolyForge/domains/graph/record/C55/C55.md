# C55

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= min_deg. Then 2*omega <= 3*m + 1.

**Formula.** `if ((alpha <= min_deg)), then (2*omega <= 3*m + 1)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*min_deg + -1*alpha >= 0`.
- Linear combination (`linarith`): `1*min_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 2, min_deg ≥ 1): `-1*n + -2*min_deg + 1*P_n_mindeg + 2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*m + -2*omega + 1 >= 0`.
