# C3

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau >= 2*alpha, n <= 5. Then tau >= 3*m - 26.

**Formula.** `if ((tau >= 2*alpha) and (n <= 5)), then (tau >= 3*m - 26)`

## Proof

- Inventory `edge_card_bound`: `-1*n + -2*m + 1*N2 >= 0`.
- Premise: `-2*alpha + 1*tau >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 5): `6*n + -1*N2 + -5 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-3*m + 1*tau + 80/3 >= 0`.
- Integer rounding (`omega`): `-3*m + 1*tau + 26 >= 0`.
