# C3

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, omega >= 2*alpha. Then 2*min_deg <= m + tau - 1.

**Formula.** `if ((has_cycle) and (omega >= 2*alpha)), then (2*min_deg <= m + tau - 1)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `1*omega + -2*alpha >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + 1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + 1*tau + -1 >= 0`.
