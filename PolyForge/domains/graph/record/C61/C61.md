# C61

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree, max_deg >= 2. Then min_deg <= -m + 3*alpha - 2.

**Formula.** `if ((nontrivial) and (is_tree) and (max_deg >= 2)), then (min_deg <= -m + 3*alpha - 2)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*max_deg + -2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Inventory `tree_min_deg`: `1*min_deg + -1 == 0`.
- Linear combination (`linarith`): `-1*m + -1*min_deg + 3*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `-1*m + -1*min_deg + 3*alpha + -2 >= 0`.
