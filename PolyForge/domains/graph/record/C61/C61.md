# C61

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, diam <= 3. Then radius >= 3*diam - 7.

**Formula.** `if ((is_connected) and (diam <= 3)), then (radius >= 3*diam - 7)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `-1*diam + 3 >= 0`.
- Linear combination (`linarith`): `-3*diam + 1*radius + 15/2 >= 0`.
- Integer rounding (`omega`): `-3*diam + 1*radius + 7 >= 0`.
