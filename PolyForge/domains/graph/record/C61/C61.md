# C61

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= tau, max_deg <= 3. Then max_deg >= m - 3*alpha + 3.

**Formula.** `if ((alpha >= tau) and (max_deg <= 3)), then (max_deg >= m - 3*alpha + 3)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 2: `-1*m + 1*max_deg + 3*alpha + -3 >= 0`.
  - **Case 1** (`1*n >= 2`):
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `1*alpha + -1*tau >= 0`.
    - Premise: `-1*max_deg + 3 >= 0`.
    - Assumption: `1*n + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 2, max_deg ≤ 3): `3*n + 2*max_deg + -1*P_n_maxdeg + -6 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-1*m + 1*max_deg + 3*alpha + -3 >= 0`.
  - **Case 2** (`1*n <= 1`):
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Inventory `edge_card_bound`: `-1*n + -2*m + 1*N2 >= 0`.
    - Assumption: `-1*n + 1 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 1): `2*n + -1*N2 + -1 >= 0`.
    - Linear combination (`linarith`): `-1*m + 1*max_deg + 3*alpha + -3 >= 0`.
