# C61

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, diam >= 1, max_deg >= 1. Then max_deg >= -2*radius + 3.

**Formula.** `if ((is_connected) and (diam >= 1) and (max_deg >= 1)), then (max_deg >= -2*radius + 3)`

## Proof

- Premise: `1*max_deg + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -1 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + 2*radius + -3 >= 0`.
