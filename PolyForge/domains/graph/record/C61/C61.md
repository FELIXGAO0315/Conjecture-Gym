# C61

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree, diam >= 3. Then -chi + 2*omega - 2*radius <= -2.

**Formula.** `if ((nontrivial) and (is_tree) and (diam >= 3)), then (-chi + 2*omega - 2*radius <= -2)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -2 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Linear combination (`linarith`): `1*chi + -2*omega + 2 >= 0`.
- Linear combination (`linarith`): `1*chi + -2*omega + 2*radius + -2 >= 0`.
