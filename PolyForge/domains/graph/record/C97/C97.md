# C97

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega >= 6. Then m >= 3*min_deg.

**Formula.** `if ((omega >= 6)), then (m >= 3*min_deg)`

## Proof

- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*omega + -6 >= 0`.
- Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
- Linear combination (`linarith`): `1*n + -6 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 0): `-6*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -3*min_deg >= 0`.
