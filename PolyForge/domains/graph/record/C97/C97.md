# C97

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial, n <= 6, -2*max_deg + 2*min_deg >= 0. Then -chi + 2*omega - 2*alpha <= 4.

**Formula.** `if ((is_connected) and (nontrivial) and (n <= 6) and (-2*max_deg + 2*min_deg >= 0)), then (-chi + 2*omega - 2*alpha <= 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*chi + -2*omega + 2*alpha + 4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
    - Premise: `-1*n + 6 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 6 >= 0`.
    - Linear combination (`linarith`): `1*chi + -2*omega + 2*alpha + 4 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `nonneg_alpha`: `1*alpha >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `1*chi + -2*omega + 2*alpha + 2 >= 0`.
