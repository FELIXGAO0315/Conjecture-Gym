# C122

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, nontrivial, m <= 3, diam <= 1. Then -min_deg + 2*diam - radius <= 0.

**Formula.** `if ((is_tree) and (nontrivial) and (m <= 3) and (diam <= 1)), then (-min_deg + 2*diam - radius <= 0)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Premise: `-1*diam + 1 >= 0`.
- Linear combination (`linarith`): `1*min_deg + -2*diam + 1*radius + 1/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -2*diam + 1*radius >= 0`.
