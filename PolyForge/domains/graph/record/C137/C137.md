# C137

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(3), has_cycle. Then m >= 3*min_deg - 3.

**Formula.** `if ((is_k_edge_connected(3)) and (has_cycle)), then (m >= 3*min_deg - 3)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `edge_conn_min_deg`: `1*min_deg + -3 >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 3): `-3*n + -3*min_deg + 1*P_n_mindeg + 9 >= 0`.
- Linear combination (`linarith`): `1*m + -3*min_deg + 3 >= 0`.
