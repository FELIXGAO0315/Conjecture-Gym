# C137

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, omega <= 2*alpha. Then alpha >= -chi + omega + 2.

**Formula.** `if ((not_bipartite) and (omega <= 2*alpha)), then (alpha >= -chi + omega + 2)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-1*omega + 2*alpha >= 0`.
- Linear combination (`linarith`): `1*chi + -1*omega + 1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*chi + -1*omega + 1*alpha + -2 >= 0`.
