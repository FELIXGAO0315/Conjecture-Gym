# C18

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, chi - 2*tau >= 0, n >= 4. Then m >= -2*chi - 2*alpha + 10.

**Formula.** `if ((nontrivial) and (chi - 2*tau >= 0) and (n >= 4)), then (m >= -2*chi - 2*alpha + 10)`

## Proof

- Case split (`by_cases`) on `bnb:alpha` at threshold 4: `1*m + 2*chi + 2*alpha + -10 >= 0`.
  - **Case 1** (`1*alpha >= 4`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `1*n + -4 >= 0`.
    - Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
    - Assumption: `1*alpha + -4 >= 0`.
    - Linear combination (`linarith`): `1*m + 2*chi + 2*alpha + -10 >= 0`.
  - **Case 2** (`1*alpha <= 3`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Premise: `1*n + -4 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `1*chi + -2*tau >= 0`.
    - Assumption: `-1*alpha + 3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*m + 2*chi + 2*alpha + -10 >= 0`.
