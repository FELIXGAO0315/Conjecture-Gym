# C262

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, diam <= 5. Then max_deg >= 3*diam - radius - 10.

**Formula.** `if ((is_connected) and (diam <= 5)), then (max_deg >= 3*diam - radius - 10)`

## Proof

- Case split (`by_cases`) on `bnb:max_deg` at threshold 2: `1*max_deg + -3*diam + 1*radius + 10 >= 0`.
  - **Case 1** (`1*max_deg >= 2`):
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Assumption: `1*max_deg + -2 >= 0`.
    - Premise: `-1*diam + 5 >= 0`.
    - Linear combination (`linarith`): `1*max_deg + -3*diam + 1*radius + 21/2 >= 0`.
    - Integer rounding (`omega`): `1*max_deg + -3*diam + 1*radius + 10 >= 0`.
  - **Case 2** (`1*max_deg <= 1`):
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Assumption: `-1*max_deg + 1 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 1): `1*n + 1*max_deg + -1*P_n_maxdeg + -1 >= 0`.
    - Linear combination (`linarith`): `1*max_deg + -3*diam + 1*radius + 3/2 >= 0`.
    - Integer rounding (`omega`): `1*max_deg + -3*diam + 1*radius + 1 >= 0`.
