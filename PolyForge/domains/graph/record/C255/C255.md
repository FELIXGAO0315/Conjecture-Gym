# C255

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 3, n >= 2*alpha. Then tau >= 3*chi - 7.

**Formula.** `if ((chi <= 3) and (n >= 2*alpha)), then (tau >= 3*chi - 7)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `-1*chi + 3 >= 0`.
- Premise: `1*n + -2*alpha >= 0`.
- Linear combination (`linarith`): `1*n + -3*chi + -1*alpha + 15/2 >= 0`.
- Integer rounding (`omega`): `1*n + -3*chi + -1*alpha + 7 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `tau >= 3*chi - 7`.
