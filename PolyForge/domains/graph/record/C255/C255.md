# C255

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 3, alpha >= 4. Then 2*max_deg >= -2*n + m + 8.

**Formula.** `if ((max_deg <= 3) and (alpha >= 4)), then (2*max_deg >= -2*n + m + 8)`

## Proof

- Premise: `1*alpha + -4 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 3 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 4, max_deg ≤ 3): `3*n + 4*max_deg + -1*P_n_maxdeg + -12 >= 0`.
- Linear combination (`linarith`): `2*n + -1*m + 2*max_deg + -8 >= 0`.
