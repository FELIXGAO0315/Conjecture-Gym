# C130

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, 2*max_deg - chi >= 0. Then n + alpha >= 3.

**Formula.** `if ((is_tree) and (2*max_deg - chi >= 0)), then (n + alpha >= 3)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + 1*alpha + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + 1*alpha + -3 >= 0`.
