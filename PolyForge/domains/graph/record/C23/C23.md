# C23

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), n <= 6, 2*chi - tau >= 0. Then tau <= 5.

**Formula.** `if ((is_k_edge_connected(1)) and (n <= 6) and (2*chi - tau >= 0)), then (tau <= 5)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-1*tau + 5 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
    - Premise: `-1*n + 6 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-1*tau + 5 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `2*chi + -1*tau >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*tau + 4 >= 0`.
