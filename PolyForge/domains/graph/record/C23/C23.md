# C23

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), not_bipartite, min_deg >= 4. Then 2*tau <= 3*m - 22.

**Formula.** `if ((is_k_edge_connected(1)) and (not_bipartite) and (min_deg >= 4)), then (2*tau <= 3*m - 22)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*min_deg + -4 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 4): `-4*n + -1*min_deg + 1*P_n_mindeg + 4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*m + -2*tau + -22 >= 0`.
