# C101

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_bipartite, -2*m + alpha >= 0. Then -omega + 2*tau <= -1.

**Formula.** `if ((is_tree) and (is_bipartite) and (-2*m + alpha >= 0)), then (-omega + 2*tau <= -1)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Premise: `-2*m + 1*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*tau + 1/2 >= 0`.
- Integer rounding (`omega`): `-1*tau >= 0`.
- Linear combination (`linarith`): `1*omega + -2*tau + -1 >= 0`.
