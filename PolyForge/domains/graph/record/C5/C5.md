# C5

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, omega >= 2*radius. Then 2*radius <= m + omega - 1.

**Formula.** `if ((is_tree) and (omega >= 2*radius)), then (2*radius <= m + omega - 1)`

## Proof

- Case split (`by_cases`) on `bnb:diam` at threshold 1: `1*m + 1*omega + -2*radius + -1 >= 0`.
  - **Case 1** (`1*diam >= 1`):
    - Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Assumption: `1*diam + -1 >= 0`.
    - Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
    - Integer rounding (`omega`): `1*radius + -1 >= 0`.
    - Premise: `1*omega + -2*radius >= 0`.
    - Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
    - Linear combination (`linarith`): `1*m + 1*omega + -2*radius + -1 >= 0`.
  - **Case 2** (`1*diam <= 0`):
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `nonneg_tau`: `1*tau >= 0`.
    - Assumption: `-1*diam >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
    - Linear combination (`linarith`): `1*m + 1*omega + -2*radius + -1 >= 0`.
