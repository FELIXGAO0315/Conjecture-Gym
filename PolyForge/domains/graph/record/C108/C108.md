# C108

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, 2*min_deg - chi >= 0, n >= 5. Then max_deg + 2*min_deg >= 3.

**Formula.** `if ((nontrivial) and (2*min_deg - chi >= 0) and (n >= 5)), then (max_deg + 2*min_deg >= 3)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Premise: `1*n + -5 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `2*min_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*min_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + 2*min_deg + -3 >= 0`.
