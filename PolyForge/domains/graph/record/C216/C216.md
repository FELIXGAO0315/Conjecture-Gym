# C216

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 2*omega, tau <= alpha. Then alpha >= max_deg - chi + 1.

**Formula.** `if ((max_deg <= 2*omega) and (tau <= alpha)), then (alpha >= max_deg - chi + 1)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `-1*max_deg + 2*omega >= 0`.
- Premise: `1*alpha + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*max_deg + 1*chi + 1*alpha + -1/2 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 1*chi + 1*alpha + -1 >= 0`.
