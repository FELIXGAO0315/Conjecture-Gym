# C189

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), chi <= 5. Then n <= 6*alpha - 2.

**Formula.** `if ((is_regular(3)) and (chi <= 5)), then (n <= 6*alpha - 2)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 5 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 5): `1*chi + 5*alpha + -1*P_alpha_chi + -5 >= 0`.
- Inventory `regular_edges`: `-3*n + 2*m == 0`.
- Linear combination (`linarith`): `1*n + -1*m + 3*alpha + -1/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*m + 3*alpha + -1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `n <= 6*alpha - 2`.
