# C252

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 6, omega >= 5. Then 2*min_deg <= m - 2.

**Formula.** `if ((m >= 6) and (omega >= 5)), then (2*min_deg <= m - 2)`

## Proof

- Premise: `1*m + -6 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*omega + -5 >= 0`.
- Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
- Linear combination (`linarith`): `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + -6/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + -2 >= 0`.
