# C38

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 3. Then max_deg <= 3*chi + alpha - 4.

**Formula.** `if ((alpha <= 3)), then (max_deg <= 3*chi + alpha - 4)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-1*alpha + 3 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 3, chi ≥ 1): `3*chi + 1*alpha + -1*P_alpha_chi + -3 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 3*chi + 1*alpha + -4 >= 0`.
