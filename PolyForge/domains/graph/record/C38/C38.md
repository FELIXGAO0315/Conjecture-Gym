# C38

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, m - 2*min_deg <= 0, alpha <= 2. Then diam >= -2*radius + 3.

**Formula.** `if ((has_cycle) and (is_connected) and (m - 2*min_deg <= 0) and (alpha <= 2)), then (diam >= -2*radius + 3)`

## Proof

- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*diam + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*diam + 2*radius + -3 >= 0`.
