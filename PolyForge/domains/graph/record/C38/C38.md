# C38

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha <= 3. Then max_deg >= 3*diam - 13.

**Formula.** `if ((is_tree) and (alpha <= 3)), then (max_deg >= 3*diam - 13)`

## Proof

- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*alpha + 3 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `-1*diam + 5 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Linear combination (`linarith`): `-1*n + 6 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 6, max_deg ≥ 0): `6*max_deg + -1*P_n_maxdeg >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*max_deg + -3*diam + 40/3 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -3*diam + 13 >= 0`.
