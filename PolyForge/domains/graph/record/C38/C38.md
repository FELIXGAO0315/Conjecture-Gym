# C38

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, max_deg >= omega. Then omega <= -n + 3*alpha.

**Formula.** `if ((is_acyclic) and (max_deg >= omega)), then (omega <= -n + 3*alpha)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*max_deg + -1*omega >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `-1*n + -1*omega + 3*alpha + 1/2 >= 0`.
- Integer rounding (`omega`): `-1*n + -1*omega + 3*alpha >= 0`.
