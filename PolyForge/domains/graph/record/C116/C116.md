# C116

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, -n + 2*max_deg >= 0. Then 2*max_deg + chi >= 7.

**Formula.** `if ((not_bipartite) and (-n + 2*max_deg >= 0)), then (2*max_deg + chi >= 7)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `-1*n + 2*max_deg >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -2 >= 0`.
- Linear combination (`linarith`): `2*max_deg + 1*chi + -7 >= 0`.
