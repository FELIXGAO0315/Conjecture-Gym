# C87

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 2. Then 2*chi >= n.

**Formula.** `if ((alpha <= 2)), then (2*chi >= n)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*alpha + 2 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `-1*n + 2*chi >= 0`.
