# C67

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 2*m. Then n >= m + 1.

**Formula.** `if ((n >= 2*m)), then (n >= m + 1)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Premise: `1*n + -2*m >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*m + 1*alpha + 1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `-1*m + 1*alpha + 1*tau + -1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n >= m + 1`.
