# C67

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, chi >= 4. Then chi >= -2*radius - 2*girth + 12.

**Formula.** `if ((is_connected) and (has_cycle) and (chi >= 4)), then (chi >= -2*radius - 2*girth + 12)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `1*chi + -4 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*chi + 2*radius + 2*girth + -12 >= 0`.
