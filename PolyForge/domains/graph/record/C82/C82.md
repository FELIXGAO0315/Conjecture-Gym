# C82

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, 2*min_deg - alpha >= 0, tau >= 3. Then 2*min_deg + chi >= 5.

**Formula.** `if ((not_bipartite) and (2*min_deg - alpha >= 0) and (tau >= 3)), then (2*min_deg + chi >= 5)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Inventory `nonneg_alpha`: `1*alpha >= 0`.
- Premise: `1*tau + -3 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Premise: `2*min_deg + -1*alpha >= 0`.
- Linear combination (`linarith`): `1*min_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*min_deg + 1*chi + -5 >= 0`.
