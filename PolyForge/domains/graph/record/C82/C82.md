# C82

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, chi <= 2. Then diam >= -2*alpha + 2*radius + 1.

**Formula.** `if ((is_connected) and (chi <= 2)), then (diam >= -2*alpha + 2*radius + 1)`

## Proof

- Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 2 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `2*alpha + 1*diam + -2*radius + -1 >= 0`.
