## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= 4, max_deg >= 2*chi. Then omega <= -n + 4*alpha - 2.

**Formula.** `if ((tau <= 4) and (max_deg >= 2*chi)), then (omega <= -n + 4*alpha - 2)`

  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
