# C50

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, is_connected, -2*min_deg + alpha <= 0, -alpha + diam <= 0. Then 2*radius >= -2*min_deg + diam + 2.

**Formula.** `if ((not_bipartite) and (is_connected) and (-2*min_deg + alpha <= 0) and (-alpha + diam <= 0)), then (2*radius >= -2*min_deg + diam + 2)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Premise: `2*min_deg + -1*alpha >= 0`.
- Linear combination (`linarith`): `1*min_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*min_deg + -1*diam + 2*radius + -2 >= 0`.
