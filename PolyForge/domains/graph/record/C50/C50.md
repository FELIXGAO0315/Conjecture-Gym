# C50

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, is_connected, diam <= 2. Then radius <= -max_deg + 3*alpha - 1.

**Formula.** `if ((is_acyclic) and (is_connected) and (diam <= 2)), then (radius <= -max_deg + 3*alpha - 1)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*diam + 2 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 3*alpha + -1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 3*alpha + -1*radius + -1 >= 0`.
