# C50

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega <= 4, n >= 2*max_deg. Then m >= min_deg + omega - 2.

**Formula.** `if ((omega <= 4) and (n >= 2*max_deg)), then (m >= min_deg + omega - 2)`

## Proof

- Case split (`by_cases`) on `omega` at threshold 3: `1*m + -1*min_deg + -1*omega + 2 >= 0`.
  - **Case 1** (`1*omega >= 3`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Premise: `-1*omega + 4 >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
    - Assumption: `1*omega + -3 >= 0`.
    - Premise: `1*n + -2*max_deg >= 0`.
    - Linear combination (`linarith`): `1*n + -4 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 0): `-4*min_deg + 1*P_n_mindeg >= 0`.
    - Linear combination (`linarith`): `1*m + -1*min_deg + -1*omega + 5/2 >= 0`.
    - Integer rounding (`omega`): `1*m + -1*min_deg + -1*omega + 2 >= 0`.
  - **Case 2** (`1*omega <= 2`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Assumption: `-1*omega + 2 >= 0`.
    - Linear combination (`linarith`): `1*m + -1*min_deg + -1*omega + 2 >= 0`.
