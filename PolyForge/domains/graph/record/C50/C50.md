# C50

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 5, omega >= 2. Then m <= n + 1.

**Formula.** `if ((m <= 5) and (omega >= 2)), then (m <= n + 1)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*m + 5 >= 0`.
- Premise: `1*omega + -2 >= 0`.
- Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 5 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 2, max_deg ≤ 5): `5*n + 2*max_deg + -1*P_n_maxdeg + -10 >= 0`.
- Linear combination (`linarith`): `2*n + -2*m + 26/7 >= 0`.
- Integer rounding (`omega`): `1*n + -1*m + 1 >= 0`.
