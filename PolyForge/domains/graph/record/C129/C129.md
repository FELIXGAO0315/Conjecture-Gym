# C129

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose -omega + 2*tau >= 0, alpha >= 2. Then n >= 3.

**Formula.** `if ((-omega + 2*tau >= 0) and (alpha >= 2)), then (n >= 3)`

## Proof

- Premise: `1*alpha + -2 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Premise: `-1*omega + 2*tau >= 0`.
- Linear combination (`linarith`): `1*n + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + -3 >= 0`.
