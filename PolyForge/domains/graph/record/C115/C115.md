# C115

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= alpha, chi >= n. Then 2*n >= -max_deg + 3*tau + 2.

**Formula.** `if ((tau <= alpha) and (chi >= n)), then (2*n >= -max_deg + 3*tau + 2)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*n + 1*max_deg + -3*tau + -2 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `1*alpha + -1*tau >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 1*max_deg + -3*tau + -3/2 >= 0`.
    - Integer rounding (`omega`): `2*n + 1*max_deg + -3*tau + -2 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Premise: `-1*n + 1*chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 2, max_deg ≥ 0): `2*max_deg + -1*P_n_maxdeg >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 1*max_deg + -3*tau + -2 >= 0`.
