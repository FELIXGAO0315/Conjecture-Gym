# C173

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg >= max_deg, tau <= 2. Then 2*m >= 2*omega + 3*tau - 6.

**Formula.** `if ((min_deg >= max_deg) and (tau <= 2)), then (2*m >= 2*omega + 3*tau - 6)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*m + -2*omega + -3*tau + 6 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Premise: `-1*max_deg + 1*min_deg >= 0`.
    - Premise: `-1*tau + 2 >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
    - Linear combination (`linarith`): `2*m + -2*omega + -3*tau + 20/3 >= 0`.
    - Integer rounding (`omega`): `2*m + -2*omega + -3*tau + 6 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Premise: `-1*tau + 2 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `2*m + -2*omega + -3*tau + 6 >= 0`.
