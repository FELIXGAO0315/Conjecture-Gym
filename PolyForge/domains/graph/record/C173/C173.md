# C173

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, max_deg <= 4. Then chi <= 3*n - m - 2.

**Formula.** `if ((is_bipartite) and (max_deg <= 4)), then (chi <= 3*n - m - 2)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + -1*chi + -3/2 >= 0`.
- Integer rounding (`omega`): `3*n + -1*m + -1*chi + -2 >= 0`.
