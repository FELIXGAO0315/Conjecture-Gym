# C2

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, omega >= 2*m. Then 2*max_deg <= chi + omega - 2.

**Formula.** `if ((is_tree) and (omega >= 2*m)), then (2*max_deg <= chi + omega - 2)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 2: `-2*max_deg + 1*chi + 1*omega + -2 >= 0`.
  - **Case 1** (`1*n >= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Assumption: `1*n + -2 >= 0`.
    - Premise: `-2*m + 1*omega >= 0`.
    - Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
    - Linear combination (`linarith`): `-2*max_deg + 1*chi + 1*omega + -2 >= 0`.
  - **Case 2** (`1*n <= 1`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Assumption: `-1*n + 1 >= 0`.
    - Linear combination (`linarith`): `-2*max_deg + 1*chi + 1*omega + -2 >= 0`.
