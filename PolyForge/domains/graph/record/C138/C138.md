# C138

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 1. Then tau <= 0.

**Formula.** `if ((chi <= 1)), then (tau <= 0)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 1 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
- Linear combination (`linarith`): `-2*n + 2*alpha >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `tau <= 0`.
