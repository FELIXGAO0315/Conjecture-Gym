# C138

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, diam <= girth. Then diam <= radius + 3*girth - 8.

**Formula.** `if ((is_connected) and (has_cycle) and (diam <= girth)), then (diam <= radius + 3*girth - 8)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `-1*diam + 1*girth >= 0`.
- Linear combination (`linarith`): `-1*diam + 1*radius + 3*girth + -15/2 >= 0`.
- Integer rounding (`omega`): `-1*diam + 1*radius + 3*girth + -8 >= 0`.
