# C233

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 2*alpha, n >= 5. Then 2*min_deg <= m + alpha - 4.

**Formula.** `if ((n <= 2*alpha) and (n >= 5)), then (2*min_deg <= m + alpha - 4)`

## Proof

- Premise: `1*n + -5 >= 0`.
- Premise: `-1*n + 2*alpha >= 0`.
- Linear combination (`linarith`): `1*alpha + -5/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -3 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + 1*alpha + -17/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + 1*alpha + -4 >= 0`.
