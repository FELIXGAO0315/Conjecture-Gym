# C143

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 5, tau >= alpha. Then tau >= 3.

**Formula.** `if ((n >= 5) and (tau >= alpha)), then (tau >= 3)`

## Proof

- Premise: `1*n + -5 >= 0`.
- Premise: `-1*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -1*alpha + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*alpha + -3 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `tau >= 3`.
