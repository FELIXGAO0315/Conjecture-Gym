# C52

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_k_edge_connected(2), n >= 5. Then n <= 2*m - 5.

**Formula.** `if ((nontrivial) and (is_k_edge_connected(2)) and (n >= 5)), then (n <= 2*m - 5)`

## Proof

- Inventory `edge_conn_min_deg`: `1*min_deg + -2 >= 0`.
- Premise: `1*n + -5 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 2): `-2*n + -5*min_deg + 1*P_n_mindeg + 10 >= 0`.
- Linear combination (`linarith`): `-1*n + 2*m + -5 >= 0`.
