# C52

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(3), has_cycle, min_deg <= 5, chi - 2*girth <= 0. Then chi <= alpha + 2*girth - 1.

**Formula.** `if ((is_k_edge_connected(3)) and (has_cycle) and (min_deg <= 5) and (chi - 2*girth <= 0)), then (chi <= alpha + 2*girth - 1)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-1*chi + 1*alpha + 2*girth + -1 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
    - Premise: `-1*chi + 2*girth >= 0`.
    - Linear combination (`linarith`): `-1*chi + 1*alpha + 2*girth + -1 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
    - Inventory `nonneg_alpha`: `1*alpha >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*chi + 1*alpha + 2*girth + -4 >= 0`.
