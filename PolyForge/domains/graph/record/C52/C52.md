# C52

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 5, n >= 4. Then 2*alpha >= -chi + 6.

**Formula.** `if ((chi <= 5) and (n >= 4)), then (2*alpha >= -chi + 6)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*chi + 2*alpha + -6 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*n + -4 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*chi + 5 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 5): `1*chi + 5*alpha + -1*P_alpha_chi + -5 >= 0`.
    - Linear combination (`linarith`): `1*chi + 2*alpha + -27/5 >= 0`.
    - Integer rounding (`omega`): `1*chi + 2*alpha + -6 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*n + -4 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*chi + 2*alpha + -6 >= 0`.
