# C52

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 2*max_deg. Then n >= 2*max_deg - chi + 2.

**Formula.** `if ((chi >= 2*max_deg)), then (n >= 2*max_deg - chi + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-2*max_deg + 1*chi >= 0`.
- Linear combination (`linarith`): `1*n + -2*max_deg + 1*chi + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2*max_deg + 1*chi + -2 >= 0`.
