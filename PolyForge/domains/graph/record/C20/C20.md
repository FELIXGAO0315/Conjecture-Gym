# C20

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 6, alpha >= 5. Then chi >= -alpha + 7.

**Formula.** `if ((n >= 6) and (alpha >= 5)), then (chi >= -alpha + 7)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*chi + 1*alpha + -7 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*alpha + -5 >= 0`.
    - Linear combination (`linarith`): `1*chi + 1*alpha + -8 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*alpha + -5 >= 0`.
    - Premise: `1*n + -6 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 5, chi ≤ 2): `5*chi + 2*alpha + -1*P_alpha_chi + -10 >= 0`.
    - Linear combination (`linarith`): `1*chi + 1*alpha + -31/5 >= 0`.
    - Integer rounding (`omega`): `1*chi + 1*alpha + -7 >= 0`.
