# C20

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(3), has_cycle, tau >= 1, min_deg >= 2*girth. Then omega <= 2*m - 35.

**Formula.** `if ((is_k_edge_connected(3)) and (has_cycle) and (tau >= 1) and (min_deg >= 2*girth)), then (omega <= 2*m - 35)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `1*min_deg + -2*girth >= 0`.
- Linear combination (`linarith`): `1*min_deg + -6 >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -7 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 7, min_deg ≥ 6): `-6*n + -7*min_deg + 1*P_n_mindeg + 42 >= 0`.
- Linear combination (`linarith`): `2*m + -1*omega + -35 >= 0`.
