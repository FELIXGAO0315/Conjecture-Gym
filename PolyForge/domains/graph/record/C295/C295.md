# C295

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 2*max_deg. Then 2*max_deg <= 3*chi - 3.

**Formula.** `if ((chi >= 2*max_deg)), then (2*max_deg <= 3*chi - 3)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 2: `-2*max_deg + 3*chi + -3 >= 0`.
  - **Case 1** (`1*n >= 2`):
    - Case split (`by_cases`) on `bnb:max_deg` at threshold 1: `-2*max_deg + 3*chi + -3 >= 0`.
      - **Case 1** (`1*max_deg >= 1`):
        - Assumption: `1*max_deg + -1 >= 0`.
        - Premise: `-2*max_deg + 1*chi >= 0`.
        - Linear combination (`linarith`): `-2*max_deg + 3*chi + -4 >= 0`.
      - **Case 2** (`1*max_deg <= 0`):
        - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
        - Assumption: `-1*max_deg >= 0`.
        - Linear combination (`linarith`): `-2*max_deg + 3*chi + -3 >= 0`.
  - **Case 2** (`1*n <= 1`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Assumption: `-1*n + 1 >= 0`.
    - Linear combination (`linarith`): `-2*max_deg + 3*chi + -3 >= 0`.
