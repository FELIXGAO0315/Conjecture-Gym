# C43

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, n <= 6. Then n >= m - 2*alpha + 3.

**Formula.** `if ((is_bipartite) and (n <= 6)), then (n >= m - 2*alpha + 3)`

## Proof

    - Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `bipartite_edges`: `-4*m + 1*N2 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Premise: `-1*n + 6 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 6): `7*n + -1*N2 + -6 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Assumption: `1*max_deg + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 6, max_deg ≥ 1): `1*n + 6*max_deg + -1*P_n_maxdeg + -6 >= 0`.
    - Linear combination (`linarith`): `1*n + -1*m + 2*alpha + -15/7 >= 0`.
    - Integer rounding (`omega`): `1*n + -1*m + 2*alpha + -3 >= 0`.
  - **Case 2** (`1*max_deg <= 0`):
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Assumption: `-1*max_deg >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 0): `1*max_deg + -1*P_n_maxdeg >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
