# C43

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 3, n >= 5. Then 2*min_deg <= m - 1.

**Formula.** `if ((m >= 3) and (n >= 5)), then (2*min_deg <= m - 1)`

## Proof

- Premise: `1*m + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + -3/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + -1 >= 0`.
