# C205

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, chi <= max_deg. Then 4*alpha >= 2*n - 3*max_deg + 6.

**Formula.** `if ((is_bipartite) and (chi <= max_deg)), then (4*alpha >= 2*n - 3*max_deg + 6)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `1*max_deg + -1*chi >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*alpha + -2*tau >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
- Linear combination (`linarith`): `3*max_deg + 2*alpha + -2*tau + -6 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `4*alpha >= 2*n - 3*max_deg + 6`.
