# C146

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 4, omega <= 2*alpha. Then max_deg >= omega - alpha + 2.

**Formula.** `if ((max_deg >= 4) and (omega <= 2*alpha)), then (max_deg >= omega - alpha + 2)`

## Proof

- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Premise: `1*max_deg + -4 >= 0`.
- Premise: `-1*omega + 2*alpha >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1*omega + 1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -1*omega + 1*alpha + -2 >= 0`.
