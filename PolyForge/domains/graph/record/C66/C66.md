# C66

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 2*omega, tau <= 2. Then 2*chi >= n - 2*alpha + 4.

**Formula.** `if ((alpha >= 2*omega) and (tau <= 2)), then (2*chi >= n - 2*alpha + 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-1*n + 2*chi + 2*alpha + -4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Premise: `-2*omega + 1*alpha >= 0`.
    - Premise: `-1*tau + 2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-1*n + 2*chi + 2*alpha + -6 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Premise: `-2*omega + 1*alpha >= 0`.
    - Linear combination (`linarith`): `1*alpha + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `-1*n + 2*chi + 2*alpha + -4 >= 0`.
