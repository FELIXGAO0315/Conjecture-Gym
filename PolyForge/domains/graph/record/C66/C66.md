# C66

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 3, max_deg >= 2*min_deg. Then n >= min_deg + 3.

**Formula.** `if ((max_deg >= 3) and (max_deg >= 2*min_deg)), then (n >= min_deg + 3)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*max_deg + -3 >= 0`.
- Premise: `1*max_deg + -2*min_deg >= 0`.
- Linear combination (`linarith`): `1*n + -1*min_deg + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*min_deg + -3 >= 0`.
