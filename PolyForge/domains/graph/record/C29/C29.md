# C29

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega >= chi, n >= 4. Then omega >= -2*chi - 3*alpha + 12.

**Formula.** `if ((omega >= chi) and (n >= 4)), then (omega >= -2*chi - 3*alpha + 12)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*chi + 1*omega + 3*alpha + -12 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*chi + 1*omega >= 0`.
    - Linear combination (`linarith`): `2*chi + 1*omega + 3*alpha + -12 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*n + -4 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*chi + 1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*alpha + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `2*chi + 1*omega + 3*alpha + -12 >= 0`.
