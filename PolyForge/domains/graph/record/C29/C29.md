# C29

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, -2*tau + girth <= 0, min_deg - alpha >= 0. Then min_deg <= 2*n + max_deg - 6.

**Formula.** `if ((has_cycle) and (-2*tau + girth <= 0) and (min_deg - alpha >= 0)), then (min_deg <= 2*n + max_deg - 6)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Inventory `nonneg_alpha`: `1*alpha >= 0`.
- Premise: `2*tau + -1*girth >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Linear combination (`linarith`): `1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -2 >= 0`.
- Linear combination (`linarith`): `2*n + 1*max_deg + -1*min_deg + -6 >= 0`.
