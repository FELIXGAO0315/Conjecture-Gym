# C151

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), n >= 2*alpha. Then tau >= 2.

**Formula.** `if ((is_regular(2)) and (n >= 2*alpha)), then (tau >= 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*n + -2*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `regular_max`: `1*max_deg + -2 == 0`.
- Inventory `regular_min`: `1*min_deg + -2 == 0`.
- Linear combination (`linarith`): `1*min_deg + 1*tau + -7/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + 1*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `tau >= 2`.
