# C245

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, omega >= max_deg. Then 2*omega >= -3*n + 3*m + 4.

**Formula.** `if ((is_bipartite) and (omega >= max_deg)), then (2*omega >= -3*n + 3*m + 4)`

## Proof

- Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 1*omega >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 2 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 2): `2*n + 1*max_deg + -1*P_n_maxdeg + -2 >= 0`.
- Linear combination (`linarith`): `3*n + -3*m + 2*omega + -7/2 >= 0`.
- Integer rounding (`omega`): `3*n + -3*m + 2*omega + -4 >= 0`.
