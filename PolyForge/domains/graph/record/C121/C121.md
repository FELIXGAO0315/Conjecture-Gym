# C121

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, min_deg >= 1. Then n >= 2*diam - 3*radius + 2.

**Formula.** `if ((is_tree) and (min_deg >= 1)), then (n >= 2*diam - 3*radius + 2)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `1*min_deg + -1 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*m + -2*diam + 3*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -2*diam + 3*radius + -1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the tree identity `m = n - 1` (`linarith`): `n >= 2*diam - 3*radius + 2`.
