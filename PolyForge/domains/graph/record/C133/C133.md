# C133

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 5, m >= 6. Then n >= 4.

**Formula.** `if ((max_deg <= 5) and (m >= 6)), then (n >= 4)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*m + -6 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 5 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 5): `5*n + 1*max_deg + -1*P_n_maxdeg + -5 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 3, max_deg ≤ 5): `5*n + 3*max_deg + -1*P_n_maxdeg + -15 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*alpha + 2*tau + -15/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + 1*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n >= 4`.
