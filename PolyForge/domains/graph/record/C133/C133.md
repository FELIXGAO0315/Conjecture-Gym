# C133

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_connected, chi - 2*diam >= 0, chi <= 1. Then 2*n - radius >= 2.

**Formula.** `if ((is_tree) and (is_connected) and (chi - 2*diam >= 0) and (chi <= 1)), then (2*n - radius >= 2)`

## Proof

- Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
- Premise: `-1*chi + 1 >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Premise: `1*chi + -2*diam >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `2*n + -1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `2*n + -1*radius + -2 >= 0`.
