# C158

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 3. Then alpha >= -2*m + 2*min_deg + 3.

**Formula.** `if ((n >= 3)), then (alpha >= -2*m + 2*min_deg + 3)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*n + -3 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*m + -2*min_deg + 1*alpha + -7/3 >= 0`.
- Integer rounding (`omega`): `2*m + -2*min_deg + 1*alpha + -3 >= 0`.
