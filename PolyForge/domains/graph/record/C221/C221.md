# C221

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, n >= 4. Then diam <= 3*m + radius - 8.

**Formula.** `if ((is_connected) and (n >= 4)), then (diam <= 3*m + radius - 8)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
- Premise: `1*n + -4 >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Linear combination (`linarith`): `3*m + -1*diam + 1*radius + -15/2 >= 0`.
- Integer rounding (`omega`): `3*m + -1*diam + 1*radius + -8 >= 0`.
