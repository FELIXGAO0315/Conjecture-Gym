# C70

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 5, n <= 2*m. Then min_deg <= 2.

**Formula.** `if ((m <= 5) and (n <= 2*m)), then (min_deg <= 2)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.

- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `-1*m + 5 >= 0`.
- Premise: `-1*n + 2*m >= 0`.
- Linear combination (`linarith`): `-1*n + 10 >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Linear combination (`linarith`): `-1*min_deg + 5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≤ 10, min_deg ≤ 5): `-5*n + -10*min_deg + 1*P_n_mindeg + 50 >= 0`.
- Linear combination (`linarith`): `-1*min_deg + 11/3 >= 0`.
- Integer rounding (`omega`): `-1*min_deg + 3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≤ 10, min_deg ≤ 3): `-3*n + -10*min_deg + 1*P_n_mindeg + 30 >= 0`.
