# C70

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 3, n - 2*max_deg <= 0. Then 2*tau <= 2*n + max_deg - 4.

**Formula.** `if ((chi >= 3) and (n - 2*max_deg <= 0)), then (2*tau <= 2*n + max_deg - 4)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*chi + -3 >= 0`.
- Premise: `-1*n + 2*max_deg >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -2 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*n + 1*max_deg + -2*tau + -4 >= 0`.
