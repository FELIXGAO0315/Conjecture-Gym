# C70

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha >= 3. Then 2*alpha >= n - 3*chi + 6.

**Formula.** `if ((is_tree) and (alpha >= 3)), then (2*alpha >= n - 3*chi + 6)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*alpha + -3 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.
- Linear combination (`linarith`): `-1*n + 3*chi + 2*alpha + -6 >= 0`.
