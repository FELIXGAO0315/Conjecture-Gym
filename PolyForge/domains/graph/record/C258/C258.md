# C258

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, tau <= 1. Then 2*alpha >= 3*diam - 3*radius + 1.

**Formula.** `if ((is_connected) and (tau <= 1)), then (2*alpha >= 3*diam - 3*radius + 1)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `-1*tau + 1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*alpha + -3*diam + 3*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `2*alpha + -3*diam + 3*radius + -1 >= 0`.
