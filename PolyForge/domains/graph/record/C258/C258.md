# C258

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, diam <= 5. Then radius >= 3*diam - 12.

**Formula.** `if ((is_tree) and (diam <= 5)), then (radius >= 3*diam - 12)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `-1*diam + 5 >= 0`.
- Linear combination (`linarith`): `-3*diam + 1*radius + 25/2 >= 0`.
- Integer rounding (`omega`): `-3*diam + 1*radius + 12 >= 0`.
