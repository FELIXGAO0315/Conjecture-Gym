# C40

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_regular(0), diam <= 1, -2*m + tau >= 0. Then -alpha + 2*diam - 2*radius <= -1.

**Formula.** `if ((is_tree) and (is_regular(0)) and (diam <= 1) and (-2*m + tau >= 0)), then (-alpha + 2*diam - 2*radius <= -1)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `-1*diam + 1 >= 0`.
- Linear combination (`linarith`): `-2*diam + 2*radius + 1 >= 0`.
- Integer rounding (`omega`): `-1*diam + 1*radius >= 0`.
- Linear combination (`linarith`): `1*alpha + -2*diam + 2*radius + -1 >= 0`.
