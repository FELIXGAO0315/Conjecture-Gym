# C40

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, -alpha + tau <= 0, n >= 3. Then m >= -2*alpha + 6.

**Formula.** `if ((is_connected) and (-alpha + tau <= 0) and (n >= 3)), then (m >= -2*alpha + 6)`

## Proof

- Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
- Premise: `1*n + -3 >= 0`.
- Linear combination (`linarith`): `1*m + -2 >= 0`.
- Premise: `1*alpha + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -2 >= 0`.
- Linear combination (`linarith`): `1*m + 2*alpha + -6 >= 0`.
