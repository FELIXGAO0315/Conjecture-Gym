# C40

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 3. Then chi <= 3*n - 2*m.

**Formula.** `if ((m <= 3)), then (chi <= 3*n - 2*m)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 3: `3*n + -2*m + -1*chi >= 0`.
  - **Case 1** (`1*n >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*n + -3 >= 0`.
    - Premise: `-1*m + 3 >= 0`.
    - Linear combination (`linarith`): `3*n + -2*m + -1*chi >= 0`.
  - **Case 2** (`1*n <= 2`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Assumption: `-1*n + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 2, max_deg ≥ 0): `2*max_deg + -1*P_n_maxdeg >= 0`.
    - Linear combination (`linarith`): `3*n + -2*m + -1*chi + -2 >= 0`.
