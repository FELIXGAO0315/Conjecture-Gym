# C124

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, diam >= 3, max_deg >= 4. Then max_deg + radius >= 6.

**Formula.** `if ((has_cycle) and (is_connected) and (diam >= 3) and (max_deg >= 4)), then (max_deg + radius >= 6)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*max_deg + -4 >= 0`.
- Premise: `1*diam + -3 >= 0`.
- Linear combination (`linarith`): `1*max_deg + 1*radius + -11/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + 1*radius + -6 >= 0`.
