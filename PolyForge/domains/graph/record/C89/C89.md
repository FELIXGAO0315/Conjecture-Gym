# C89

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 2, alpha <= 4. Then 2*n <= 3*m + 3*chi.

**Formula.** `if ((m >= 2) and (alpha <= 4)), then (2*n <= 3*m + 3*chi)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-2*n + 3*m + 3*chi >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Premise: `1*m + -2 >= 0`.
    - Premise: `-1*alpha + 4 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-2*n + 3*m + 3*chi + -3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Case split (`by_cases`) on `bnb:chi` at threshold 2: `-2*n + 3*m + 3*chi >= 0`.
      - **Case 1** (`1*chi >= 2`):
        - Assumption: `1*chi + -2 >= 0`.
        - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
        - Premise: `1*m + -2 >= 0`.
        - Premise: `-1*alpha + 4 >= 0`.
        - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
        - Linear combination (`linarith`): `-2*n + 3*m + 3*chi >= 0`.
      - **Case 2** (`1*chi <= 1`):
        - Premise: `1*m + -2 >= 0`.
        - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
        - Premise: `-1*alpha + 4 >= 0`.
        - Assumption: `-1*chi + 1 >= 0`.
        - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
        - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 4, chi ≥ 1): `4*chi + 1*alpha + -1*P_alpha_chi + -4 >= 0`.
        - Linear combination (`linarith`): `-2*n + 3*m + 3*chi + -1 >= 0`.
