# C256

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha >= 2*tau. Then radius >= -3*alpha + 2*diam + 3.

**Formula.** `if ((is_tree) and (alpha >= 2*tau)), then (radius >= -3*alpha + 2*diam + 3)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `1*alpha + -2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*alpha + -2*diam + 1*radius + -9/4 >= 0`.
- Integer rounding (`omega`): `3*alpha + -2*diam + 1*radius + -3 >= 0`.
