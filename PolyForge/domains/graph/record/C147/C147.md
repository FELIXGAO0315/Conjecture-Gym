# C147

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega <= 2*max_deg. Then n >= 2.

**Formula.** `if ((omega <= 2*max_deg)), then (n >= 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
- Premise: `2*max_deg + -1*omega >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*alpha + 1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + 1*tau + -2 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n >= 2`.
