## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 2, max_deg <= omega. Then n >= 3.

**Formula.** `if ((m >= 2) and (max_deg <= omega)), then (n >= 3)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*n + 3*alpha + 3*tau + -15 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 3*alpha + 3*tau + -15 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Premise: `1*m + -2 >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Premise: `-1*max_deg + 1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 2): `2*n + 1*max_deg + -1*P_n_maxdeg + -2 >= 0`.
    - Linear combination (`linarith`): `1*n + -7/3 >= 0`.
    - Integer rounding (`omega`): `1*n + -3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 3*alpha + 3*tau + -15 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n >= 3`.
