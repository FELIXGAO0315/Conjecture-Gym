# C90

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, 2*max_deg - 2*tau >= 0, tau >= 2. Then 2*n - alpha + 2*radius >= 7.

**Formula.** `if ((has_cycle) and (is_connected) and (2*max_deg - 2*tau >= 0) and (tau >= 2)), then (2*n - alpha + 2*radius >= 7)`

## Proof

- Inventory `nonneg_alpha`: `1*alpha >= 0`.
- Premise: `1*tau + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `2*n + -1*alpha + 2*radius + -7 >= 0`.
