# C136

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg >= 5. Then 2*max_deg <= 2*m - 3*chi - 2.

**Formula.** `if ((min_deg >= 5)), then (2*max_deg <= 2*m - 3*chi - 2)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*min_deg + -5 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 5): `-5*n + -1*min_deg + 1*P_n_mindeg + 5 >= 0`.
- Linear combination (`linarith`): `2*m + -2*max_deg + -3*chi + -2 >= 0`.
