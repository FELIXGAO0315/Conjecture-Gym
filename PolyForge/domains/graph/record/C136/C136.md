# C136

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 2*tau. Then n <= 2*alpha - 1.

**Formula.** `if ((alpha >= 2*tau)), then (n <= 2*alpha - 1)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*alpha + -2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -2*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2*tau + -1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n <= 2*alpha - 1`.
