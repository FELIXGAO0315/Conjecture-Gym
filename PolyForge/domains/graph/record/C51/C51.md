# C51

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 3. Then max_deg >= -3*n + 2*m + 3.

**Formula.** `if ((max_deg <= 3)), then (max_deg >= -3*n + 2*m + 3)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 3 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 3): `3*n + 1*max_deg + -1*P_n_maxdeg + -3 >= 0`.
- Linear combination (`linarith`): `3*n + -2*m + 1*max_deg + -3 >= 0`.
