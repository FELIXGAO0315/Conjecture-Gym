# C51

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, min_deg >= 1. Then 2*omega <= 3*m - 3*min_deg + 3.

**Formula.** `if ((not_bipartite) and (min_deg >= 1)), then (2*omega <= 3*m - 3*min_deg + 3)`

## Proof

- Case split (`by_cases`) on `bnb:min_deg` at threshold 2: `3*m + -3*min_deg + -2*omega + 3 >= 0`.
  - **Case 1** (`1*min_deg >= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
    - Assumption: `1*min_deg + -2 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 2): `-2*n + -1*min_deg + 1*P_n_mindeg + 2 >= 0`.
    - Linear combination (`linarith`): `1*m + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 2): `-2*n + -3*min_deg + 1*P_n_mindeg + 6 >= 0`.
    - Linear combination (`linarith`): `3*m + -3*min_deg + -2*omega + 3 >= 0`.
  - **Case 2** (`1*min_deg <= 1`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Assumption: `-1*min_deg + 1 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Premise: `1*min_deg + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 1): `-1*n + -1*min_deg + 1*P_n_mindeg + 1 >= 0`.
    - Linear combination (`linarith`): `3*m + -3*min_deg + -2*omega + 7/2 >= 0`.
    - Integer rounding (`omega`): `3*m + -3*min_deg + -2*omega + 3 >= 0`.
