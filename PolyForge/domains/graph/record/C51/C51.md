# C51

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg - omega >= 0, chi <= 4. Then -n + 2*omega <= 3.

**Formula.** `if ((max_deg - omega >= 0) and (chi <= 4)), then (-n + 2*omega <= 3)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*n + -2*omega + 3 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Premise: `1*max_deg + -1*omega >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Premise: `-1*chi + 4 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 4 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*omega + 3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*omega + 2 >= 0`.
