# C259

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 5, tau <= 2*alpha. Then alpha >= 2.

**Formula.** `if ((n >= 5) and (tau <= 2*alpha)), then (alpha >= 2)`

## Proof

- Premise: `1*n + -5 >= 0`.
- Premise: `2*alpha + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*n + -2*tau + -10/3 >= 0`.
- Integer rounding (`omega`): `1*n + -1*tau + -2 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `alpha >= 2`.
