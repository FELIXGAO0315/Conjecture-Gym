## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial, m >= 6. Then diam >= -3*m + 3*min_deg + 10.

**Formula.** `if ((is_connected) and (nontrivial) and (m >= 6)), then (diam >= -3*m + 3*min_deg + 10)`

    - Inventory `radius_ge_one`: `1*radius + -1 >= 0`.

    - Linear combination (`linarith`): `3*m + -3*min_deg + 1*diam + -13 >= 0`.
