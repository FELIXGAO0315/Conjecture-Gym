## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_connected, n >= 5, -2*alpha + 2*tau >= 0. Then n + 2*tau >= 11.

**Formula.** `if ((nontrivial) and (is_connected) and (n >= 5) and (-2*alpha + 2*tau >= 0)), then (n + 2*tau >= 11)`

## Proof

- Premise: `1*n + -5 >= 0`.
- Premise: `-2*alpha + 2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*tau + -5/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -3 >= 0`.
- Linear combination (`linarith`): `1*n + 2*tau + -11 >= 0`.
