# C19

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite. Then 2*alpha >= -3*chi + 2*tau + 5.

**Formula.** `if ((is_bipartite)), then (2*alpha >= -3*chi + 2*tau + 5)`

## Proof

- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*chi + 2*alpha + -2*tau + -5 >= 0`.
