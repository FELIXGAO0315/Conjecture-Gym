# C152

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), tau >= 4. Then 3*n >= 2*alpha + 14.

**Formula.** `if ((is_regular(3)) and (tau >= 4)), then (3*n >= 2*alpha + 14)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*tau + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `regular_min`: `1*min_deg + -3 == 0`.
- Inventory `regular_edges`: `-3*n + 2*m == 0`.
- Linear combination (`linarith`): `1*m + 1*min_deg + -1*alpha + -19/2 >= 0`.
- Integer rounding (`omega`): `1*m + 1*min_deg + -1*alpha + -10 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `3*n >= 2*alpha + 14`.
