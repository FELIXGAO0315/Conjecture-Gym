# C119

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, is_tree, omega - 2*radius >= 0. Then -chi - omega + 2*radius <= -2.

**Formula.** `if ((is_acyclic) and (is_tree) and (omega - 2*radius >= 0)), then (-chi - omega + 2*radius <= -2)`

## Proof

- Case split (`by_cases`) on `bnb:diam` at threshold 1: `1*chi + 1*omega + -2*radius + -2 >= 0`.
  - **Case 1** (`1*diam >= 1`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Assumption: `1*diam + -1 >= 0`.
    - Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
    - Integer rounding (`omega`): `1*radius + -1 >= 0`.
    - Premise: `1*omega + -2*radius >= 0`.
    - Linear combination (`linarith`): `1*chi + 1*omega + -2*radius + -2 >= 0`.
  - **Case 2** (`1*diam <= 0`):
    - Inventory `nonneg_m`: `1*m >= 0`.
    - Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
    - Linear combination (`linarith`): `1*n + -1 >= 0`.
    - Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
    - Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Assumption: `-1*diam >= 0`.
    - Linear combination (`linarith`): `-1*radius >= 0`.
    - Linear combination (`linarith`): `1*chi + 1*omega + -2*radius + -2 >= 0`.
