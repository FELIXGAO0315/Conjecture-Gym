# C56

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, nontrivial, max_deg >= 3. Then min_deg <= 3*m - 8.

**Formula.** `if ((is_acyclic) and (nontrivial) and (max_deg >= 3)), then (min_deg <= 3*m - 8)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `1*max_deg + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 0): `-4*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `3*m + -1*min_deg + -15/2 >= 0`.
- Integer rounding (`omega`): `3*m + -1*min_deg + -8 >= 0`.
