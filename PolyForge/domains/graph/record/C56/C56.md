# C56

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, diam >= 1, -2*m + chi <= 0. Then chi <= 2*m + 2*radius - 2.

**Formula.** `if ((is_connected) and (diam >= 1) and (-2*m + chi <= 0)), then (chi <= 2*m + 2*radius - 2)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -1 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Premise: `2*m + -1*chi >= 0`.
- Linear combination (`linarith`): `2*m + -1*chi + 2*radius + -2 >= 0`.
