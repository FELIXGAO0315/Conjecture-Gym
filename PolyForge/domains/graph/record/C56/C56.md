# C56

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, has_cycle, chi - 2*alpha >= 0, -2*min_deg + omega >= 0. Then 2*min_deg - 2*chi - girth <= -7.

**Formula.** `if ((not_bipartite) and (has_cycle) and (chi - 2*alpha >= 0) and (-2*min_deg + omega >= 0)), then (2*min_deg - 2*chi - girth <= -7)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-2*min_deg + 1*omega >= 0`.
- Linear combination (`linarith`): `-2*min_deg + 2*chi + -3 >= 0`.
- Integer rounding (`omega`): `-1*min_deg + 1*chi + -2 >= 0`.
- Linear combination (`linarith`): `-2*min_deg + 2*chi + 1*girth + -7 >= 0`.
