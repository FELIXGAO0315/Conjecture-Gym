# C49

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, n >= 2*alpha. Then alpha <= 2*n - 5.

**Formula.** `if ((has_cycle) and (n >= 2*alpha)), then (alpha <= 2*n - 5)`

## Proof

- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Premise: `1*n + -2*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*alpha + 2*tau + -9/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + 2*tau + -5 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `alpha <= 2*n - 5`.
