# C49

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, nontrivial, max_deg - girth >= 0, -2*tau + girth <= 0. Then alpha <= 2*n + 2*tau - 10.

**Formula.** `if ((has_cycle) and (nontrivial) and (max_deg - girth >= 0) and (-2*tau + girth <= 0)), then (alpha <= 2*n + 2*tau - 10)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `1*max_deg + -1*girth >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3 >= 0`.
- Premise: `2*tau + -1*girth >= 0`.
- Linear combination (`linarith`): `1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -2 >= 0`.
- Inventory `nonneg_alpha`: `1*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*n + -1*alpha + 2*tau + -10 >= 0`.
