# C49

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, n >= 6, max_deg <= 6. Then 2*min_deg <= m.

**Formula.** `if ((nontrivial) and (n >= 6) and (max_deg <= 6)), then (2*min_deg <= m)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*n + -6 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 0): `-6*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg >= 0`.
