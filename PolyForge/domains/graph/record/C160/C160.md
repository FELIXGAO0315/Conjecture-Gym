# C160

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 5. Then m <= 3*n - 3.

**Formula.** `if ((max_deg <= 5)), then (m <= 3*n - 3)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 5 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 5): `5*n + 1*max_deg + -1*P_n_maxdeg + -5 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + -3 >= 0`.
