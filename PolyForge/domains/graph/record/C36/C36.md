# C36

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, diam >= 3, max_deg >= 4. Then omega <= chi + 2*radius - 4.

**Formula.** `if ((has_cycle) and (is_connected) and (diam >= 3) and (max_deg >= 4)), then (omega <= chi + 2*radius - 4)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -2 >= 0`.
- Linear combination (`linarith`): `1*chi + -1*omega + 2*radius + -4 >= 0`.
