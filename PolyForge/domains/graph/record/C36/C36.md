# C36

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial, alpha <= 1, 2*n - m >= 0. Then 2*n + m + alpha >= 6.

**Formula.** `if ((is_connected) and (nontrivial) and (alpha <= 1) and (2*n - m >= 0)), then (2*n + m + alpha >= 6)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*m + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1 >= 0`.
- Premise: `2*n + -1*m >= 0`.
- Linear combination (`linarith`): `1*n + -1/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*n + 1*m + 1*alpha + -6 >= 0`.
