# C114

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega <= 3. Then 2*m >= 2*min_deg + 3*omega - 7.

**Formula.** `if ((omega <= 3)), then (2*m >= 2*min_deg + 3*omega - 7)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*m + -2*min_deg + -3*omega + 7 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Premise: `-1*omega + 3 >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
    - Linear combination (`linarith`): `2*m + -2*min_deg + -3*omega + 23/3 >= 0`.
    - Integer rounding (`omega`): `2*m + -2*min_deg + -3*omega + 7 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `2*m + -2*min_deg + -3*omega + 6 >= 0`.
