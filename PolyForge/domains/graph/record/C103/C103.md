# C103

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 5. Then 2*tau <= n + 3*alpha.

**Formula.** `if ((chi <= 5)), then (2*tau <= n + 3*alpha)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 5 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 5): `1*chi + 5*alpha + -1*P_alpha_chi + -5 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + 3*alpha + -2*tau >= 0`.
