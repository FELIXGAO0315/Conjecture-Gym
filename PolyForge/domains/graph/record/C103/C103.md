# C103

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 2*alpha, alpha <= 2. Then n <= 2*chi + 2*alpha - 4.

**Formula.** `if ((n >= 2*alpha) and (alpha <= 2)), then (n <= 2*chi + 2*alpha - 4)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*alpha + 2 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `1*n + -2*alpha >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `1*chi + -3/2 >= 0`.
- Integer rounding (`omega`): `1*chi + -2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + 2*chi + -2*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n <= 2*chi + 2*alpha - 4`.
