# C273

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 5, max_deg >= 1. Then m >= 2*min_deg + 1.

**Formula.** `if ((n >= 5) and (max_deg >= 1)), then (m >= 2*min_deg + 1)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `1*max_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + -1/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + -1 >= 0`.
