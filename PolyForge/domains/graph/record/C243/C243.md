# C243

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, tau >= 3. Then alpha >= min_deg - chi + 4.

**Formula.** `if ((is_tree) and (tau >= 3)), then (alpha >= min_deg - chi + 4)`

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.

- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*chi + 1*alpha + -5 >= 0`.
- Linear combination (`linarith`): `1*alpha + -3 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.

- Integer rounding (`omega`): `-1*min_deg + 1*chi + 1*alpha + -4 >= 0`.
