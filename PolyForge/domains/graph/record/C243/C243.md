# C243

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 5, max_deg <= 6. Then 2*max_deg >= -3*n + m + 12.

**Formula.** `if ((n >= 5) and (max_deg <= 6)), then (2*max_deg >= -3*n + m + 12)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 6 >= 0`.
- Premise: `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 5, max_deg ≤ 6): `6*n + 5*max_deg + -1*P_n_maxdeg + -30 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + 2*max_deg + -12 >= 0`.
