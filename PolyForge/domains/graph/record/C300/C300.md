# C300

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), alpha <= 5. Then 2*alpha >= -3*chi + 10.

**Formula.** `if ((is_regular(2)) and (alpha <= 5)), then (2*alpha >= -3*chi + 10)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*chi + 2*alpha + -10 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Linear combination (`linarith`): `3*chi + 2*alpha + -11 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*alpha + 5 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 10 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 3, n ≤ 10): `13*n + -1*N2 + -30 >= 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `1*n + -10/3 >= 0`.
    - Integer rounding (`omega`): `1*n + -4 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 5, chi ≥ 1): `5*chi + 1*alpha + -1*P_alpha_chi + -5 >= 0`.
    - Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*alpha + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `3*chi + 2*alpha + -37/4 >= 0`.
    - Integer rounding (`omega`): `3*chi + 2*alpha + -10 >= 0`.
