# C261

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 2*max_deg. Then chi >= -3*max_deg + 2*omega + 1.

**Formula.** `if ((chi <= 2*max_deg)), then (chi >= -3*max_deg + 2*omega + 1)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `3*max_deg + 1*chi + -2*omega + -1/2 >= 0`.
- Integer rounding (`omega`): `3*max_deg + 1*chi + -2*omega + -1 >= 0`.
