# C48

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= 2*alpha. Then 3*alpha >= n - chi + 3.

**Formula.** `if ((tau <= 2*alpha)), then (3*alpha >= n - chi + 3)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*chi + 2*alpha + -1*tau + -3 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `2*alpha + -1*tau >= 0`.
    - Linear combination (`linarith`): `1*chi + 2*alpha + -1*tau + -3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*chi + 2*alpha + -1*tau + -3 >= 0`.
