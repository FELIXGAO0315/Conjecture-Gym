# C210

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 2, tau >= alpha. Then alpha <= 2*n - 3*max_deg + 1.

**Formula.** `if ((max_deg <= 2) and (tau >= alpha)), then (alpha <= 2*n - 3*max_deg + 1)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `-1*max_deg + 2 >= 0`.
- Premise: `-1*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-3*max_deg + 1*alpha + 2*tau + 3/2 >= 0`.
- Integer rounding (`omega`): `-3*max_deg + 1*alpha + 2*tau + 1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `alpha <= 2*n - 3*max_deg + 1`.
