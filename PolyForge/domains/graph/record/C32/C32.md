# C32

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), nontrivial, alpha <= 6. Then n <= 3*m - 1.

**Formula.** `if ((is_k_edge_connected(1)) and (nontrivial) and (alpha <= 6)), then (n <= 3*m - 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `edge_conn_min_deg`: `1*min_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 1): `-1*n + -1*min_deg + 1*P_n_mindeg + 1 >= 0`.
- Linear combination (`linarith`): `-1*n + 3*m + -1 >= 0`.
