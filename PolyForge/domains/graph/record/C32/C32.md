# C32

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, diam >= 5. Then min_deg <= 3*alpha - diam - 3.

**Formula.** `if ((is_tree) and (diam >= 5)), then (min_deg <= 3*alpha - diam - 3)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `1*diam + -5 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `1*alpha + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Linear combination (`linarith`): `1*n + -6 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 0): `-6*min_deg + 1*P_n_mindeg >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `-1*min_deg + 3*alpha + -1*diam + -7/3 >= 0`.
- Integer rounding (`omega`): `-1*min_deg + 3*alpha + -1*diam + -3 >= 0`.
