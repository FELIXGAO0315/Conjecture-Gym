# C22

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_k_edge_connected(2), chi <= 2*min_deg, n >= 3. Then max_deg <= 2*m - 4.

**Formula.** `if ((nontrivial) and (is_k_edge_connected(2)) and (chi <= 2*min_deg) and (n >= 3)), then (max_deg <= 2*m - 4)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `edge_conn_min_deg`: `1*min_deg + -2 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 2): `-2*n + -3*min_deg + 1*P_n_mindeg + 6 >= 0`.
- Linear combination (`linarith`): `2*m + -1*max_deg + -4 >= 0`.
