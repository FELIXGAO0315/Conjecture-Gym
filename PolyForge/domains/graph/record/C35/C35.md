# C35

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= 6. Then 2*chi <= n + 2*alpha + 5.

**Formula.** `if ((tau <= 6)), then (2*chi <= n + 2*alpha + 5)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*n + -2*chi + 2*alpha + 5 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
    - Premise: `-1*tau + 6 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*n + -2*chi + 2*alpha + 5 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `nonneg_alpha`: `1*alpha >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*chi + 2*alpha + 2 >= 0`.
