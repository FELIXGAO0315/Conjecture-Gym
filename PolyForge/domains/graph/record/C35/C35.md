# C35

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose tau <= 3, n >= 5. Then 2*chi >= -3*alpha + 12.

**Formula.** `if ((tau <= 3) and (n >= 5)), then (2*chi >= -3*alpha + 12)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `2*chi + 3*alpha + -12 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*n + -5 >= 0`.
    - Premise: `-1*tau + 3 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*chi + 3*alpha + -12 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*n + -5 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*alpha + -5/2 >= 0`.
    - Integer rounding (`omega`): `1*alpha + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.
    - Linear combination (`linarith`): `2*chi + 3*alpha + -37/3 >= 0`.
    - Integer rounding (`omega`): `2*chi + 3*alpha + -13 >= 0`.
