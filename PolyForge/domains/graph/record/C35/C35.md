# C35

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 2*omega, max_deg >= 4. Then min_deg <= 2*m - 3*omega - 1.

**Formula.** `if ((max_deg >= 2*omega) and (max_deg >= 4)), then (min_deg <= 2*m - 3*omega - 1)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `1*max_deg + -4 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `1*max_deg + -2*omega >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*m + -1*min_deg + -3*omega + -2/5 >= 0`.
- Integer rounding (`omega`): `2*m + -1*min_deg + -3*omega + -1 >= 0`.
