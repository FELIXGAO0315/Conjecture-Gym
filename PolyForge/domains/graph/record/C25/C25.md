# C25

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, max_deg >= 2, n <= 6. Then omega - alpha - radius <= 4.

**Formula.** `if ((has_cycle) and (is_connected) and (max_deg >= 2) and (n <= 6)), then (omega - alpha - radius <= 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-1*omega + 1*alpha + 1*radius + 4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
    - Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
    - Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
    - Integer rounding (`omega`): `1*radius + -1 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Premise: `-1*n + 6 >= 0`.
    - Linear combination (`linarith`): `-1*chi + 6 >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `tau_le_card_sub_one` (via `linarith`): `1*n + -1*tau + -1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `-1*omega + 1*alpha + 1*radius + 4 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
    - Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
    - Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
    - Inventory `nonneg_alpha`: `1*alpha >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 1*alpha + 1*radius + 3/2 >= 0`.
    - Integer rounding (`omega`): `-1*omega + 1*alpha + 1*radius + 1 >= 0`.
