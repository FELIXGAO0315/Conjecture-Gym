# C24

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, is_connected, diam >= 1. Then max_deg <= 2*n + 2*radius - 6.

**Formula.** `if ((not_bipartite) and (is_connected) and (diam >= 1)), then (max_deg <= 2*n + 2*radius - 6)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -1 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `2*n + -1*max_deg + 2*radius + -6 >= 0`.
