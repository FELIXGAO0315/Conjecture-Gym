# C24

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_bipartite. Then chi >= -2*alpha + girth + 2.

**Formula.** `if ((has_cycle) and (is_bipartite)), then (chi >= -2*alpha + girth + 2)`

## Proof

- Inventory `girth_le_card`: `1*n + -1*girth >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `1*chi + 2*alpha + -1*girth + -2 >= 0`.
