# C88

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg >= 4. Then n >= -m + 3*chi.

**Formula.** `if ((min_deg >= 4)), then (n >= -m + 3*chi)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*min_deg + -4 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 4): `-4*n + -1*min_deg + 1*P_n_mindeg + 4 >= 0`.
- Linear combination (`linarith`): `1*n + 1*m + -3*chi >= 0`.
