# C88

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, is_connected, diam >= 1. Then diam + 2*radius >= 3.

**Formula.** `if ((not_bipartite) and (is_connected) and (diam >= 1)), then (diam + 2*radius >= 3)`

## Proof

- Premise: `1*diam + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*diam + 2*radius + -3 >= 0`.
