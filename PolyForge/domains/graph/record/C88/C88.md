# C88

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 2*chi. Then m >= min_deg - 3*alpha + 6.

**Formula.** `if ((n >= 2*chi)), then (m >= min_deg - 3*alpha + 6)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + -1*min_deg + 3*alpha + -6 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*n + -2*chi >= 0`.
    - Linear combination (`linarith`): `1*n + -6 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 0): `-6*min_deg + 1*P_n_mindeg >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*m + -1*min_deg + 3*alpha + -19/3 >= 0`.
    - Integer rounding (`omega`): `1*m + -1*min_deg + 3*alpha + -7 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `1*n + -2*chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*alpha + -2 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
    - Linear combination (`linarith`): `1*n + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 2, min_deg ≥ 0): `-2*min_deg + 1*P_n_mindeg >= 0`.
    - Linear combination (`linarith`): `1*m + -1*min_deg + 3*alpha + -6 >= 0`.
