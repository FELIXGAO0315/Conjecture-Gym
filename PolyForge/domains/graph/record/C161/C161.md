## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_connected, tau >= 3. Then 2*chi >= -m + 2*min_deg + 6.

**Formula.** `if ((nontrivial) and (is_connected) and (tau >= 3)), then (2*chi >= -m + 2*min_deg + 6)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + -2*min_deg + 2*chi + -6 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `1*tau + -3 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*n + -4 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 1): `-1*n + -4*min_deg + 1*P_n_mindeg + 4 >= 0`.
    - Linear combination (`linarith`): `1*m + -2*min_deg + 2*chi + -6 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
    - Premise: `1*tau + -3 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*alpha + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.
    - Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
    - Linear combination (`linarith`): `1*n + -6 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 6, min_deg ≥ 1): `-1*n + -6*min_deg + 1*P_n_mindeg + 6 >= 0`.
    - Linear combination (`linarith`): `1*m + -2*min_deg + 2*chi + -17/3 >= 0`.
    - Integer rounding (`omega`): `1*m + -2*min_deg + 2*chi + -6 >= 0`.
