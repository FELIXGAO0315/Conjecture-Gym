# C157

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, alpha >= 4. Then omega <= 2*m - 3*min_deg + 1.

**Formula.** `if ((is_acyclic) and (alpha >= 4)), then (omega <= 2*m - 3*min_deg + 1)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Linear combination (`linarith`): `-1*omega + 2 >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*alpha + -4 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 0): `-4*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `2*m + -3*min_deg + -1*omega + 3/2 >= 0`.
- Integer rounding (`omega`): `2*m + -3*min_deg + -1*omega + 1 >= 0`.
