# C71

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, -2*max_deg + chi <= 0, n >= 6. Then min_deg <= 2*max_deg - 1.

**Formula.** `if ((is_bipartite) and (-2*max_deg + chi <= 0) and (n >= 6)), then (min_deg <= 2*max_deg - 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Premise: `1*n + -6 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `2*max_deg + -1*min_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `2*max_deg + -1*min_deg + -1 >= 0`.
