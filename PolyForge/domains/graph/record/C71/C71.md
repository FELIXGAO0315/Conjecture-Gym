# C71

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 1. Then max_deg >= 2*min_deg - alpha + 1.

**Formula.** `if ((chi <= 1)), then (max_deg >= 2*min_deg - alpha + 1)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 1 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + -2*min_deg + 1*alpha + -1 >= 0`.
