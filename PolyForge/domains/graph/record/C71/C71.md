# C71

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), omega >= chi. Then n >= m - 2*alpha.

**Formula.** `if ((is_regular(3)) and (omega >= chi)), then (n >= m - 2*alpha)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Premise: `-1*chi + 1*omega >= 0`.
- Inventory `regular_max`: `1*max_deg + -3 == 0`.
- Linear combination (`linarith`): `-1*chi + 4 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 4): `1*chi + 4*alpha + -1*P_alpha_chi + -4 >= 0`.
- Inventory `regular_edges`: `-3*n + 2*m == 0`.
- Linear combination (`linarith`): `1*n + -1*m + 2*alpha >= 0`.
