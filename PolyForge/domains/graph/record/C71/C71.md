## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_connected, tau <= 1. Then diam <= 3*chi + 3*alpha - 8.

**Formula.** `if ((nontrivial) and (is_connected) and (tau <= 1)), then (diam <= 3*chi + 3*alpha - 8)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*chi + 3*alpha + -1*diam + -8 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Premise: `-1*tau + 1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*chi + 3*alpha + -1*diam + -13 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Case split (`by_cases`) on `bnb:alpha` at threshold 2: `3*chi + 3*alpha + -1*diam + -8 >= 0`.
      - **Case 1** (`1*alpha >= 2`):
        - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
        - Assumption: `1*alpha + -2 >= 0`.
        - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
        - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.

        - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
        - Linear combination (`linarith`): `3*chi + 3*alpha + -1*diam + -8 >= 0`.
      - **Case 2** (`1*alpha <= 1`):
        - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
        - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
        - Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
        - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
        - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
        - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
        - Assumption: `-1*alpha + 1 >= 0`.
        - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 1, chi ≥ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
        - Linear combination (`linarith`): `3*chi + 3*alpha + -1*diam + -8 >= 0`.
