# C28

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega - 2*alpha <= 0, omega >= 3. Then omega >= -2*alpha + 7.

**Formula.** `if ((omega - 2*alpha <= 0) and (omega >= 3)), then (omega >= -2*alpha + 7)`

## Proof

- Premise: `1*omega + -3 >= 0`.
- Premise: `-1*omega + 2*alpha >= 0`.
- Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -2 >= 0`.
- Linear combination (`linarith`): `1*omega + 2*alpha + -7 >= 0`.
