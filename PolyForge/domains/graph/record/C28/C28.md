# C28

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, is_tree, -2*m + omega >= 0. Then 2*chi - 2*omega - alpha <= -1.

**Formula.** `if ((is_connected) and (is_tree) and (-2*m + omega >= 0)), then (2*chi - 2*omega - alpha <= -1)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Premise: `-2*m + 1*omega >= 0`.
- Linear combination (`linarith`): `-2*chi + 2*omega + 1 >= 0`.
- Integer rounding (`omega`): `-1*chi + 1*omega >= 0`.
- Linear combination (`linarith`): `-2*chi + 2*omega + 1*alpha + -1 >= 0`.
