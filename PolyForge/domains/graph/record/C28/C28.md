# C28

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, nontrivial. Then n <= 3*m - 3*min_deg + 2.

**Formula.** `if ((is_connected) and (nontrivial)), then (n <= 3*m - 3*min_deg + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
- Inventory `radius_ge_one`: `1*radius + -1 >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 2, min_deg ≥ 1): `-1*n + -2*min_deg + 1*P_n_mindeg + 2 >= 0`.
- Linear combination (`linarith`): `-1*n + 3*m + -3*min_deg + 2 >= 0`.
