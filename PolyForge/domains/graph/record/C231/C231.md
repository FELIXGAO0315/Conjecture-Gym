# C231

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 1, max_deg <= 6. Then max_deg >= m - 3*alpha + 3.

**Formula.** `if ((chi <= 1) and (max_deg <= 6)), then (max_deg >= m - 3*alpha + 3)`

## Proof

- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 1 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 6 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 6): `6*n + 1*max_deg + -1*P_n_maxdeg + -6 >= 0`.
- Linear combination (`linarith`): `-1*m + 1*max_deg + 3*alpha + -3 >= 0`.
