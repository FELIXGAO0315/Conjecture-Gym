# C86

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 5, alpha >= 2. Then alpha >= -m + 2*min_deg + 3.

**Formula.** `if ((n >= 5) and (alpha >= 2)), then (alpha >= -m + 2*min_deg + 3)`

## Proof

- Premise: `1*alpha + -2 >= 0`.
- Premise: `1*n + -5 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + 1*alpha + -13/5 >= 0`.
- Integer rounding (`omega`): `1*m + -2*min_deg + 1*alpha + -3 >= 0`.
