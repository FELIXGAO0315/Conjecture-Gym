# C86

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, is_regular(3), chi <= 6. Then chi >= -alpha + 5.

**Formula.** `if ((not_bipartite) and (is_regular(3)) and (chi <= 6)), then (chi >= -alpha + 5)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `-1*chi + 6 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 6): `1*chi + 6*alpha + -1*P_alpha_chi + -6 >= 0`.
- Inventory `regular_max`: `1*max_deg + -3 == 0`.
- Linear combination (`linarith`): `1*chi + 1*alpha + -25/6 >= 0`.
- Integer rounding (`omega`): `1*chi + 1*alpha + -5 >= 0`.
