# C72

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, min_deg <= 6, -2*max_deg + girth >= 0. Then max_deg <= girth - 2.

**Formula.** `if ((has_cycle) and (min_deg <= 6) and (-2*max_deg + girth >= 0)), then (max_deg <= girth - 2)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `-2*max_deg + 1*girth >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 1*girth + -3/2 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 1*girth + -2 >= 0`.
