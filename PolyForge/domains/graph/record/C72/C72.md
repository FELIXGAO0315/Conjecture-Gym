# C72

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 5, n >= 2*min_deg. Then min_deg <= n - 3.

**Formula.** `if ((chi >= 5) and (n >= 2*min_deg)), then (min_deg <= n - 3)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*chi + -5 >= 0`.
- Premise: `1*n + -2*min_deg >= 0`.
- Linear combination (`linarith`): `1*n + -1*min_deg + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*min_deg + -3 >= 0`.
