# C72

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg <= 2. Then 2*alpha >= 3*min_deg - chi - 1.

**Formula.** `if ((min_deg <= 2)), then (2*alpha >= 3*min_deg - chi - 1)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `-3*min_deg + 1*chi + 2*alpha + 1 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*min_deg + 2 >= 0`.
    - Linear combination (`linarith`): `-3*min_deg + 1*chi + 2*alpha + 1 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*min_deg + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-3*min_deg + 1*chi + 2*alpha + 1 >= 0`.
