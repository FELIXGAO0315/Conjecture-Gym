# C76

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_bipartite, -2*max_deg + chi <= 0, diam >= 5. Then m <= n + radius - 4.

**Formula.** `if ((is_tree) and (is_bipartite) and (-2*max_deg + chi <= 0) and (diam >= 5)), then (m <= n + radius - 4)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -5 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1*m + 1*radius + -7/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*m + 1*radius + -4 >= 0`.
