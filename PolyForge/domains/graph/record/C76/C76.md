# C76

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(1), nontrivial, n <= 2*chi. Then m >= 2*min_deg - 1.

**Formula.** `if ((is_k_edge_connected(1)) and (nontrivial) and (n <= 2*chi)), then (m >= 2*min_deg - 1)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + -2*min_deg + 1 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `edge_conn_min_deg`: `1*min_deg + -1 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 1): `-1*n + -3*min_deg + 1*P_n_mindeg + 3 >= 0`.
    - Linear combination (`linarith`): `1*m + -2*min_deg + 1 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `edge_conn_min_deg`: `1*min_deg + -1 >= 0`.
    - Linear combination (`linarith`): `1*n + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 2, min_deg ≥ 1): `-1*n + -2*min_deg + 1*P_n_mindeg + 2 >= 0`.
    - Premise: `-1*n + 2*chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Linear combination (`linarith`): `-1*min_deg + 3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≤ 4, min_deg ≤ 3): `-3*n + -4*min_deg + 1*P_n_mindeg + 12 >= 0`.
    - Linear combination (`linarith`): `1*m + -2*min_deg + 3/2 >= 0`.
    - Integer rounding (`omega`): `1*m + -2*min_deg + 1 >= 0`.
