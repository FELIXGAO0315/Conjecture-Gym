# C76

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, 2*radius - girth >= 0. Then 2*radius + girth >= 7.

**Formula.** `if ((is_connected) and (has_cycle) and (2*radius - girth >= 0)), then (2*radius + girth >= 7)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `2*radius + -1*girth >= 0`.
- Linear combination (`linarith`): `1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -2 >= 0`.
- Linear combination (`linarith`): `2*radius + 1*girth + -7 >= 0`.
