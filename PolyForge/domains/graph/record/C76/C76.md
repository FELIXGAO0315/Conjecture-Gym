# C76

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, girth <= max_deg. Then 2*min_deg <= m.

**Formula.** `if ((has_cycle) and (girth <= max_deg)), then (2*min_deg <= m)`

## Proof

- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Premise: `1*max_deg + -1*girth >= 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 0): `-4*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg >= 0`.
