# C46

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, max_deg <= 2*min_deg. Then chi >= -min_deg + 3*omega - 3.

**Formula.** `if ((is_acyclic) and (max_deg <= 2*min_deg)), then (chi >= -min_deg + 3*omega - 3)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Premise: `-1*max_deg + 2*min_deg >= 0`.
- Linear combination (`linarith`): `1*min_deg + 1*chi + -3*omega + 7/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + 1*chi + -3*omega + 3 >= 0`.
