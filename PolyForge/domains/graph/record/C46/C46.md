# C46

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, alpha >= 3, n <= 5. Then n <= 2*max_deg + 3*alpha - 6.

**Formula.** `if ((is_bipartite) and (alpha >= 3) and (n <= 5)), then (n <= 2*max_deg + 3*alpha - 6)`

## Proof

- Premise: `1*alpha + -3 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 5, max_deg ≥ 0): `5*max_deg + -1*P_n_maxdeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*n + 2*max_deg + 3*alpha + -28/5 >= 0`.
- Integer rounding (`omega`): `-1*n + 2*max_deg + 3*alpha + -6 >= 0`.
