# C46

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_bipartite, -2*max_deg + chi >= 0. Then 2*max_deg - 2*chi - radius <= -2.

**Formula.** `if ((is_tree) and (is_bipartite) and (-2*max_deg + chi >= 0)), then (2*max_deg - 2*chi - radius <= -2)`

## Proof

- Inventory `nonneg_radius`: `1*radius >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `-2*max_deg + 1*chi >= 0`.
- Linear combination (`linarith`): `-2*max_deg + 2*chi + -1 >= 0`.
- Integer rounding (`omega`): `-1*max_deg + 1*chi + -1 >= 0`.
- Linear combination (`linarith`): `-2*max_deg + 2*chi + 1*radius + -2 >= 0`.
