# C46

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, m >= 5. Then girth >= -2*diam - 2*radius + 7.

**Formula.** `if ((has_cycle) and (is_connected) and (m >= 5)), then (girth >= -2*diam - 2*radius + 7)`

## Proof

- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Linear combination (`linarith`): `1*diam + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `2*diam + 2*radius + 1*girth + -7 >= 0`.
