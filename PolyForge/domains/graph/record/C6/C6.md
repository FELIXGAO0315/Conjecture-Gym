# C6

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, m - 2*diam <= 0, n - 2*max_deg <= 0. Then min_deg <= max_deg + 2*radius - 2.

**Formula.** `if ((is_tree) and (m - 2*diam <= 0) and (n - 2*max_deg <= 0)), then (min_deg <= max_deg + 2*radius - 2)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `-1*m + 2*diam >= 0`.
- Premise: `-1*n + 2*max_deg >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*radius + -1/4 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1*min_deg + 2*radius + -2 >= 0`.
