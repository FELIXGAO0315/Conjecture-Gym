# C6

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega >= 2*m. Then 2*min_deg <= chi + omega - 2.

**Formula.** `if ((omega >= 2*m)), then (2*min_deg <= chi + omega - 2)`

        - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
        - Assumption: `1*m + -1 >= 0`.
        - Premise: `-2*m + 1*omega >= 0`.
        - Linear combination (`linarith`): `-2*min_deg + 1*chi + 1*omega + -2 >= 0`.
      - **Case 2** (`1*m <= 0`):
        - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.

    - Linear combination (`linarith`): `-2*min_deg + 1*chi + 1*omega + -2 >= 0`.
