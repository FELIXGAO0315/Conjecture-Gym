# C6

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 5. Then omega <= 3*max_deg + 2*alpha - 1.

**Formula.** `if ((n <= 5)), then (omega <= 3*max_deg + 2*alpha - 1)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 5, max_deg ≥ 0): `5*max_deg + -1*P_n_maxdeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*max_deg + -1*omega + 2*alpha + -1 >= 0`.
