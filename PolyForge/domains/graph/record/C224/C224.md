# C224

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), not_bipartite, alpha <= 2*omega. Then n >= -3*chi - alpha + 17.

**Formula.** `if ((is_regular(3)) and (not_bipartite) and (alpha <= 2*omega)), then (n >= -3*chi - alpha + 17)`

    - Assumption: `1*chi + -4 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -3 == 0`.
    - Linear combination (`linarith`): `1*n + 3*chi + 1*alpha + -17 >= 0`.
  - **Case 2** (`1*chi <= 3`):
    - Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.

    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.

    - Inventory theorem `turan_r3` (via `linarith`): `-6*m + 2*N2 >= 0`.
    - Linear combination (`linarith`): `1*n + -4 >= 0`.
