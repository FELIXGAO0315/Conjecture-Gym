# C31

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_k_edge_connected(3), m >= 6, n <= 5. Then m <= 10.

**Formula.** `if ((is_k_edge_connected(3)) and (m >= 6) and (n <= 5)), then (m <= 10)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 5, max_deg ≥ 0): `5*max_deg + -1*P_n_maxdeg >= 0`.
- Linear combination (`linarith`): `-1*m + 10 >= 0`.
