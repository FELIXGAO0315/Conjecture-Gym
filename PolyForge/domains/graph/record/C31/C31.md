# C31

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree, m >= 5, m - diam <= 0. Then n >= -2*radius + 12.

**Formula.** `if ((nontrivial) and (is_tree) and (m >= 5) and (m - diam <= 0)), then (n >= -2*radius + 12)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*m + -5 >= 0`.
- Premise: `-1*m + 1*diam >= 0`.
- Linear combination (`linarith`): `1*radius + -5/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -3 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -6 >= 0`.
- Linear combination (`linarith`): `1*n + 2*radius + -12 >= 0`.
