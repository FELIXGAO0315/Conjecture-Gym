# C12

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, diam >= 3. Then 2*radius >= -diam + 7.

**Formula.** `if ((is_connected) and (diam >= 3)), then (2*radius >= -diam + 7)`

## Proof

- Premise: `1*diam + -3 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Linear combination (`linarith`): `1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -2 >= 0`.
- Linear combination (`linarith`): `1*diam + 2*radius + -7 >= 0`.
