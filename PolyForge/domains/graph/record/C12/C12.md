# C12

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, n >= 1, alpha - 2*diam >= 0. Then -n - alpha + 2*diam <= -2.

**Formula.** `if ((is_tree) and (n >= 1) and (alpha - 2*diam >= 0)), then (-n - alpha + 2*diam <= -2)`

## Proof

- Case split (`by_cases`) on `bnb:diam` at threshold 1: `1*n + 1*alpha + -2*diam + -2 >= 0`.
  - **Case 1** (`1*diam >= 1`):
    - Inventory `nonneg_tau`: `1*tau >= 0`.
    - Assumption: `1*diam + -1 >= 0`.
    - Premise: `1*alpha + -2*diam >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*n + 1*alpha + -2*diam + -2 >= 0`.
  - **Case 2** (`1*diam <= 0`):
    - Premise: `1*n + -1 >= 0`.
    - Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
    - Assumption: `-1*diam >= 0`.
    - Linear combination (`linarith`): `1*n + 1*alpha + -2*diam + -2 >= 0`.
