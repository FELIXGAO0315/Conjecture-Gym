# C12

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, chi >= min_deg, max_deg <= 2*omega. Then 2*max_deg >= -2*n + m + 2.

**Formula.** `if ((is_acyclic) and (chi >= min_deg) and (max_deg <= 2*omega)), then (2*max_deg >= -2*n + m + 2)`

## Proof

- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `-1*max_deg + 2*omega >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Linear combination (`linarith`): `2*n + -1*m + 2*max_deg + -2 >= 0`.
