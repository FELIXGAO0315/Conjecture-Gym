# C12

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 2*tau. Then alpha <= n - 1.

**Formula.** `if ((chi <= 2*tau)), then (alpha <= n - 1)`

## Proof

- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-1*chi + 2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -1*alpha + -1/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*alpha + -1 >= 0`.
