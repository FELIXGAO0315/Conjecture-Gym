# C110

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 4. Then omega <= 3*n - m.

**Formula.** `if ((max_deg <= 4)), then (omega <= 3*n - m)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 4 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + -1*omega >= 0`.
