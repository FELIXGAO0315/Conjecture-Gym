# C110

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, max_deg <= 5, -max_deg + chi >= 0. Then -n + 2*max_deg <= 4.

**Formula.** `if ((has_cycle) and (max_deg <= 5) and (-max_deg + chi >= 0)), then (-n + 2*max_deg <= 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*n + -2*max_deg + 4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Premise: `-1*max_deg + 5 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*max_deg + 4 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Premise: `-1*max_deg + 1*chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `1*n + -2*max_deg + 2 >= 0`.
