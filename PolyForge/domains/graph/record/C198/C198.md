# C198

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, max_deg >= 4. Then n <= 3*m - 3*min_deg - 4.

**Formula.** `if ((is_connected) and (max_deg >= 4)), then (n <= 3*m - 3*min_deg - 4)`

## Proof

- Case split (`by_cases`) on `bnb:min_deg` at threshold 2: `-1*n + 3*m + -3*min_deg + -4 >= 0`.
  - **Case 1** (`1*min_deg >= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Premise: `1*max_deg + -4 >= 0`.
    - Assumption: `1*min_deg + -2 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 2): `-2*n + -1*min_deg + 1*P_n_mindeg + 2 >= 0`.
    - Linear combination (`linarith`): `1*m + -5 >= 0`.
    - Linear combination (`linarith`): `1*n + -5 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 2): `-2*n + -5*min_deg + 1*P_n_mindeg + 10 >= 0`.
    - Linear combination (`linarith`): `-1*n + 3*m + -3*min_deg + -4 >= 0`.
  - **Case 2** (`1*min_deg <= 1`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
    - Premise: `1*max_deg + -4 >= 0`.
    - Assumption: `-1*min_deg + 1 >= 0`.
    - Linear combination (`linarith`): `-1*n + 3*m + -3*min_deg + -4 >= 0`.
