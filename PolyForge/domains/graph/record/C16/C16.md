# C16

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic. Then 2*chi >= 3*n - 6*alpha + 4.

**Formula.** `if ((is_acyclic)), then (2*chi >= 3*n - 6*alpha + 4)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*chi + 3*alpha + -3*tau + -4 >= 0`.
