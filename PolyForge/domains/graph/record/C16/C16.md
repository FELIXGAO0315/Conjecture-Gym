# C16

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree, diam >= 3. Then m <= n + 2*radius - 5.

**Formula.** `if ((nontrivial) and (is_tree) and (diam >= 3)), then (m <= n + 2*radius - 5)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -2 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1*m + 2*radius + -5 >= 0`.
