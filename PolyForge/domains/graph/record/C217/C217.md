# C217

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 2*omega, alpha <= 5. Then chi >= 3*omega - 4.

**Formula.** `if ((alpha >= 2*omega) and (alpha <= 5)), then (chi >= 3*omega - 4)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Premise: `-2*omega + 1*alpha >= 0`.
- Premise: `-1*alpha + 5 >= 0`.
- Linear combination (`linarith`): `-1*omega + 5/2 >= 0`.
- Integer rounding (`omega`): `-1*omega + 2 >= 0`.
- Linear combination (`linarith`): `1*chi + -3*omega + 4 >= 0`.
