# C94

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, n <= 5. Then m <= 3*alpha - 2.

**Formula.** `if ((is_acyclic) and (n <= 5)), then (m <= 3*alpha - 2)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `bipartite_edges`: `-4*m + 1*N2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 5): `6*n + -1*N2 + -5 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `-1*m + 3*alpha + -5/4 >= 0`.
- Integer rounding (`omega`): `-1*m + 3*alpha + -2 >= 0`.
