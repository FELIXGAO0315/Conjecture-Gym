# C14

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 5. Then m >= -n + 3*min_deg + 3.

**Formula.** `if ((chi >= 5)), then (m >= -n + 3*min_deg + 3)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*chi + -5 >= 0`.
- Linear combination (`linarith`): `1*n + -5 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*n + 1*m + -3*min_deg + -3 >= 0`.
