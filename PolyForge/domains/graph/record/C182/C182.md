# C182

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_connected, diam >= 2. Then diam <= 2*m - 2*min_deg.

**Formula.** `if ((nontrivial) and (is_connected) and (diam >= 2)), then (diam <= 2*m - 2*min_deg)`

## Proof

- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `1*diam + -2 >= 0`.
- Inventory `connected_edges`: `-1*n + 1*m + 1 >= 0`.
- Linear combination (`linarith`): `2*m + -1*diam + -2 >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 1): `-1*n + -3*min_deg + 1*P_n_mindeg + 3 >= 0`.
- Linear combination (`linarith`): `2*m + -2*min_deg + -1*diam + 2/3 >= 0`.
- Integer rounding (`omega`): `2*m + -2*min_deg + -1*diam >= 0`.
