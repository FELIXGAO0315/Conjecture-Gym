# C79

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, m >= 5, n - 2*alpha >= 0. Then max_deg <= alpha + 2*tau - 3.

**Formula.** `if ((not_bipartite) and (m >= 5) and (n - 2*alpha >= 0)), then (max_deg <= alpha + 2*tau - 3)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `1*n + -2*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -2 >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `max_lt_card` (via `linarith`): `1*n + -1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 1*alpha + 2*tau + -3 >= 0`.
