# C93

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, omega >= max_deg. Then max_deg >= -alpha + 3.

**Formula.** `if ((not_bipartite) and (omega >= max_deg)), then (max_deg >= -alpha + 3)`

## Proof

- Case split (`by_cases`) on `omega` at threshold 3: `1*n + 1*max_deg + -1*tau + -3 >= 0`.
  - **Case 1** (`1*omega >= 3`):
    - Assumption: `1*omega + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*n + 1*max_deg + -1*tau + -3 >= 0`.
  - **Case 2** (`1*omega <= 2`):
    - Inventory `tau_le_card_sub_one`: `1*n + -1*tau + -1 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Premise: `-1*max_deg + 1*omega >= 0`.
    - Assumption: `-1*omega + 2 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 3, max_deg ≤ 2): `2*n + 3*max_deg + -1*P_n_maxdeg + -6 >= 0`.
    - Linear combination (`linarith`): `1*n + 1*max_deg + -1*tau + -7/3 >= 0`.
    - Integer rounding (`omega`): `1*n + 1*max_deg + -1*tau + -3 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `max_deg >= -alpha + 3`.
