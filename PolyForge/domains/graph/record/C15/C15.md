# C15

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 5, chi <= 2. Then m <= 3*n - 3.

**Formula.** `if ((n <= 5) and (chi <= 2)), then (m <= 3*n - 3)`

## Proof

- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Inventory `edge_card_bound`: `-1*n + -2*m + 1*N2 >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 5): `6*n + -1*N2 + -5 >= 0`.
- Linear combination (`linarith`): `3*n + -1*m + -3 >= 0`.
