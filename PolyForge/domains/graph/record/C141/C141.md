# C141

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg <= 2, tau >= alpha. Then chi <= -min_deg + 3*tau.

**Formula.** `if ((min_deg <= 2) and (tau >= alpha)), then (chi <= -min_deg + 3*tau)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `-1*min_deg + 2 >= 0`.
- Premise: `-1*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*min_deg + -1*chi + 3*tau + 1/2 >= 0`.
- Integer rounding (`omega`): `-1*min_deg + -1*chi + 3*tau >= 0`.
