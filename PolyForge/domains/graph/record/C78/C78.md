# C78

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, alpha - tau <= 0. Then tau >= -2*n + 8.

**Formula.** `if ((not_bipartite) and (alpha - tau <= 0)), then (tau >= -2*n + 8)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-1*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*n + 1*tau + -15/2 >= 0`.
- Integer rounding (`omega`): `2*n + 1*tau + -8 >= 0`.
