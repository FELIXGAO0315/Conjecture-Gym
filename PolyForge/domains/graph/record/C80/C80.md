# C80

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, tau >= 2*max_deg. Then alpha >= 2*max_deg.

**Formula.** `if ((is_bipartite) and (tau >= 2*max_deg)), then (alpha >= 2*max_deg)`

## Proof

- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-2*max_deg + 1*tau >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-2*max_deg + 1*alpha >= 0`.
