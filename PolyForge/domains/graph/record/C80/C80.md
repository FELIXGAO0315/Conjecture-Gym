# C80

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, omega <= max_deg. Then 2*omega <= -n + 4*alpha.

**Formula.** `if ((is_acyclic) and (omega <= max_deg)), then (2*omega <= -n + 4*alpha)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Linear combination (`linarith`): `-1*omega + 2 >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*max_deg + -1*omega >= 0`.
- Linear combination (`linarith`): `-2*omega + 3*alpha + -1/2 >= 0`.
- Integer rounding (`omega`): `-2*omega + 3*alpha + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-2*omega + 3*alpha + -1*tau + 2/3 >= 0`.
- Integer rounding (`omega`): `-2*omega + 3*alpha + -1*tau >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `2*omega <= -n + 4*alpha`.
