## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, max_deg <= 2*min_deg. Then 2*min_deg >= 2*max_deg - 3*alpha + 3.

**Formula.** `if ((is_acyclic) and (max_deg <= 2*min_deg)), then (2*min_deg >= 2*max_deg - 3*alpha + 3)`

    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Assumption: `1*min_deg + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*max_deg + 2*min_deg >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-2*max_deg + 2*min_deg + 3*alpha + -5/2 >= 0`.
    - Integer rounding (`omega`): `-2*max_deg + 2*min_deg + 3*alpha + -3 >= 0`.
  - **Case 2** (`1*min_deg <= 0`):

    - Assumption: `-1*min_deg >= 0`.
    - Linear combination (`linarith`): `-2*max_deg + 2*min_deg + 3*alpha + -3 >= 0`.
