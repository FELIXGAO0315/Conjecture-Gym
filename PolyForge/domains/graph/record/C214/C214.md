# C214

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, alpha >= 2. Then 4*alpha >= 2*n - 3*chi + 6.

**Formula.** `if ((is_bipartite) and (alpha >= 2)), then (4*alpha >= 2*n - 3*chi + 6)`

## Proof

- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `1*alpha + -2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*chi + 2*alpha + -2*tau + -6 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `4*alpha >= 2*n - 3*chi + 6`.
