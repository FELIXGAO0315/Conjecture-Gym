# C214

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi >= 2*max_deg. Then min_deg <= 3*chi - 3.

**Formula.** `if ((chi >= 2*max_deg)), then (min_deg <= 3*chi - 3)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `-2*max_deg + 1*chi >= 0`.
- Linear combination (`linarith`): `-1*min_deg + 3*chi + -5/2 >= 0`.
- Integer rounding (`omega`): `-1*min_deg + 3*chi + -3 >= 0`.
