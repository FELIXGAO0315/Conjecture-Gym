# C100

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= 6. Then chi >= 3*min_deg - 3*alpha - 2.

**Formula.** `if ((m <= 6)), then (chi >= 3*min_deg - 3*alpha - 2)`

    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Premise: `-1*m + 6 >= 0`.

    - Assumption: `1*n + -5 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
    - Linear combination (`linarith`): `-1*min_deg + 12/5 >= 0`.
    - Integer rounding (`omega`): `-1*min_deg + 2 >= 0`.
    - Linear combination (`linarith`): `-3*min_deg + 1*chi + 3*alpha + 2 >= 0`.
