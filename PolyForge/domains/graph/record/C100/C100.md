# C100

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 3, min_deg >= 1. Then max_deg <= 3*m - 3*min_deg - 1.

**Formula.** `if ((m >= 3) and (min_deg >= 1)), then (max_deg <= 3*m - 3*min_deg - 1)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 4: `3*m + -1*max_deg + -3*min_deg + -1 >= 0`.
  - **Case 1** (`1*n >= 4`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Assumption: `1*n + -4 >= 0`.
    - Premise: `1*m + -3 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Premise: `1*min_deg + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 1): `-1*n + -4*min_deg + 1*P_n_mindeg + 4 >= 0`.
    - Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + -3/2 >= 0`.
    - Integer rounding (`omega`): `3*m + -1*max_deg + -3*min_deg + -2 >= 0`.
  - **Case 2** (`1*n <= 3`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Premise: `1*m + -3 >= 0`.
    - Assumption: `-1*n + 3 >= 0`.
    - Linear combination (`linarith`): `3*m + -1*max_deg + -3*min_deg + -1 >= 0`.
