# C100

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_bipartite, -m + 2*min_deg >= 0. Then -max_deg - min_deg + 2*chi <= 2.

**Formula.** `if ((is_tree) and (is_bipartite) and (-m + 2*min_deg >= 0)), then (-max_deg - min_deg + 2*chi <= 2)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Premise: `-1*m + 2*min_deg >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*min_deg + -2*chi + 7/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + -2*chi + 3 >= 0`.
- Linear combination (`linarith`): `1*max_deg + 1*min_deg + -2*chi + 8/3 >= 0`.
- Integer rounding (`omega`): `1*max_deg + 1*min_deg + -2*chi + 2 >= 0`.
