# C111

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, chi <= 2*max_deg. Then omega <= 3*max_deg - 3.

**Formula.** `if ((not_bipartite) and (chi <= 2*max_deg)), then (omega <= 3*max_deg - 3)`

## Proof

- Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -2 >= 0`.
- Linear combination (`linarith`): `3*max_deg + -1*omega + -3 >= 0`.
