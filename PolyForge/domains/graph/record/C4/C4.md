# C4

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, -omega + tau <= 0, -2*max_deg + chi <= 0. Then alpha >= -2*max_deg + 5.

**Formula.** `if ((not_bipartite) and (-omega + tau <= 0) and (-2*max_deg + chi <= 0)), then (alpha >= -2*max_deg + 5)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -2 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Linear combination (`linarith`): `1*n + -3 >= 0`.
- Inventory theorem `alpha_ge_one` (via `linarith`): `1*alpha + -1 >= 0`.
- Linear combination (`linarith`): `2*max_deg + 1*alpha + -5 >= 0`.
