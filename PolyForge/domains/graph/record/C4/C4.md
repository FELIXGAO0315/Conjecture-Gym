# C4

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, chi >= 2*alpha. Then 2*tau >= n - 2*chi + 7.

**Formula.** `if ((not_bipartite) and (chi >= 2*alpha)), then (2*tau >= n - 2*chi + 7)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*chi + -2*alpha >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -2 >= 0`.
- Linear combination (`linarith`): `-1*n + 2*chi + 2*tau + -13/2 >= 0`.
- Integer rounding (`omega`): `-1*n + 2*chi + 2*tau + -7 >= 0`.
