# C62

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 2*omega, m >= 1. Then omega <= 3*n - 4.

**Formula.** `if ((n <= 2*omega) and (m >= 1)), then (omega <= 3*n - 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*n + -1*omega + -4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `3*n + -1*omega + -6 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*m + -1 >= 0`.
    - Inventory `edge_card_bound`: `-1*n + -2*m + 1*N2 >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Premise: `-1*n + 2*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 4): `5*n + -1*N2 + -4 >= 0`.
    - Linear combination (`linarith`): `1*n + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*n + -2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Linear combination (`linarith`): `3*n + -1*omega + -4 >= 0`.
