# C62

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, is_acyclic, n >= 2, omega - 2*tau <= 0. Then n >= -2*tau + 4.

**Formula.** `if ((is_bipartite) and (is_acyclic) and (n >= 2) and (omega - 2*tau <= 0)), then (n >= -2*tau + 4)`

## Proof

- Premise: `1*n + -2 >= 0`.
- Inventory theorem `omega_ge_one` (via `linarith`): `1*omega + -1 >= 0`.
- Premise: `-1*omega + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -1 >= 0`.
- Linear combination (`linarith`): `1*n + 2*tau + -4 >= 0`.
