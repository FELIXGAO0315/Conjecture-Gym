# C62

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 2, alpha <= 2. Then m >= 3*min_deg - 2.

**Formula.** `if ((chi <= 2) and (alpha <= 2)), then (m >= 3*min_deg - 2)`

## Proof

- Case split (`by_cases`) on `bnb:n` at threshold 3: `1*m + -3*min_deg + 2 >= 0`.
  - **Case 1** (`1*n >= 3`):
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
    - Assumption: `1*n + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Premise: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*alpha + 2 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 3, n ≤ 4): `7*n + -1*N2 + -12 >= 0`.
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Linear combination (`linarith`): `-1*min_deg + 3 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≤ 4, min_deg ≤ 3): `-3*n + -4*min_deg + 1*P_n_mindeg + 12 >= 0`.
    - Linear combination (`linarith`): `1*m + -3*min_deg + 72/25 >= 0`.
    - Integer rounding (`omega`): `1*m + -3*min_deg + 2 >= 0`.
  - **Case 2** (`1*n <= 2`):
    - Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Assumption: `-1*n + 2 >= 0`.
    - Linear combination (`linarith`): `1*m + -3*min_deg + 2 >= 0`.
