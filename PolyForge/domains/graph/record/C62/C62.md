# C62

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 2*tau, m <= 2. Then 5*alpha >= 3*n - 3*chi + 4.

**Formula.** `if ((alpha <= 2*tau) and (m <= 2)), then (5*alpha >= 3*n - 3*chi + 4)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*chi + 2*alpha + -3*tau + -4 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Premise: `-1*m + 2 >= 0`.
    - Linear combination (`linarith`): `3*chi + 2*alpha + -3*tau + -5 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*m + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Premise: `-1*alpha + 2*tau >= 0`.
    - Linear combination (`linarith`): `-1*alpha + 4 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 4, chi ≥ 1): `4*chi + 1*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*chi + 2*alpha + -3*tau + -7/2 >= 0`.
    - Integer rounding (`omega`): `3*chi + 2*alpha + -3*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `5*alpha >= 3*n - 3*chi + 4`.
