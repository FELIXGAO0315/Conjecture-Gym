# C209

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha >= 2*tau. Then alpha >= 3*omega - 4.

**Formula.** `if ((is_tree) and (alpha >= 2*tau)), then (alpha >= 3*omega - 4)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
- Premise: `1*alpha + -2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -3*omega + -1*tau + 14/3 >= 0`.
- Integer rounding (`omega`): `1*n + -3*omega + -1*tau + 4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the tree identity `m = n - 1` (`linarith`): `alpha >= 3*omega - 4`.
