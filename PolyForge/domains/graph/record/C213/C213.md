# C213

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 2*chi, alpha >= 4. Then n >= max_deg - chi + 3.

**Formula.** `if ((max_deg <= 2*chi) and (alpha >= 4)), then (n >= max_deg - chi + 3)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*alpha + -4 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Premise: `-1*max_deg + 2*chi >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -1*max_deg + 1*chi + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + -1*max_deg + 1*chi + -3 >= 0`.
