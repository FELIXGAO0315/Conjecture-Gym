# C60

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, is_tree, chi - 2*tau <= 0. Then radius <= 2*m + diam - 2.

**Formula.** `if ((is_acyclic) and (is_tree) and (chi - 2*tau <= 0)), then (radius <= 2*m + diam - 2)`

## Proof

- Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `-1*chi + 2*tau >= 0`.
- Inventory theorem `tau_le_card_sub_one` (via `linarith`): `1*n + -1*tau + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + -2 >= 0`.
- Linear combination (`linarith`): `2*m + 1*diam + -1*radius + -2 >= 0`.
