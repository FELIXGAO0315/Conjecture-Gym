# C60

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, diam >= 3. Then radius >= 2.

**Formula.** `if ((is_tree) and (diam >= 3)), then (radius >= 2)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Premise: `1*diam + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -3/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -2 >= 0`.
