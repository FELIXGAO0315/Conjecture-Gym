## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, max_deg >= 2, n >= m. Then max_deg >= 3*min_deg - 3*alpha + 2.

**Formula.** `if ((is_bipartite) and (max_deg >= 2) and (n >= m)), then (max_deg >= 3*min_deg - 3*alpha + 2)`

    - Assumption: `1*max_deg + -3 >= 0`.

    - Premise: `1*n + -1*m >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `nonneg_min_deg`: `1*min_deg >= 0`.

  - **Case 2** (`1*max_deg <= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
