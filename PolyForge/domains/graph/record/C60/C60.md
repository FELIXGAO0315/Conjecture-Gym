# C60

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 4, tau >= chi. Then chi <= max_deg + 1.

**Formula.** `if ((n <= 4) and (tau >= chi)), then (chi <= max_deg + 1)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*n + 4 >= 0`.
- Premise: `-1*chi + 1*tau >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 4, max_deg ≥ 0): `4*max_deg + -1*P_n_maxdeg >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*max_deg + -2*chi + 3 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -1*chi + 1 >= 0`.
