# C60

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha >= 2. Then diam <= n + radius - 2.

**Formula.** `if ((is_tree) and (alpha >= 2)), then (diam <= n + radius - 2)`

## Proof

- Premise: `1*alpha + -2 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*m + -1*diam + 1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*m + -1*diam + 1*radius + -1 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the tree identity `m = n - 1` (`linarith`): `diam <= n + radius - 2`.
