# C188

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_bipartite, n <= 5. Then alpha >= 3*m - chi - 13.

**Formula.** `if ((is_bipartite) and (n <= 5)), then (alpha >= 3*m - chi - 13)`

## Proof

- Inventory `bipartite_edges`: `-4*m + 1*N2 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*n + 5 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 5): `6*n + -1*N2 + -5 >= 0`.
- Linear combination (`linarith`): `-1*m + 25/4 >= 0`.
- Integer rounding (`omega`): `-1*m + 6 >= 0`.
- Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `-1*tau + 5/2 >= 0`.
- Integer rounding (`omega`): `-1*tau + 2 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Linear combination (`linarith`): `-1*alpha + 5 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 5, chi ≥ 1): `5*chi + 1*alpha + -1*P_alpha_chi + -5 >= 0`.
- Linear combination (`linarith`): `-3*m + 1*chi + 1*alpha + 413/30 >= 0`.
- Integer rounding (`omega`): `-3*m + 1*chi + 1*alpha + 13 >= 0`.
