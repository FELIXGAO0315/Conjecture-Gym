# C10

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, min_deg <= 1, chi <= 2*max_deg. Then max_deg <= 3*n - 5.

**Formula.** `if ((nontrivial) and (min_deg <= 1) and (chi <= 2*max_deg)), then (max_deg <= 3*n - 5)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Linear combination (`linarith`): `1*max_deg + -1/2 >= 0`.
- Integer rounding (`omega`): `1*max_deg + -1 >= 0`.
- Linear combination (`linarith`): `3*n + -1*max_deg + -5 >= 0`.
