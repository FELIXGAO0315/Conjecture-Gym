# C10

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose nontrivial, is_tree, -min_deg + 2*tau >= 0. Then 2*n - chi + 2*tau >= 4.

**Formula.** `if ((nontrivial) and (is_tree) and (-min_deg + 2*tau >= 0)), then (2*n - chi + 2*tau >= 4)`

## Proof

- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Inventory `connected_min_deg`: `1*min_deg + -1 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Premise: `-1*min_deg + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -1 >= 0`.
- Linear combination (`linarith`): `2*n + -1*chi + 2*tau + -4 >= 0`.
