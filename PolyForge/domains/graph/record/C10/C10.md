# C10

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega >= 2, m <= 2*min_deg. Then min_deg >= -max_deg - 2*alpha + 4.

**Formula.** `if ((omega >= 2) and (m <= 2*min_deg)), then (min_deg >= -max_deg - 2*alpha + 4)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Premise: `1*omega + -2 >= 0`.
- Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Premise: `-1*m + 2*min_deg >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*min_deg + 2*alpha + -5/2 >= 0`.
- Integer rounding (`omega`): `1*min_deg + 2*alpha + -3 >= 0`.
- Linear combination (`linarith`): `1*max_deg + 1*min_deg + 2*alpha + -10/3 >= 0`.
- Integer rounding (`omega`): `1*max_deg + 1*min_deg + 2*alpha + -4 >= 0`.
