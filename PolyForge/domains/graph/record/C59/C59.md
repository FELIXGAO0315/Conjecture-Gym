# C59

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, min_deg >= 2. Then m >= 3.

**Formula.** `if ((not_bipartite) and (min_deg >= 2)), then (m >= 3)`

## Proof

- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `1*min_deg + -2 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 2): `-2*n + -1*min_deg + 1*P_n_mindeg + 2 >= 0`.
- Linear combination (`linarith`): `1*m + -3 >= 0`.
