# C59

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, diam <= 3, chi - 2*diam <= 0. Then 2*radius >= -diam + 3.

**Formula.** `if ((is_tree) and (diam <= 3) and (chi - 2*diam <= 0)), then (2*radius >= -diam + 3)`

## Proof

- Inventory `nonneg_m`: `1*m >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -1 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `-1*chi + 2*diam >= 0`.
- Linear combination (`linarith`): `1*diam + -1/2 >= 0`.
- Integer rounding (`omega`): `1*diam + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Linear combination (`linarith`): `1*radius + -1/4 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Linear combination (`linarith`): `1*diam + 2*radius + -3 >= 0`.
