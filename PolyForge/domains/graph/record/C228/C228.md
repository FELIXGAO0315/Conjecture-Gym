# C228

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= omega, n <= 2*alpha. Then omega >= -3*max_deg + 2*tau + 1.

**Formula.** `if ((alpha <= omega) and (n <= 2*alpha)), then (omega >= -3*max_deg + 2*tau + 1)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*max_deg + 1*omega + -2*tau + -1 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*omega + -1*alpha >= 0`.
    - Premise: `-1*n + 2*alpha >= 0`.
    - Linear combination (`linarith`): `1*max_deg + -1/2 >= 0`.
    - Integer rounding (`omega`): `1*max_deg + -1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*max_deg + 1*omega + -2*tau + -1 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `1*omega + -1*alpha >= 0`.
    - Premise: `-1*n + 2*alpha >= 0`.
    - Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 4, max_deg ≥ 0): `4*max_deg + -1*P_n_maxdeg >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*max_deg + 1*omega + -2*tau + -1/2 >= 0`.
    - Integer rounding (`omega`): `3*max_deg + 1*omega + -2*tau + -1 >= 0`.
