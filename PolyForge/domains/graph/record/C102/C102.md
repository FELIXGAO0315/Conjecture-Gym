# C102

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, alpha <= 2. Then max_deg <= 2*chi + 3*alpha - 7.

**Formula.** `if ((not_bipartite) and (alpha <= 2)), then (max_deg <= 2*chi + 3*alpha - 7)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Premise: `-1*alpha + 2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 3): `2*chi + 3*alpha + -1*P_alpha_chi + -6 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 2*chi + 3*alpha + -7 >= 0`.
