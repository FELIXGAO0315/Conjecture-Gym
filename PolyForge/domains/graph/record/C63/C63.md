# C63

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, is_acyclic, chi - 2*tau <= 0, max_deg >= 6. Then 2*m >= -max_deg - 2*tau + 20.

**Formula.** `if ((is_tree) and (is_acyclic) and (chi - 2*tau <= 0) and (max_deg >= 6)), then (2*m >= -max_deg - 2*tau + 20)`

## Proof

- Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
- Premise: `1*max_deg + -6 >= 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `1*n + -7 >= 0`.
- Inventory theorem `chi_ge_one` (via `linarith`): `1*chi + -1 >= 0`.
- Premise: `-1*chi + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -1 >= 0`.
- Linear combination (`linarith`): `2*m + 1*max_deg + 2*tau + -20 >= 0`.
