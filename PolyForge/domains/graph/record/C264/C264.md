# C264

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 4, alpha <= 2*tau. Then max_deg <= 3*n - 2*alpha - 5.

**Formula.** `if ((max_deg >= 4) and (alpha <= 2*tau)), then (max_deg <= 3*n - 2*alpha - 5)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*max_deg + -4 >= 0`.
- Premise: `-1*alpha + 2*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*n + -1*max_deg + -2*alpha + -13/3 >= 0`.
- Integer rounding (`omega`): `3*n + -1*max_deg + -2*alpha + -5 >= 0`.
