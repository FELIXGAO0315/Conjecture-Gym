# C39

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, has_cycle, min_deg <= 3. Then omega <= n + 2*radius - 2.

**Formula.** `if ((is_connected) and (has_cycle) and (min_deg <= 3)), then (omega <= n + 2*radius - 2)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_ge_three`: `1*girth + -3 >= 0`.
- Linear combination (`linarith`): `1*radius + -1/2 >= 0`.
- Integer rounding (`omega`): `1*radius + -1 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Linear combination (`linarith`): `1*n + -1*omega >= 0`.
- Linear combination (`linarith`): `1*n + -1*omega + 2*radius + -2 >= 0`.
