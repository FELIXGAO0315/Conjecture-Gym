## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), alpha <= 4. Then 2*chi >= -3*alpha + 9.

**Formula.** `if ((is_regular(2)) and (alpha <= 4)), then (2*chi >= -3*alpha + 9)`

## Proof

    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Linear combination (`linarith`): `2*chi + 3*alpha + -9 >= 0`.
  - **Case 2** (`1*chi <= 2`):

    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.

    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.

    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Premise: `-1*alpha + 4 >= 0`.

    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
