# C39

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, omega <= 2*max_deg. Then n <= 3*chi + 3*alpha - 7.

**Formula.** `if ((is_tree) and (omega <= 2*max_deg)), then (n <= 3*chi + 3*alpha - 7)`

## Proof

    - Assumption: `1*alpha + -2 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 3*chi + -3*tau + -7 >= 0`.
  - **Case 2** (`1*alpha <= 1`):
    - Inventory `max_le_edges`: `1*m + -1*max_deg >= 0`.
    - Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `2*max_deg + -1*omega >= 0`.
    - Assumption: `-1*alpha + 1 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 1, chi ≥ 1): `1*chi + 1*alpha + -1*P_alpha_chi + -1 >= 0`.
    - Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
    - Linear combination (`linarith`): `1*chi + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*n + -3/2 >= 0`.

    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.

    - Linear combination (`linarith`): `2*n + 3*chi + -3*tau + -7 >= 0`.
