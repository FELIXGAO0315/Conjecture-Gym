# C39

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), alpha <= 4. Then n >= -3*chi - 2*alpha + 14.

**Formula.** `if ((is_regular(2)) and (alpha <= 4)), then (n >= -3*chi - 2*alpha + 14)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + 3*chi + 2*alpha + -14 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `1*m + 3*chi + 2*alpha + -14 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*alpha + 4 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 8 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 3, n ≤ 8): `11*n + -1*N2 + -24 >= 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `1*n + -24/7 >= 0`.
    - Integer rounding (`omega`): `1*n + -4 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 4, chi ≥ 1): `4*chi + 1*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*alpha + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `1*m + 3*chi + 2*alpha + -40/3 >= 0`.
    - Integer rounding (`omega`): `1*m + 3*chi + 2*alpha + -14 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `n >= -3*chi - 2*alpha + 14`.
