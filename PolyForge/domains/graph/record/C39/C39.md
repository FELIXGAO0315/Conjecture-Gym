# C39

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose not_bipartite, alpha - tau >= 0. Then 2*min_deg + chi + 2*alpha >= 7.

**Formula.** `if ((not_bipartite) and (alpha - tau >= 0)), then (2*min_deg + chi + 2*alpha >= 7)`

## Proof

- Inventory `not_bipartite_chi`: `1*chi + -3 >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Premise: `1*alpha + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + -2 >= 0`.
- Linear combination (`linarith`): `2*min_deg + 1*chi + 2*alpha + -7 >= 0`.
