# C241

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 4, tau >= 2*alpha. Then m >= 3*min_deg - tau + 2.

**Formula.** `if ((max_deg >= 4) and (tau >= 2*alpha)), then (m >= 3*min_deg - tau + 2)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*max_deg + -4 >= 0`.
- Premise: `-2*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*tau + -10/3 >= 0`.
- Integer rounding (`omega`): `1*tau + -4 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Linear combination (`linarith`): `1*n + -5 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 5, min_deg ≥ 0): `-5*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -3*min_deg + 1*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*m + -3*min_deg + 1*tau + -2 >= 0`.
