# C120

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, n <= 6. Then n >= 3*diam - radius - 6.

**Formula.** `if ((is_tree) and (n <= 6)), then (n >= 3*diam - radius - 6)`

## Proof

- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `-1*n + 6 >= 0`.
- Linear combination (`linarith`): `1*n + -3*diam + 1*radius + 13/2 >= 0`.
- Integer rounding (`omega`): `1*n + -3*diam + 1*radius + 6 >= 0`.
