# C271

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, alpha <= 2. Then chi >= -2*m + 3*min_deg + 3.

**Formula.** `if ((has_cycle) and (alpha <= 2)), then (chi >= -2*m + 3*min_deg + 3)`

## Proof

    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.

    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 3, min_deg ≥ 0): `-3*min_deg + 1*P_n_mindeg >= 0`.
    - Linear combination (`linarith`): `2*m + -3*min_deg + 1*chi + -3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.

    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.

    - Inventory `cycle_three_le_edges`: `1*m + -3 >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 4 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 3, n ≤ 4): `7*n + -1*N2 + -12 >= 0`.
    - Linear combination (`linarith`): `1*n + -24/7 >= 0`.
    - Integer rounding (`omega`): `1*n + -4 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
