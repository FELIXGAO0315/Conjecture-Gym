# C269

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m <= n, max_deg <= 2*chi. Then omega <= 3*n - m - 2.

**Formula.** `if ((m <= n) and (max_deg <= 2*chi)), then (omega <= 3*n - m - 2)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*n + -1*m + -1*omega + -2 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*n + -1*m >= 0`.
    - Linear combination (`linarith`): `3*n + -1*m + -1*omega + -3 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `omega_le_n`: `1*n + -1*omega >= 0`.
    - Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
    - Premise: `1*n + -1*m >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Premise: `-1*max_deg + 2*chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*max_deg + 4 >= 0`.
    - Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 4): `4*n + 1*max_deg + -1*P_n_maxdeg + -4 >= 0`.
    - Linear combination (`linarith`): `3*n + -1*m + -1*omega + -5/3 >= 0`.
    - Integer rounding (`omega`): `3*n + -1*m + -1*omega + -2 >= 0`.
