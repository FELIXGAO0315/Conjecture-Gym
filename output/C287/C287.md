# C287

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, alpha <= 2*omega. Then n >= -chi + 6.

**Formula.** `if ((has_cycle) and (alpha <= 2*omega)), then (n >= -chi + 6)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*n + 1*chi + -6 >= 0`.

    - Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Linear combination (`linarith`): `2*n + 2*chi + -12 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `cycle_three_le_edges`: `1*m + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `2*omega + -1*alpha >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
    - Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `-1*n + 8 >= 0`.
    - Product step (`mul_nonneg`) on N2 from (n ≥ 3, n ≤ 8): `11*n + -1*N2 + -24 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Linear combination (`linarith`): `-1*alpha + 4 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 4, chi ≥ 1): `4*chi + 1*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `1*chi + -40/33 >= 0`.
    - Integer rounding (`omega`): `1*chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*n + -36/11 >= 0`.
    - Integer rounding (`omega`): `1*n + -4 >= 0`.
    - Linear combination (`linarith`): `2*n + 2*chi + -12 >= 0`.
