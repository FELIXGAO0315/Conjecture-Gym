# C293

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 2, n >= 6. Then omega <= 3*chi + 2*alpha - 10.

**Formula.** `if ((alpha >= 2) and (n >= 6)), then (omega <= 3*chi + 2*alpha - 10)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*chi + -1*omega + 2*alpha + -10 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Assumption: `1*chi + -3 >= 0`.
    - Premise: `1*alpha + -2 >= 0`.
    - Linear combination (`linarith`): `3*chi + -1*omega + 2*alpha + -10 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Premise: `1*n + -6 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `1*alpha + -2 >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Linear combination (`linarith`): `3*chi + -1*omega + 2*alpha + -10 >= 0`.
