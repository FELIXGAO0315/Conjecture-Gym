# C32

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha >= tau, diam >= 2. Then omega <= 3*chi + 2*alpha - 8.

**Formula.** `if ((is_tree) and (alpha >= tau) and (diam >= 2)), then (omega <= 3*chi + 2*alpha - 8)`

## Proof

    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Assumption: `1*alpha + -3 >= 0`.
    - Linear combination (`linarith`): `3*chi + -1*omega + 2*alpha + -8 >= 0`.
  - **Case 2** (`1*alpha <= 2`):
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Premise: `1*diam + -2 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*alpha + 2 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*chi + -3/2 >= 0`.

    - Linear combination (`linarith`): `1*alpha + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*alpha + -2 >= 0`.
    - Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
    - Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
    - Linear combination (`linarith`): `-1*omega + 2 >= 0`.
    - Linear combination (`linarith`): `3*chi + -1*omega + 2*alpha + -8 >= 0`.
