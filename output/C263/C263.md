# C263

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg >= 2*chi, n >= 4. Then max_deg >= -n + 3*chi + 3.

**Formula.** `if ((max_deg >= 2*chi) and (n >= 4)), then (max_deg >= -n + 3*chi + 3)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `1*n + -4 >= 0`.
- Premise: `1*max_deg + -2*chi >= 0`.
- Linear combination (`linarith`): `1*n + 1*max_deg + -3*chi + -5/2 >= 0`.
- Integer rounding (`omega`): `1*n + 1*max_deg + -3*chi + -3 >= 0`.
