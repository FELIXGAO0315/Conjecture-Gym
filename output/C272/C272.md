# C272

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, chi <= 6, radius <= 3. Then radius <= chi + 3*alpha - 4.

**Formula.** `if ((is_connected) and (chi <= 6) and (radius <= 3)), then (radius <= chi + 3*alpha - 4)`

## Proof

- Case split (`by_cases`) on `bnb:alpha` at threshold 2: `1*chi + 3*alpha + -1*radius + -4 >= 0`.
  - **Case 1** (`1*alpha >= 2`):
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Premise: `-1*radius + 3 >= 0`.
    - Premise: `-1*chi + 6 >= 0`.
    - Assumption: `1*alpha + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 6): `2*chi + 6*alpha + -1*P_alpha_chi + -12 >= 0`.
    - Linear combination (`linarith`): `1*chi + 3*alpha + -1*radius + -5 >= 0`.
  - **Case 2** (`1*alpha <= 1`):
    - Inventory `radius_le_diam`: `1*diam + -1*radius >= 0`.
    - Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*alpha + 1 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `-1*chi + 6 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 6): `1*chi + 6*alpha + -1*P_alpha_chi + -6 >= 0`.
    - Linear combination (`linarith`): `1*chi + 3*alpha + -1*radius + -4 >= 0`.
