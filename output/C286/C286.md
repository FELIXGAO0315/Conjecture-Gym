# C286

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 2, max_deg <= min_deg. Then 2*min_deg >= -3*n + 3*m + 3.

**Formula.** `if ((max_deg <= 2) and (max_deg <= min_deg)), then (2*min_deg >= -3*n + 3*m + 3)`

## Proof

- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 1*min_deg >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Premise: `-1*max_deg + 2 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 2): `2*n + 1*max_deg + -1*P_n_maxdeg + -2 >= 0`.
- Linear combination (`linarith`): `3*n + -3*m + 2*min_deg + -3 >= 0`.
