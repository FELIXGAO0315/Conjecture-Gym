# C282

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose omega >= chi, alpha <= 4. Then omega >= n - 3*chi.

**Formula.** `if ((omega >= chi) and (alpha <= 4)), then (omega >= n - 3*chi)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `-1*chi + 1*omega >= 0`.
- Premise: `-1*alpha + 4 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 4, chi ≥ 1): `4*chi + 1*alpha + -1*P_alpha_chi + -4 >= 0`.
- Linear combination (`linarith`): `-1*n + 3*chi + 1*omega >= 0`.
