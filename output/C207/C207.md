# C207

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, tau <= 2*alpha. Then n <= m + 2*alpha - 2.

**Formula.** `if ((has_cycle) and (tau <= 2*alpha)), then (n <= m + 2*alpha - 2)`

## Proof

- Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
- Inventory `cycle_three_le_edges`: `1*m + -3 >= 0`.
- Premise: `2*alpha + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + 1*m + -2*tau + -3/2 >= 0`.
- Integer rounding (`omega`): `1*n + 1*m + -2*tau + -2 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n <= m + 2*alpha - 2`.
