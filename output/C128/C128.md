# C128

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, n <= 2*chi. Then girth <= 3*chi - 2.

**Formula.** `if ((has_cycle) and (n <= 2*chi)), then (girth <= 3*chi - 2)`

## Proof

- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Inventory `girth_le_card`: `1*n + -1*girth >= 0`.
- Premise: `-1*n + 2*chi >= 0`.
- Linear combination (`linarith`): `3*chi + -1*girth + -3/2 >= 0`.
- Integer rounding (`omega`): `3*chi + -1*girth + -2 >= 0`.
