# C294

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), is_bipartite. Then 2*alpha >= n - 3*chi + 6.

**Formula.** `if ((is_regular(2)) and (is_bipartite)), then (2*alpha >= n - 3*chi + 6)`

## Proof

- Case split (`by_cases`) on `bnb:alpha` at threshold 3: `-1*m + 3*chi + 2*alpha + -6 >= 0`.
  - **Case 1** (`1*alpha >= 3`):
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
    - Assumption: `1*alpha + -3 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 2): `3*chi + 2*alpha + -1*P_alpha_chi + -6 >= 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `-1*m + 3*chi + 2*alpha + -6 >= 0`.
  - **Case 2** (`1*alpha <= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Inventory `bipartite_chi`: `-1*chi + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Assumption: `-1*alpha + 2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Inventory `regular_edges`: `-2*n + 2*m == 0`.
    - Linear combination (`linarith`): `-1*m + 3*chi + 2*alpha + -16/3 >= 0`.
    - Integer rounding (`omega`): `-1*m + 3*chi + 2*alpha + -6 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `2*alpha >= n - 3*chi + 6`.
