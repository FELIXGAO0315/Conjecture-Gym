# C31

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), tau >= 4. Then n >= -2*chi + 12.

**Formula.** `if ((is_regular(3)) and (tau >= 4)), then (n >= -2*chi + 12)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `1*m + 1*min_deg + 3*chi + -21 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `1*tau + -4 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Inventory `regular_edges`: `-3*n + 2*m == 0`.
    - Linear combination (`linarith`): `1*m + -15/2 >= 0`.
    - Integer rounding (`omega`): `1*m + -8 >= 0`.
    - Linear combination (`linarith`): `1*n + -16/3 >= 0`.
    - Integer rounding (`omega`): `1*n + -6 >= 0`.
    - Inventory `regular_min`: `1*min_deg + -3 == 0`.
    - Linear combination (`linarith`): `1*m + 1*min_deg + 3*chi + -21 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*tau + -4 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*alpha + -4 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 4, chi ≤ 2): `4*chi + 2*alpha + -1*P_alpha_chi + -8 >= 0`.
    - Inventory `regular_min`: `1*min_deg + -3 == 0`.
    - Inventory `regular_edges`: `-3*n + 2*m == 0`.
    - Linear combination (`linarith`): `1*m + 1*min_deg + 3*chi + -21 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `n >= -2*chi + 12`.
