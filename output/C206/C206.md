# C206

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_tree, alpha <= tau. Then diam <= 3*n + radius - 6.

**Formula.** `if ((is_tree) and (alpha <= tau)), then (diam <= 3*n + radius - 6)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `-1*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `tree_edges`: `-1*n + 1*m + 1 == 0`.
- Linear combination (`linarith`): `3*m + -1*diam + 1*radius + -5/2 >= 0`.
- Integer rounding (`omega`): `3*m + -1*diam + 1*radius + -3 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the tree identity `m = n - 1` (`linarith`): `diam <= 3*n + radius - 6`.
