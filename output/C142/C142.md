# C142

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 2*chi, n <= 5. Then n >= m - 1.

**Formula.** `if ((n >= 2*chi) and (n <= 5)), then (n >= m - 1)`

## Proof

- Premise: `-1*n + 5 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Premise: `1*n + -2*chi >= 0`.
- Linear combination (`linarith`): `-1*omega + 5/2 >= 0`.
- Integer rounding (`omega`): `-1*omega + 2 >= 0`.
- Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
- Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
- Linear combination (`linarith`): `1*n + -2 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 2, n ≤ 5): `7*n + -1*N2 + -10 >= 0`.
- Linear combination (`linarith`): `1*n + -1*m + 5/4 >= 0`.
- Integer rounding (`omega`): `1*n + -1*m + 1 >= 0`.
