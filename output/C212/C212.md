# C212

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, max_deg <= min_deg, min_deg <= 4. Then min_deg >= -2*n + m + 4.

**Formula.** `if ((has_cycle) and (max_deg <= min_deg) and (min_deg <= 4)), then (min_deg >= -2*n + m + 4)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 1*min_deg >= 0`.
- Premise: `-1*min_deg + 4 >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Linear combination (`linarith`): `-1*max_deg + 4 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 3, max_deg ≤ 4): `4*n + 3*max_deg + -1*P_n_maxdeg + -12 >= 0`.
- Linear combination (`linarith`): `2*n + -1*m + 1*min_deg + -4 >= 0`.
