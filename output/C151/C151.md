# C151

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose max_deg <= 5, tau <= 5. Then 2*alpha >= -3*n + 2*m - 10.

**Formula.** `if ((max_deg <= 5) and (tau <= 5)), then (2*alpha >= -3*n + 2*m - 10)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Premise: `-1*max_deg + 5 >= 0`.
- Premise: `-1*tau + 5 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≥ 1, max_deg ≤ 5): `5*n + 1*max_deg + -1*P_n_maxdeg + -5 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `3*n + -2*m + 2*alpha + 10 >= 0`.
