# C64

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 6. Then 3*max_deg >= m.

**Formula.** `if ((n <= 6)), then (3*max_deg >= m)`

## Proof

- Inventory `handshake_max`: `-2*m + 1*P_n_maxdeg >= 0`.
- Inventory `nonneg_max_deg`: `1*max_deg >= 0`.
- Premise: `-1*n + 6 >= 0`.
- Product step (`mul_nonneg`) on P_n_maxdeg from (n ≤ 6, max_deg ≥ 0): `6*max_deg + -1*P_n_maxdeg >= 0`.
- Linear combination (`linarith`): `-1*m + 3*max_deg >= 0`.
