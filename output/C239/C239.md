# C239

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 5, tau >= 2. Then 2*min_deg <= m - 2.

**Formula.** `if ((alpha >= 5) and (tau >= 2)), then (2*min_deg <= m - 2)`

## Proof

- Case split (`by_cases`) on `bnb:min_deg` at threshold 1: `1*m + -2*min_deg + -2 >= 0`.
  - **Case 1** (`1*min_deg >= 1`):
    - Premise: `1*alpha + -5 >= 0`.
    - Assumption: `1*min_deg + -1 >= 0`.
    - Premise: `1*tau + -2 >= 0`.
    - Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
    - Inventory `n_ge_one`: `1*n + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 1, min_deg ≥ 1): `-1*n + -1*min_deg + 1*P_n_mindeg + 1 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `1*m + -7/2 >= 0`.
    - Integer rounding (`omega`): `1*m + -4 >= 0`.
    - Linear combination (`linarith`): `1*n + -7 >= 0`.
    - Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 7, min_deg ≥ 1): `-1*n + -7*min_deg + 1*P_n_mindeg + 7 >= 0`.
    - Linear combination (`linarith`): `1*m + -2*min_deg + -12/7 >= 0`.
    - Integer rounding (`omega`): `1*m + -2*min_deg + -2 >= 0`.
  - **Case 2** (`1*min_deg <= 0`):
    - Inventory `tau_le_m`: `1*m + -1*tau >= 0`.
    - Premise: `1*tau + -2 >= 0`.
    - Assumption: `-1*min_deg >= 0`.
    - Linear combination (`linarith`): `1*m + -2*min_deg + -2 >= 0`.
