# C256

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha <= 2*tau. Then 2*alpha <= 3*n - 4.

**Formula.** `if ((alpha <= 2*tau)), then (2*alpha <= 3*n - 4)`

## Proof

- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `-1*alpha + 2*tau >= 0`.
- Linear combination (`linarith`): `1*tau + -1/2 >= 0`.
- Integer rounding (`omega`): `1*tau + -1 >= 0`.
- Linear combination (`linarith`): `1*alpha + 3*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `2*alpha <= 3*n - 4`.
