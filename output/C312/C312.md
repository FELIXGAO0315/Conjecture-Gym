# C312

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n >= 2*chi, tau >= 2. Then 3*n >= -2*chi - 3*alpha + 22.

**Formula.** `if ((n >= 2*chi) and (tau >= 2)), then (3*n >= -2*chi - 3*alpha + 22)`

## Proof

- Case split (`by_cases`) on `chi` at threshold 3: `3*n + 2*chi + 3*alpha + -22 >= 0`.
  - **Case 1** (`1*chi >= 3`):
    - Assumption: `1*chi + -3 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Premise: `1*n + -2*chi >= 0`.
    - Linear combination (`linarith`): `3*n + 2*chi + 3*alpha + -27 >= 0`.
  - **Case 2** (`1*chi <= 2`):
    - Premise: `1*tau + -2 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*chi + 2 >= 0`.
    - Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `3*n + 2*chi + 3*alpha + -22 >= 0`.
