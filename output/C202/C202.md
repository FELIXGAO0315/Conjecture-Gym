# C202

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, is_connected, alpha >= tau. Then diam >= -alpha + girth.

**Formula.** `if ((has_cycle) and (is_connected) and (alpha >= tau)), then (diam >= -alpha + girth)`

## Proof

- Inventory `girth_le_diam`: `2*diam + -1*girth + 1 >= 0`.
- Inventory `girth_le_card`: `1*n + -1*girth >= 0`.
- Premise: `1*alpha + -1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*alpha + 1*diam + -1*girth + 1/2 >= 0`.
- Integer rounding (`omega`): `1*alpha + 1*diam + -1*girth >= 0`.
