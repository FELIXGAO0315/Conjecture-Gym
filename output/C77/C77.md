# C77

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_acyclic, n >= 4. Then n <= 2*chi + 2*alpha - 4.

**Formula.** `if ((is_acyclic) and (n >= 4)), then (n <= 2*chi + 2*alpha - 4)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Inventory `acyclic_chi`: `-1*chi + 2 >= 0`.
- Premise: `1*n + -4 >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 2): `1*chi + 2*alpha + -1*P_alpha_chi + -2 >= 0`.
- Linear combination (`linarith`): `1*alpha + -2 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 2, chi ≤ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + 2*chi + -2*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `n <= 2*chi + 2*alpha - 4`.
