# C296

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(2), chi <= omega. Then n <= 3*chi + 3*alpha - 8.

**Formula.** `if ((is_regular(2)) and (chi <= omega)), then (n <= 3*chi + 3*alpha - 8)`

## Proof

- Case split (`by_cases`) on `bnb:alpha` at threshold 3: `2*n + 3*chi + -3*tau + -8 >= 0`.
  - **Case 1** (`1*alpha >= 3`):
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `1*alpha + -3 >= 0`.
    - Inventory `omega_le_maxdeg`: `1*max_deg + -1*omega + 1 >= 0`.
    - Premise: `-1*chi + 1*omega >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Linear combination (`linarith`): `-1*chi + 3 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 3, chi ≤ 3): `3*chi + 3*alpha + -1*P_alpha_chi + -9 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 3*chi + -3*tau + -9 >= 0`.
  - **Case 2** (`1*alpha <= 2`):
    - Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
    - Inventory `regular_max`: `1*max_deg + -2 == 0`.
    - Linear combination (`linarith`): `1*n + -3 >= 0`.
    - Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
    - Assumption: `-1*alpha + 2 >= 0`.
    - Inventory `chi_ge_one`: `1*chi + -1 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 1): `2*chi + 1*alpha + -1*P_alpha_chi + -2 >= 0`.
    - Linear combination (`linarith`): `1*chi + -3/2 >= 0`.
    - Integer rounding (`omega`): `1*chi + -2 >= 0`.
    - Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≤ 2, chi ≥ 2): `2*chi + 2*alpha + -1*P_alpha_chi + -4 >= 0`.
    - Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
    - Linear combination (`linarith`): `2*n + 3*chi + -3*tau + -15/2 >= 0`.
    - Integer rounding (`omega`): `2*n + 3*chi + -3*tau + -8 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `n <= 3*chi + 3*alpha - 8`.
