# C144

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose alpha >= 4. Then 2*min_deg <= m.

**Formula.** `if ((alpha >= 4)), then (2*min_deg <= m)`

## Proof

- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Inventory `nonneg_min_deg`: `1*min_deg >= 0`.
- Premise: `1*alpha + -4 >= 0`.
- Inventory `nonneg_tau`: `1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 0): `-4*min_deg + 1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg >= 0`.
