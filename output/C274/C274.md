# C274

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose m >= 2*n, min_deg >= 3. Then max_deg <= m - 2*min_deg + 2.

**Formula.** `if ((m >= 2*n) and (min_deg >= 3)), then (max_deg <= m - 2*min_deg + 2)`

## Proof

- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Premise: `-2*n + 1*m >= 0`.
- Premise: `1*min_deg + -3 >= 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 3): `-3*n + -4*min_deg + 1*P_n_mindeg + 12 >= 0`.
- Linear combination (`linarith`): `1*m + -1*max_deg + -2*min_deg + 7/3 >= 0`.
- Integer rounding (`omega`): `1*m + -1*max_deg + -2*min_deg + 2 >= 0`.
