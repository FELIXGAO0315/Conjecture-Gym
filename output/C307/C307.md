# C307

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_regular(3), tau >= 2*alpha. Then 2*alpha <= n + 3*m - 20.

**Formula.** `if ((is_regular(3)) and (tau >= 2*alpha)), then (2*alpha <= n + 3*m - 20)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Premise: `-2*alpha + 1*tau >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Inventory `regular_max`: `1*max_deg + -3 == 0`.
- Inventory `regular_edges`: `-3*n + 2*m == 0`.
- Linear combination (`linarith`): `3*m + -1*alpha + 1*tau + -58/3 >= 0`.
- Integer rounding (`omega`): `3*m + -1*alpha + 1*tau + -20 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n`; the regular-degree identities `2*m = d*n` and `max_deg = min_deg = d` (`linarith`): `2*alpha <= n + 3*m - 20`.
