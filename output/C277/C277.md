# C277

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose chi <= 4, chi <= 2*max_deg. Then 2*max_deg >= n - 4*alpha + 4.

**Formula.** `if ((chi <= 4) and (chi <= 2*max_deg)), then (2*max_deg >= n - 4*alpha + 4)`

## Proof

- Inventory `card_le_alpha_chi`: `-1*n + 1*P_alpha_chi >= 0`.
- Premise: `2*max_deg + -1*chi >= 0`.
- Inventory `alpha_ge_one`: `1*alpha + -1 >= 0`.
- Premise: `-1*chi + 4 >= 0`.
- Product step (`mul_nonneg`) on P_alpha_chi from (alpha ≥ 1, chi ≤ 4): `1*chi + 4*alpha + -1*P_alpha_chi + -4 >= 0`.
- Inventory `gallai`: `-1*n + 1*alpha + 1*tau == 0`.
- Linear combination (`linarith`): `2*max_deg + 3*alpha + -1*tau + -4 >= 0`.
- Rewrite the proven form to the displayed conclusion using the Gallai identity `alpha + tau = n` (`linarith`): `2*max_deg >= n - 4*alpha + 4`.
