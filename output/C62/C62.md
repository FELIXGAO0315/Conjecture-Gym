# C62

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose has_cycle, n <= 2*chi. Then omega <= 2*chi - 2.

**Formula.** `if ((has_cycle) and (n <= 2*chi)), then (omega <= 2*chi - 2)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `cycle_three_le_card`: `1*n + -3 >= 0`.
- Premise: `-1*n + 2*chi >= 0`.
- Linear combination (`linarith`): `2*chi + -1*omega + -3/2 >= 0`.
- Integer rounding (`omega`): `2*chi + -1*omega + -2 >= 0`.
