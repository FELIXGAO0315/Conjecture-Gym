# C12

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose n <= 5, chi <= 2. Then n >= 3*m - 13.

**Formula.** `if ((n <= 5) and (chi <= 2)), then (n >= 3*m - 13)`

## Proof

- Premise: `-1*n + 5 >= 0`.
- Inventory `n_ge_one`: `1*n + -1 >= 0`.
- Product step (`mul_nonneg`) on N2 from (n ≥ 1, n ≤ 5): `6*n + -1*N2 + -5 >= 0`.
- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Premise: `-1*chi + 2 >= 0`.
- Linear combination (`linarith`): `-1*omega + 2 >= 0`.
- Inventory theorem `turan_r2` (via `linarith`): `-4*m + 1*N2 >= 0`.
- Linear combination (`linarith`): `1*n + -3*m + 55/4 >= 0`.
- Integer rounding (`omega`): `1*n + -3*m + 13 >= 0`.
