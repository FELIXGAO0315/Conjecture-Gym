# C199

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose is_connected, omega <= 2*max_deg. Then n >= 2*diam - 3*radius + 2.

**Formula.** `if ((is_connected) and (omega <= 2*max_deg)), then (n >= 2*diam - 3*radius + 2)`

## Proof

- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `omega_ge_one`: `1*omega + -1 >= 0`.
- Inventory `diam_le_two_radius`: `-1*diam + 2*radius >= 0`.
- Inventory `diam_le_card_sub_one`: `1*n + -1*diam + -1 >= 0`.
- Premise: `2*max_deg + -1*omega >= 0`.
- Linear combination (`linarith`): `1*n + -2*diam + 3*radius + -5/4 >= 0`.
- Integer rounding (`omega`): `1*n + -2*diam + 3*radius + -2 >= 0`.
