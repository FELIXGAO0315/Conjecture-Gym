# C107

## Statement

Let G be a finite simple graph with the usual invariants (n, m, max_deg, min_deg, chi, omega, alpha, tau, diam, radius, girth). Suppose min_deg >= 3. Then omega <= m - 2*min_deg + 4.

**Formula.** `if ((min_deg >= 3)), then (omega <= m - 2*min_deg + 4)`

## Proof

- Inventory `omega_le_chi`: `1*chi + -1*omega >= 0`.
- Inventory `chi_le_n`: `1*n + -1*chi >= 0`.
- Inventory `max_lt_card`: `1*n + -1*max_deg + -1 >= 0`.
- Inventory `min_le_max`: `1*max_deg + -1*min_deg >= 0`.
- Premise: `1*min_deg + -3 >= 0`.
- Linear combination (`linarith`): `1*max_deg + -3 >= 0`.
- Inventory `handshake_min`: `2*m + -1*P_n_mindeg >= 0`.
- Linear combination (`linarith`): `1*n + -4 >= 0`.
- Product step (`mul_nonneg`) on P_n_mindeg from (n ≥ 4, min_deg ≥ 3): `-3*n + -4*min_deg + 1*P_n_mindeg + 12 >= 0`.
- Linear combination (`linarith`): `1*m + -2*min_deg + -1*omega + 4 >= 0`.
