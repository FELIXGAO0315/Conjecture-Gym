# C149

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 57, 3*p_3 - p_4 >= 0, -2*p_3 + p_5 >= 0. Then p_6 >= -p_5 - sum_pk_after_p6 + 20.

**Formula.** `if ((is_simple) and (f_2>=_57) and (3*p_3 - p_4 >= 0) and (-2*p_3 + p_5 >= 0)), then p6 >= ((((-1 * p5) + (-1 * sum_pk_after_p6)) + 20))`

## Proof

- Case split (`by_cases`) on `bnb:p_3` at threshold 10: `1*p_5 + 1*p_6 + 1*sum_pk_after_p6 + -20 >= 0`.
  - **Case 1** (`1*p_3 >= 10`):
    - Assumption: `1*p_3 + -10 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Inventory `nonneg_sum_pk_after_p6`: `1*sum_pk_after_p6 >= 0`.
    - Premise: `-2*p_3 + 1*p_5 >= 0`.
    - Linear combination (`linarith`): `1*p_5 + 1*p_6 + 1*sum_pk_after_p6 + -20 >= 0`.
  - **Case 2** (`1*p_3 <= 9`):
    - Premise: `1*f_2 + -57 >= 0`.
    - Premise: `3*p_3 + -1*p_4 >= 0`.
    - Assumption: `-1*p_3 + 9 >= 0`.
    - Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
    - Linear combination (`linarith`): `1*p_5 + 1*p_6 + 1*sum_pk_after_p6 + -21 >= 0`.
