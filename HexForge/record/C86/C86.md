# C86

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose p_3 = 0, f_2 >= 35, sum_pk_after_p6 >= 2. Then p_6 >= -2*p_4 - p_5 + 24.

**Formula.** `if ((is_simple) and (p_3 = 0) and (f_2>=_35) and (sum_pk_after_p6 >= 2)), then p6 >= ((((-2 * p4) + (-1 * p5)) + 24))`

## Proof

- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `1*f_2 + -35 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Premise: `1*p_3 == 0`.
- Linear combination (`linarith`): `2*p_4 + 1*p_5 + 1*p_6 + -47/2 >= 0`.
- Integer rounding (`omega`): `2*p_4 + 1*p_5 + 1*p_6 + -24 >= 0`.
