# C112

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose sum_pk_after_p6 <= 2, f_2 >= 52, p_5 <= 4. Then 2*p_6 >= -2*p_4 + p_5 + 24.

**Formula.** `if ((is_simple) and (sum_pk_after_p6 <= 2) and (f_2>=_52) and (p_5 <= 4)), then p6 >= ((((-1 * p4) + (0.5 * p5)) + 12))`

## Proof

- Premise: `-1*p_5 + 4 >= 0`.
- Inventory `tail_juc_half`: `6*sum_pk_after_p6 + -1*W_tail + 2*J_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `-1*sum_pk_after_p6 + 2 >= 0`.
- Premise: `1*f_2 + -52 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `2*p_4 + 2*p_6 + -236/9 >= 0`.
- Integer rounding (`omega`): `1*p_4 + 1*p_6 + -14 >= 0`.
- Linear combination (`linarith`): `2*p_4 + -1*p_5 + 2*p_6 + -24 >= 0`.
