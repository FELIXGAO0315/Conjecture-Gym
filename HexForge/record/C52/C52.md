# C52

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose sum_pk_after_p6 <= 3, p_5 = 0, f_2 <= 22. Then p_6 >= -p_4 + sum_pk_after_p6 - 1.

**Formula.** `if ((is_simple) and (sum_pk_after_p6 <= 3) and (p_5 = 0) and (f_2<=_22)), then p6 >= ((((-1 * p4) + sum_pk_after_p6) + -1))`

## Proof

- Case split (`by_cases`) on `f_2` at threshold 7: `1*p_4 + 1*p_6 + -1*sum_pk_after_p6 + 1 >= 0`.
  - **Case 1** (`1*f_2 >= 7`):
    - Inventory `tail_juc_lower`: `2*sum_pk_after_p6 + 1*J_tail >= 0`.
    - Inventory `nonneg_p_4`: `1*p_4 >= 0`.
    - Premise: `-1*sum_pk_after_p6 + 3 >= 0`.
    - Assumption: `1*f_2 + -7 >= 0`.
    - Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
    - Premise: `1*p_5 == 0`.
    - Linear combination (`linarith`): `1*p_4 + 1*p_6 + -1*sum_pk_after_p6 + 1 >= 0`.
  - **Case 2** (`1*f_2 <= 6`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `nonneg_p_4`: `1*p_4 >= 0`.
    - Inventory `nonneg_p_5`: `1*p_5 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Assumption: `-1*f_2 + 6 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
    - Linear combination (`linarith`): `1*p_4 + 1*p_6 + -1*sum_pk_after_p6 + 3/2 >= 0`.
    - Integer rounding (`omega`): `1*p_4 + 1*p_6 + -1*sum_pk_after_p6 + 1 >= 0`.
