# C122

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 37, p_5 <= 2, sum_pk_after_p6 >= 3. Then 2*p_6 >= -p_4 - 2*sum_pk_after_p6 + 25.

**Formula.** `if ((is_simple) and (f_2>=_37) and (p_5 <= 2) and (sum_pk_after_p6 >= 3)), then p6 >= ((((-0.5 * p4) + (-1 * sum_pk_after_p6)) + 12.5))`

## Proof

- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `1*f_2 + -37 >= 0`.
- Premise: `-1*p_5 + 2 >= 0`.
- Premise: `1*sum_pk_after_p6 + -3 >= 0`.
- Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `1*p_4 + 2*p_6 + 2*sum_pk_after_p6 + -74/3 >= 0`.
- Integer rounding (`omega`): `1*p_4 + 2*p_6 + 2*sum_pk_after_p6 + -25 >= 0`.
