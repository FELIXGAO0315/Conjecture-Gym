# C4

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 15. Then 3*p_6 >= -p_3 - p_4 - p_5 + 7.

**Formula.** `if ((is_simple) and (f_2 >= 15)), then (3*p_6 >= -p_3 - p_4 - p_5 + 7)`

## Proof

- Inventory `tail_excess`: `-5*sum_pk_after_p10 + 1*W_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Inventory `nonneg_p_5`: `1*p_5 >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Inventory `nonneg_p_8`: `1*p_8 >= 0`.
- Inventory `nonneg_p_9`: `1*p_9 >= 0`.
- Inventory `nonneg_p_10`: `1*p_10 >= 0`.
- Inventory `nonneg_sum_pk_after_p10`: `1*sum_pk_after_p10 >= 0`.
- Premise: `1*f_2 + -15 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*p_7 + -2*p_8 + -3*p_9 + -4*p_10 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*p_7 + -1*p_8 + -1*p_9 + -1*p_10 + -1*sum_pk_after_p10 + 1*f_2 == 0`.
- Linear combination (`linarith`): `1*p_3 + 1*p_4 + 1*p_5 + 3*p_6 + -27/4 >= 0`.
- Integer rounding (`omega`): `1*p_3 + 1*p_4 + 1*p_5 + 3*p_6 + -7 >= 0`.
