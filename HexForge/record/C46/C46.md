# C46

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 21, p_3 = 0, p_4 = 0. Then 2*p_6 >= p_4 - 2*p_5 + 34.

**Formula.** `if ((is_simple) and (f_2>=_21) and (p_3 = 0) and (p_4 = 0)), then p6 >= ((((0.5 * p4) + (-1 * p5)) + 17))`

## Proof

- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `1*f_2 + -21 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Premise: `1*p_3 == 0`.
- Premise: `1*p_4 == 0`.
- Linear combination (`linarith`): `1*p_5 + 1*p_6 + -33/2 >= 0`.
- Integer rounding (`omega`): `1*p_5 + 1*p_6 + -17 >= 0`.
- Linear combination (`linarith`): `-1*p_4 + 2*p_5 + 2*p_6 + -34 >= 0`.
