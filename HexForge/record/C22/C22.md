# C22

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose -p_3 + p_5 >= 0, -p_4 + 2*p_5 >= 0, sum_pk_after_p6 >= 5. Then p_6 >= -2*p_4 - 2*p_5 + 10.

**Formula.** `if ((is_simple) and (-p_3 + p_5 >= 0) and (-p_4 + 2*p_5 >= 0) and (sum_pk_after_p6 >= 5)), then p6 >= ((((-2 * p4) + (-2 * p5)) + 10))`

## Proof

- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `1*sum_pk_after_p6 + -5 >= 0`.
- Premise: `-1*p_3 + 1*p_5 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Linear combination (`linarith`): `1*p_4 + 1*p_5 + -17/4 >= 0`.
- Integer rounding (`omega`): `1*p_4 + 1*p_5 + -5 >= 0`.
- Linear combination (`linarith`): `2*p_4 + 2*p_5 + 1*p_6 + -10 >= 0`.
