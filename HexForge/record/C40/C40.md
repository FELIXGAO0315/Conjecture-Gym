# C40

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose sum_pk_after_p6 <= 4, sum_pk_after_p6 >= 4. Then p_6 >= -2*p_4 - p_5 + 2.

**Formula.** `if ((is_simple) and (sum_pk_after_p6 <= 4) and (sum_pk_after_p6 >= 4)), then p6 >= ((((-2 * p4) + (-1 * p5)) + 2))`

## Proof

- Inventory `tail_juc_lower`: `2*sum_pk_after_p6 + 1*J_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `-1*sum_pk_after_p6 + 4 >= 0`.
- Inventory `tail_juc_upper`: `-3*sum_pk_after_p6 + 1*W_tail + -1*J_tail >= 0`.
- Premise: `1*sum_pk_after_p6 + -4 >= 0`.
- Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `1*f_2 + -10 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
- Linear combination (`linarith`): `2*p_4 + 1*p_5 + 1*p_6 + -4/3 >= 0`.
- Integer rounding (`omega`): `2*p_4 + 1*p_5 + 1*p_6 + -2 >= 0`.
