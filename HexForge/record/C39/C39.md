# C39

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 47, p_4 = 0, p_5 = 0. Then p_6 >= -2*p_3 + 2*p_5 + 30.

**Formula.** `if ((is_simple) and (f_2>=_47) and (p_4 = 0) and (p_5 = 0)), then p6 >= ((((-2 * p3) + (2 * p5)) + 30))`

## Proof

- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `1*f_2 + -47 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Premise: `1*p_4 == 0`.
- Premise: `1*p_5 == 0`.
- Linear combination (`linarith`): `2*p_3 + -2*p_5 + 1*p_6 + -59/2 >= 0`.
- Integer rounding (`omega`): `2*p_3 + -2*p_5 + 1*p_6 + -30 >= 0`.
