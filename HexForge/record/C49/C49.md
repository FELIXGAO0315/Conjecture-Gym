# C49

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 54, -p_3 + 3*p_4 >= 0. Then 2*p_6 >= -2*p_4 - p_5 + 10.

**Formula.** `if ((is_simple) and (f_2>=_54) and (-p_3 + 3*p_4 >= 0)), then p6 >= ((((-1 * p4) + (-0.5 * p5)) + 5))`

    - Inventory `nonneg_p_5`: `1*p_5 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Linear combination (`linarith`): `2*p_4 + 1*p_5 + 2*p_6 + -10 >= 0`.
  - **Case 2** (`1*p_4 <= 4`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `1*f_2 + -54 >= 0`.
