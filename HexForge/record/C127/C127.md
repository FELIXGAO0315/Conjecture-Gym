# C127

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 41, -3*p_4 + 2*p_5 >= 0, -p_3 + 3*p_4 >= 0. Then p_6 >= p_4 - 2*p_5 + 7.

**Formula.** `if ((is_simple) and (f_2>=_41) and (-3*p_4 + 2*p_5 >= 0) and (-p_3 + 3*p_4 >= 0)), then p6 >= (((p4 + (-2 * p5)) + 7))`
