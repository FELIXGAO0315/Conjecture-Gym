# C75

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 8, p_3 <= 3. Then p_6 >= -p_4 - p_5 + 4.

**Formula.** `if ((is_simple) and (f_2>=_8) and (p_3 <= 3)), then p6 >= ((((-1 * p4) + (-1 * p5)) + 4))`

## Proof

- Case split (`by_cases`) on `tail_count` at threshold 3: `1*p_4 + 1*p_5 + 1*p_6 + -4 >= 0`.
  - **Case 1** (`1*sum_pk_after_p6 >= 3`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `nonneg_p_5`: `1*p_5 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `-1*p_3 + 3 >= 0`.
    - Assumption: `1*sum_pk_after_p6 + -3 >= 0`.
    - Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Linear combination (`linarith`): `1*p_4 + 1*p_5 + 1*p_6 + -13/4 >= 0`.
    - Integer rounding (`omega`): `1*p_4 + 1*p_5 + 1*p_6 + -4 >= 0`.
  - **Case 2** (`1*sum_pk_after_p6 <= 2`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `tail_juc_lower`: `2*sum_pk_after_p6 + 1*J_tail >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `-1*p_3 + 3 >= 0`.
    - Assumption: `-1*sum_pk_after_p6 + 2 >= 0`.
    - Premise: `1*f_2 + -8 >= 0`.
    - Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Linear combination (`linarith`): `1*p_4 + 1*p_5 + 1*p_6 + -13/4 >= 0`.
    - Integer rounding (`omega`): `1*p_4 + 1*p_5 + 1*p_6 + -4 >= 0`.
