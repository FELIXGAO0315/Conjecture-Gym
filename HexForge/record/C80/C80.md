# C80

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 43, f_2 <= 47, sum_pk_after_p6 <= 5. Then 2*p_6 >= p_3 - 2*sum_pk_after_p6 - 27.

**Formula.** `if ((is_simple) and (f_2>=_43) and (f_2<=_47) and (sum_pk_after_p6 <= 5)), then p6 >= ((((0.5 * p3) + (-1 * sum_pk_after_p6)) + -13.5))`

## Proof

- Inventory `tail_juc_half`: `6*sum_pk_after_p6 + -1*W_tail + 2*J_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Inventory `nonneg_sum_pk_after_p6`: `1*sum_pk_after_p6 >= 0`.
- Premise: `-1*f_2 + 47 >= 0`.
- Premise: `1*f_2 + -43 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `-1*p_3 + 2*p_6 + 2*sum_pk_after_p6 + 223/8 >= 0`.
- Integer rounding (`omega`): `-1*p_3 + 2*p_6 + 2*sum_pk_after_p6 + 27 >= 0`.
