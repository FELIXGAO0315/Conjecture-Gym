# C2

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 30, sum_pk_after_p6 <= 3, p_3 >= 1. Then p_6 >= -2*p_4 - p_5 + 9.

**Formula.** `if ((is_simple) and (f_2 >= 30) and (sum_pk_after_p6 <= 3) and (p_3 >= 1)), then (p_6 >= -2*p_4 - p_5 + 9)`

## Proof

- Inventory `tail_juc_half`: `6*sum_pk_after_p10 + -1*W_tail + 2*J_tail >= 0`.
- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Inventory `nonneg_p_5`: `1*p_5 >= 0`.
- Inventory `nonneg_p_7`: `1*p_7 >= 0`.
- Inventory `nonneg_p_9`: `1*p_9 >= 0`.
- Premise: `1*f_2 + -30 >= 0`.
- Premise: `-1*p_7 + -1*p_8 + -1*p_9 + -1*p_10 + -1*sum_pk_after_p10 + 3 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + 2*p_7 + 2*p_8 + 1*p_9 + 1*p_10 + -1*J_tail + -12 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*p_7 + -2*p_8 + -3*p_9 + -4*p_10 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*p_7 + -1*p_8 + -1*p_9 + -1*p_10 + -1*sum_pk_after_p10 + 1*f_2 == 0`.
- Linear combination (`linarith`): `2*p_4 + 1*p_5 + 1*p_6 + -25/3 >= 0`.
- Integer rounding (`omega`): `2*p_4 + 1*p_5 + 1*p_6 + -9 >= 0`.
