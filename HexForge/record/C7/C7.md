# C7

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 32, sum_pk_after_p6 <= 5. Then 2*p_6 >= -2*p_4 - p_5 + 11.

**Formula.** `if ((is_simple) and (f_2>=_32) and (sum_pk_after_p6 <= 5)), then p6 >= ((((-1 * p4) + (-0.5 * p5)) + 5.5))`

    - Premise: `-1*sum_pk_after_p6 + 5 >= 0`.
    - Assumption: `1*sum_pk_after_p6 + -3 >= 0`.
    - Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
    - Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
    - Linear combination (`linarith`): `2*p_4 + 1*p_5 + 2*p_6 + -21/2 >= 0`.
    - Integer rounding (`omega`): `2*p_4 + 1*p_5 + 2*p_6 + -11 >= 0`.
  - **Case 2** (`1*sum_pk_after_p6 <= 2`):
    - Inventory `tail_juc_half`: `6*sum_pk_after_p6 + -1*W_tail + 2*J_tail >= 0`.
    - Inventory `nonneg_p_4`: `1*p_4 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `1*f_2 + -32 >= 0`.
