# C36

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose -3*p_4 + 2*p_5 >= 0, p_3 <= 2, f_2 >= 40. Then 2*p_6 >= -2*p_5 - sum_pk_after_p6 + 42.

**Formula.** `if ((is_simple) and (-3*p_4 + 2*p_5 >= 0) and (p_3 <= 2) and (f_2>=_40)), then p6 >= ((((-1 * p5) + (-0.5 * sum_pk_after_p6)) + 21))`

## Proof

- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `-3*p_4 + 2*p_5 >= 0`.
- Premise: `-1*p_3 + 2 >= 0`.
- Premise: `1*f_2 + -40 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `2*p_5 + 2*p_6 + 1*sum_pk_after_p6 + -125/3 >= 0`.
- Integer rounding (`omega`): `2*p_5 + 2*p_6 + 1*sum_pk_after_p6 + -42 >= 0`.
