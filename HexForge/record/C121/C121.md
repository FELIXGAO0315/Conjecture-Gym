# C121

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose sum_pk_after_p6 >= 3, p_4 = 0. Then 2*p_6 >= -p_5 - 2*sum_pk_after_p6 + 9.

**Formula.** `if ((is_simple) and (sum_pk_after_p6 >= 3) and (p_4 = 0)), then p6 >= ((((-0.5 * p5) + (-1 * sum_pk_after_p6)) + 4.5))`

## Proof

- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `1*sum_pk_after_p6 + -3 >= 0`.
- Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Premise: `1*p_4 == 0`.
- Linear combination (`linarith`): `1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -33/4 >= 0`.
- Integer rounding (`omega`): `1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -9 >= 0`.
