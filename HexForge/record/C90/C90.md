## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 30, sum_pk_after_p6 >= 6, p_5 <= 3. Then p_6 >= -p_4 - sum_pk_after_p6 + 10.

**Formula.** `if ((is_simple) and (f_2>=_30) and (sum_pk_after_p6 >= 6) and (p_5 <= 3)), then p6 >= ((((-1 * p4) + (-1 * sum_pk_after_p6)) + 10))`

## Proof

- Inventory `nonneg_p_4`: `1*p_4 >= 0`.
- Premise: `1*f_2 + -30 >= 0`.
- Premise: `-1*p_5 + 3 >= 0`.
- Premise: `1*sum_pk_after_p6 + -6 >= 0`.
- Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `1*p_4 + 1*p_6 + 1*sum_pk_after_p6 + -28/3 >= 0`.
- Integer rounding (`omega`): `1*p_4 + 1*p_6 + 1*sum_pk_after_p6 + -10 >= 0`.
