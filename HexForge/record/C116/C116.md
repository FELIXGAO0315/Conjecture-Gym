# C116

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose p_5 = 0, p_4 <= 4, sum_pk_after_p6 <= 4. Then 2*p_6 >= -p_4 + 2*sum_pk_after_p6 - 6.

**Formula.** `if ((is_simple) and (p_5 = 0) and (p_4 <= 4) and (sum_pk_after_p6 <= 4)), then p6 >= ((((-0.5 * p4) + sum_pk_after_p6) + -3))`

## Proof

- Case split (`by_cases`) on `tail_count` at threshold 3: `1*p_4 + 2*p_6 + -2*sum_pk_after_p6 + 6 >= 0`.
  - **Case 1** (`1*sum_pk_after_p6 >= 3`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `nonneg_p_4`: `1*p_4 >= 0`.
    - Premise: `-1*sum_pk_after_p6 + 4 >= 0`.
    - Assumption: `1*sum_pk_after_p6 + -3 >= 0`.
    - Inventory theorem `Barnette_P6Bound` (via `linarith`): `-1*p_3 + 1*p_5 + 2*p_6 + 2*sum_pk_after_p6 + -4 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Premise: `1*p_5 == 0`.
    - Linear combination (`linarith`): `1*p_4 + 2*p_6 + -2*sum_pk_after_p6 + 20/3 >= 0`.
    - Integer rounding (`omega`): `1*p_4 + 2*p_6 + -2*sum_pk_after_p6 + 6 >= 0`.
  - **Case 2** (`1*sum_pk_after_p6 <= 2`):
    - Inventory `nonneg_p_4`: `1*p_4 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Assumption: `-1*sum_pk_after_p6 + 2 >= 0`.
    - Linear combination (`linarith`): `1*p_4 + 2*p_6 + -2*sum_pk_after_p6 + 4 >= 0`.
