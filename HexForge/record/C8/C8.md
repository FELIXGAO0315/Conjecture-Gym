# C8

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 35, p_9 >= 1, p_8 <= 1. Then 2*p_6 >= p_8 + p_9 - f_2 + 20.

**Formula.** `if ((is_simple) and (f_2 >= 35) and (p_9 >= 1) and (p_8 <= 1)), then (2*p_6 >= p_8 + p_9 - f_2 + 20)`
