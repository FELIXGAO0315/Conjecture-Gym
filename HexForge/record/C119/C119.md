# C119

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 8, p_4 = 0, sum_pk_after_p6 <= 3. Then p_6 >= -p_3 - p_5 + 7.

**Formula.** `if ((is_simple) and (f_2>=_8) and (p_4 = 0) and (sum_pk_after_p6 <= 3)), then p6 >= ((((-1 * p3) + (-1 * p5)) + 7))`

## Proof

- Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
- Inventory `tail_juc_lower`: `2*sum_pk_after_p6 + 1*J_tail >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `-1*sum_pk_after_p6 + 3 >= 0`.
- Premise: `1*f_2 + -8 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Premise: `1*p_4 == 0`.
- Linear combination (`linarith`): `1*p_3 + 1*p_5 + 1*p_6 + -19/3 >= 0`.
- Integer rounding (`omega`): `1*p_3 + 1*p_5 + 1*p_6 + -7 >= 0`.
