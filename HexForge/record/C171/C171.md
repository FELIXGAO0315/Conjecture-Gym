# C171

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose p_5 <= 2, p_3 - 3*p_4 >= 0. Then p_6 >= -2*p_3 - 2*p_5 + 8.

**Formula.** `if ((is_simple) and (p_5 <= 2) and (p_3 - 3*p_4 >= 0)), then p6 >= ((((-2 * p3) + (-2 * p5)) + 8))`

## Proof

- Case split (`by_cases`) on `bnb:p_3` at threshold 4: `2*p_3 + 2*p_5 + 1*p_6 + -8 >= 0`.
  - **Case 1** (`1*p_3 >= 4`):
    - Assumption: `1*p_3 + -4 >= 0`.
    - Inventory `nonneg_p_5`: `1*p_5 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Linear combination (`linarith`): `2*p_3 + 2*p_5 + 1*p_6 + -8 >= 0`.
  - **Case 2** (`1*p_3 <= 3`):
    - Inventory `tail_juc_lower`: `2*sum_pk_after_p6 + 1*J_tail >= 0`.
    - Inventory `tail_juc_upper`: `-3*sum_pk_after_p6 + 1*W_tail + -1*J_tail >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Inventory `nonneg_sum_pk_after_p6`: `1*sum_pk_after_p6 >= 0`.
    - Premise: `1*p_3 + -3*p_4 >= 0`.
    - Assumption: `-1*p_3 + 3 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Linear combination (`linarith`): `2*p_3 + 2*p_5 + 1*p_6 + -8 >= 0`.
