# C92

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 16, p_3 - 3*p_4 >= 0. Then 2*p_6 >= -p_5 - sum_pk_after_p6 + 6.

**Formula.** `if ((is_simple) and (f_2>=_16) and (p_3 - 3*p_4 >= 0)), then p6 >= ((((-0.5 * p5) + (-0.5 * sum_pk_after_p6)) + 3))`

## Proof

- Inventory `tail_juc_half`: `6*sum_pk_after_p6 + -1*W_tail + 2*J_tail >= 0`.
- Inventory `nonneg_p_5`: `1*p_5 >= 0`.
- Inventory `nonneg_p_6`: `1*p_6 >= 0`.
- Premise: `1*f_2 + -16 >= 0`.
- Premise: `1*p_3 + -3*p_4 >= 0`.
- Inventory theorem `JucovicTheorem` (via `linarith`): `2*p_4 + 3*p_5 + 3*p_6 + -1*J_tail + -12 >= 0`.
- Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
- Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
- Linear combination (`linarith`): `1*p_5 + 2*p_6 + 1*sum_pk_after_p6 + -160/31 >= 0`.
- Integer rounding (`omega`): `1*p_5 + 2*p_6 + 1*sum_pk_after_p6 + -6 >= 0`.
