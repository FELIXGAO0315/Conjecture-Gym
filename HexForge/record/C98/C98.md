# C98

## Statement

Let M be a simple 3-polytope (a simple 3-connected planar map), with p_k the number of k-gonal faces, f_2 the total number of faces, and sum_{k>=7} p_k the number of faces of size at least 7. Suppose f_2 >= 16, -3*p_4 + 2*p_5 >= 0, sum_pk_after_p6 >= 3. Then 2*p_6 >= -2*p_3 - p_5 + 8.

**Formula.** `if ((is_simple) and (f_2>=_16) and (-3*p_4 + 2*p_5 >= 0) and (sum_pk_after_p6 >= 3)), then p6 >= ((((-1 * p3) + (-0.5 * p5)) + 4))`

## Proof

- Case split (`by_cases`) on `bnb:p_4` at threshold 5: `2*p_3 + 1*p_5 + 2*p_6 + -8 >= 0`.
  - **Case 1** (`1*p_4 >= 5`):
    - Inventory `nonneg_p_3`: `1*p_3 >= 0`.
    - Assumption: `1*p_4 + -5 >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `-3*p_4 + 2*p_5 >= 0`.
    - Linear combination (`linarith`): `2*p_3 + 1*p_5 + 2*p_6 + -15/2 >= 0`.
    - Integer rounding (`omega`): `2*p_3 + 1*p_5 + 2*p_6 + -8 >= 0`.
  - **Case 2** (`1*p_4 <= 4`):
    - Inventory `tail_excess`: `-1*sum_pk_after_p6 + 1*W_tail >= 0`.
    - Inventory `nonneg_p_6`: `1*p_6 >= 0`.
    - Premise: `1*f_2 + -16 >= 0`.
    - Assumption: `-1*p_4 + 4 >= 0`.
    - Inventory `Juc_EulerFormula`: `3*p_3 + 2*p_4 + 1*p_5 + -1*W_tail + -12 == 0`.
    - Inventory `face_split`: `-1*p_3 + -1*p_4 + -1*p_5 + -1*p_6 + -1*sum_pk_after_p6 + 1*f_2 == 0`.
    - Linear combination (`linarith`): `2*p_3 + 1*p_5 + 2*p_6 + -8 >= 0`.
